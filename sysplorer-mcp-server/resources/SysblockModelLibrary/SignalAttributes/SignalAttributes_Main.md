# SignalAttributes
---
&nbsp;

用于修改信号属性的模块。

使用 SignalAttributes 库中的模块来转换信号数据类型或单位，并操作其他信号属性。

## 模块

| 模块名                                                       | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| **[DownSample](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SignalAttributes/DownSample.md)** | 通过采样因子对输入信号进行降采样                             |
| **[RateTransition](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SignalAttributes/RateTransition.md)** | 处理不同速率和任务之间的数据传输                             |
| **[Width](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SignalAttributes/Width.md)** | 输出输入信号的宽度                                           |
| **[WeightedSampleTime](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SignalAttributes/WeightedSampleTime.md)** | 使用加权采样时间对输入信号进行加、减、乘或除运算，或只输出加权采样时间或加权采样率 |
