# FlipFlops
---
&nbsp;

触发器模块，例如 DFlipFlop。

使用 FlipFlops 库中的模块来创建触发器模块。

&nbsp;

| 模块名          | 说明     |
| --------------- | -------- |
| [DFlipFlop](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/FlipFlops/DFlipFlop.html)  | 带使能端口的 D 触发器 |
| [S_RFlipFlop](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/FlipFlops/S_RFlipFlop.html) | 置位/复位触发器 |
| [J_KFlipFlop](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/FlipFlops/JKFlipFlop.html) | 负边沿触发的 J-K 触发器建模 |
