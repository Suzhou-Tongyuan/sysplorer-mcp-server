# Discrete
---
&nbsp;

离散时间模块，如 UnitDelay。  


使用 Discrete 库中的模块对离散系统建模和实现离散算法。

## 模块

| 模块名                                                       | 说明                                         |
| ------------------------------------------------------------ | -------------------------------------------- |
| **[Delay](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/Delay.html)** | 按固定或可变采样周期延迟输入信号             |
| **[TappedDelay](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/TappedDelay.html)** | 将标量信号延迟多个采样周期并输出所有延迟版本 |
| **[UnitDelay](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/UnitDelay.html)** | 将信号延迟一个采样周期                       |
| **[DiscreteTimeIntegrator](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/DiscreteTimeIntegrator.html)** | 执行信号的离散时间积分或累积                 |
| **[DiscreteTransferFcn](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/DiscreteTransferFcn.html)** | 实现离散传递函数                             |
| **[ZeroOrderHold](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/ZeroOrderHold.html)** | 实现零阶保持采样周期                         |
| **[Difference](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/Difference.html)** | 计算一个时间步内的信号变化                   |
| **[DiscretePIDController](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/DiscretePIDController.html)** | 离散时间或连续时间 PID 控制器                |
| **[Memory](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/Memory.html)** | 输出上一个时间步的输入                       |
| **[DiscreteDerivative](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/DiscreteDerivative.html)** | 输入的离散时间导数                           |
| **[DiscreteStateSpace](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/DiscreteStateSpace.html)** | 实现离散状态空间系统                           |
| **[TransferFcnFirstOrder](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/TransferFcnFirstOrder.html)** | 实现离散时间一阶传递函数                           |
| **[TransferFcnLeadorLeg](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/TransferFcnLeadorLeg.html)** | 实现离散时间超前或滞后补偿器                           |
| **[TransferFcnRealZero](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Discrete/TransferFcnRealZero.html)** | 离散时间传递函数有一个零点且没有极点                           |
