# 电机模型库
---
&nbsp;

## 概述

TYMotor 电机模型库，包括电机本体、控制器、驱动器、负载、传感器等组件模型。该库可应用于电机系统、控制策略、驱动电路的设计、验证与优化，用户可根据实际需求搭建所需的系统模型，应用于电机控制策略的开发、电驱动系统的故障诊断、电机动态特性的仿真与分析等。

## 功能要点

- 支持多种电机选型

    提供无刷直流电机、永磁同步电机、感应电机、查表电机等模型，用户可根据实际需求，通过虚拟试验完成电机的选型。

- 支持电机控制策略设计

    根据设计需求，能够实现电流环、角速度环、角度环等不同组合的闭环控制，为电机控制策略的设计与验证提供依据。

- 支持电机系统的动态特性分析

    提供不同粒度的组件模型，可以根据不同的仿真需要进行选择，快速构建适用不同仿真工况的系统模型，并进行电机系统的动态特性分析。


## 模型库目录

TYMotor 电机模型库提供了复杂电控系统构成所需的零部件模型，主要包括：电机本体（直流电机、永磁同步电机、异步电机、步进电机）、控制器（伺服控制、矢量控制、直接转矩控制）、驱动器、负载和传感器设备等模型，采用搭积木和连线的模块化建模方式，易于快速实现电控部件的开发和复杂电控系统模型的仿真分析。

## 应用场景

- 电动机和发电机动态特性建模与仿真

    支持快速搭建电动机和发电机系统模型，对电动机和发电机的电流、转速和转矩等变量的动态特性进行仿真分析。

- 电机系统控制策略开发与验证

    支持搭建不同控制方式的电机系统，对电机系统在不同控制模式下的电流、转速和转矩等变量的动态特性进行仿真分析。

- 电机系统故障仿真分析

    在系统正常工况基础上，通过关联不同的故障模式，搭建典型故障工况下的故障模型，用于预示或复现系统状态的变化情况。

- 电控系统示教培训

    利用电机模型库可以动态模拟基本电控部件和电控系统的工作原理，加强理论知识与仿真应用的结合，开拓视野、培养创新思维和专业意识。

## 应用案例

控制力矩陀螺（Control Moment Gyro，CMG）是一种依靠恒定角动量和框架组件驱动转子旋转输出力矩的重要装置，主要由转子、框架、电机等核心部件组成，转子以恒定的角速度高速旋转，提供一种恒定角动量。框架通过驱动转子围绕垂直于角动量矢量方向的框架轴顺（或逆）时针旋转，实现框架轴向两端的力矩输出。

本案例基于 TYMotor 电机模型库，结合控制力矩陀螺系统原理，快速搭建包含电机本体、控制器、逆变器、传感器、框架、转子、基座的单框架控制力矩陀螺系统模型，用于验证电机控制算法的稳定性与可靠性、调试在不同工况下的控制参数、观察在多种激励下的系统响应。
