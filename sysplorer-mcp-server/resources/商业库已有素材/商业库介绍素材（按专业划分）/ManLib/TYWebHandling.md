# 卷料处理模型库
---
&nbsp;

## 概述
<br>
TYWebHandling 卷料处理模型库包括卷料属性设置、卷料类、卷辊类、边界源、卷料辅件和各种传感器等模型。该库可用于造纸、印刷、包装加工、柔性电子封装等工业生产制造领域，该库提供了一系列卷料系统基本要素的组件模型，专门用于卷料处理和运输过程模拟、仿真和优化，例如开展卷料张力和速度计算与控制；收放卷系统动态模拟和辊轮负载计算分析；验证卷料生产线运行系统的关键指标等。

## 功能要点

- 提供丰富的卷料系统组件模型

    模型库涵盖了常用的卷料系统基本要素模型，能够提供卷料、卷辊、压辊以及各种传感器等模型，覆盖生产制造行业中的卷料系统建模需求，帮助用户实现系统的快速设计和验证。

- 支持柔性卷料和时变直径卷辊建模

    模型库采用精确的物理模型来描述卷料系统中的各种卷料系统零部件，包括考虑重力的柔性卷料、考虑滑移的卷辊以及具有时变直径和转动惯量特性的收放卷辊等。这些模型经过验证和优化，能够准确地预测组件的行为和性能，提供可靠的仿真结果。

- 适用多场景、多工况的建模与仿真

    模型库包含的卷料、卷辊、边界源、传感器和卷料辅件等模型，能够适用于多场景、多工况的卷料系统建模与仿真，如卷料加工过程中的动态张力计算、卷料系统安放设计与模拟、收放卷实时变化分析与运行速度控制等。
    
- 具有较强的卷料系统动态控制能力

    支持模拟卷料系统在不同场景下的运动行为，能够为控制器验证提供开发系统模型，用户可以对卷料系统中张力和速度添加合适的控制模型，如 PID 控制，防止卷料运行中张力过大或过小，降低生产过程中的风险程度。

- 参数化模型生成和强大的可视化分析

    支持用户可以创建参数化的卷料和卷辊模型，便于调整不同的几何和材料属性，这使得该库适用于多种类型的卷料，如金属、纸张和塑料薄膜等，满足卷料系统建模需求。同时该库能够使用户能够直观地查看卷料加工过程中的各种参数，如张力变化、转速等，并进行深入的数据分析。



## 模型库目录

## 应用场景

卷料处理模型库是一个行业专用的行业模型库，主要适用于生产制造领域中的多个研发阶段的应用。

- 方案设计阶段

    在方案设计阶段，可用于选择合适的卷料组件，包括卷料、卷辊、边界源等，以满足系统的工作条件和性能要求，并进行组合、调整和优化，支撑系统功能和性能的初步验证评价，实现系统多方案优选分析。

    - 典型卷料系统设计的快速验证

        卷料系统在进行搭建前需要根据需求进行工况的分析，并初步拟定卷料系统原理图，包括基本系统的设计，如速度控制系统、张力控制系统等，为了能够更高效准确的对卷料系统进行设计，可使用卷料处理模型库进行系统化、模块化的设计方法，支撑系统功能及性能的初步验证，确保系统设计合理、运行高效。

        真空镀膜设备快速验证：

        <img :src="$withBase('/ManLib/TYWebHandling/2.png')" style="width:468px;border:black 1px solid;">

    - 卷料系统关键设备的快速选型

        卷料系统进行部件设计选型时，首先明确系统的需求，并选择合适的卷辊及边界源，搭配恰当的卷料模型进行系统搭建，在该过程中还需要考虑卷料重力、卷辊摩擦等问题，因此借助卷料处理库可以有效的模拟该过程，节省实验投入的人力和物力，提高选型的效率。

- 详细设计阶段

    在详细设计阶段，可用于确定卷料系统中每个组件的具体规格和参数，包括卷料的弹性模量和泊松比、卷辊的几何和材质等，能够合理做出组件参数信息调整，模拟和评估各个组件参数调整对整个系统的影响程度，以辅助详细设计决策。

    - 各种卷料设备的三维设计

        卷料系统中模型参数的设置，影响整个卷料系统的性能指标，因此利用卷料处理模型库搭建相应的卷料系统，并通过修改各模型的参数进行仿真模拟，确保系统运行的安全性和可靠性。

## 应用案例

卷料张力控制系统要应用于工业生产中，特别是卷材加工、印刷、涂布和包装等领域。在卷绕、展开或者传输过程中，因为张力或高或者过低导致材料损坏、变形或者生产不稳定，张力控制的目的是确保卷料的连续性、质量和安全性。卷料处理系统可以通过采用合适的控制算法，实现对卷料系统的张力控制。通过使用 TYWebHandling 卷料处理模型库中的卷料设置、惯性放卷辊、卷料、卷辊、理想收卷辊等模型以及 TYMultibody 多体库中的转动副、固定约束等模型，对卷料张力控制系统中的部件和约束进行快速建模，通过浮辊的受力计算添加 PID 控制器，搭建的系统模型如下图如所示。从输出曲线可以看出，卷料的实际张力值和期望张力值趋于一致，控制效果较好。因此，通过 TYWebHandling 可以对卷料生产系统模拟、合理设计和调节张力控制系统，支持实时调整控制策略，实现稳定控制，有效提高卷料的生产过程的精度和可靠性。
