# 接触模型库
---
&nbsp;

## 概述

TYContact 接触模型库包括球体、圆柱体、圆锥体、平面等常用刚体的接触元件，可以模拟不同刚体间的点接触和线接触、面接触功能，也可以模拟其在二维固定平面的简化接触，其作为产品货架体系中一款专业基础库，是机械多体库的功能扩展，研究和解决机械接触领域中的接触状态和接触力的问题。

## 功能要点

- 提供丰富的三维接触类型

    在多体运动状态模拟中，提供不同刚体间的接触计算功能，提供如球、圆柱、圆锥、平面等常用刚体的点、线、面类型的接触碰撞模拟功能。

- 提供简化的二维平面基础模型

    当多体模型都处于一个平面运动时，可以提供在二维平面中的简化接触元件，降低模型计算时的方程数量，提高简化工况时的计算效率。

- 提供通用的刚体接口

    在接触模型建模和使用时，模型接口为通用的刚体接口，和多体模型库有良好的兼容性，可以扩展多体库的使用范围。

- 适用多场景、多工况的建模与仿真

    该模型库包含的接触元件既可以支持在机械运动系统中，两物体间的接触检测，同时也可以支持机器人系统和机械制作领域可以分析接触过程中的摩擦力和接触力，支持在航空、航天领域进行连接件间的接触分析。

## 应用场景

- 支持接触分析和接触力计算功能
    
    针对两机械物体的相互接触，可以使用接触库中的典型元件进行接触状态判断和接触力计算，模拟两物体的接触运动。

- 设计优化元件接触特性

    针对不同类型的物体接触，可以设置不同的接触力和摩擦参数模拟不同的材料属性和接触力属性，针对机械系统的接触进行设计验证和分析优化，比较不同接触体形状和接触体材料对接触状态的影响。

- 针对接触现象的仿真案例

    教育和科研工作者可以使用机械模型库、接触模型库来进行机械系统的仿真实验和研究，从而加深对机械系统工作原理和特性的认识和理解。
