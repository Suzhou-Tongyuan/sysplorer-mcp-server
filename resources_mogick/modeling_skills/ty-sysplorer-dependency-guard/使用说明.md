# Sysplorer 模型库依赖保障使用说明（modelica_lite / mogick）

## 快速开始

当平台为 **modelica_lite / mols**，或 `load_library` 返回 `ok: false` /
`LoadLibrary returned False`（含无日志），或工具返回「模型库未安装」时，使用本 Skill。

**先分析，再安装：**

```text
load_library(action="plan", library_name="<library>")
```

显式库名且确认要安装：

```text
load_library(
  action="prepare",
  library_name="<library>",
  dry_run=false,
  download_missing=true,
  load_after_download=true,
  refresh_after_download=true
)
```

已有 `.mo` 文件场景：

```text
model_manager(
  action="load_file",
  file_path="<path>",
  prepare_dependencies=true,
  dependency_dry_run=false,
  download_missing_deps=true,
  refresh_libraries_after_download=true,
  load_dependencies_after_download=true
)
```

## modelica_lite 注意

- 本运行时通常**不预装**完整 Modelica / TY 商业 `.mol`。
- 静默 `LoadLibrary returned False` 也要走 `plan → prepare`，不要反复 `load_library(action="load")`。
- `load_library` 不是下载工具。
- `plan` 和 `dry_run=true` 不会安装模型库。
- 只有 `dry_run=false` 且 `download_missing=true` 才是真实下载/安装。
- 下载前必须经过可下载清单解析。
- 如果未启用 `--user-workspace`，MCP 不能执行真实下载/安装；仍应先 `plan` 把缺失项列清。
