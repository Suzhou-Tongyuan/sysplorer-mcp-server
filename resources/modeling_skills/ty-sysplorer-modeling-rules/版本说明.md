## 1.9.0 - 2026-09-09

1. 明确三个调试 Skill 独立触发，按修改对象引用建模约束，避免重复分流和流程重启。
2. 统一首次实时访问会话确认、有效会话复用及未知 API 调用前定向确认。

## 1.8.1 - 2026-08-27

1. 明确 Sysplorer 模型库的顶层和所有子 package 的 `package.mo` 均省略 `within`，禁止空路径和父路径形式的 `within` 子句，并保留普通类 `.mo` 文件按所属 package 填写 `within` 的规则。
2. 增加顶层包与子包的完整 `package.mo` 示例，两个示例均不使用 `within`。
3. 修正类声明描述字符串的分号规则，明确描述字符串属于类头、后面不得添加分号，并将检查同步到 Modelica 建模工作流、七道门验证和修改前自检。

## 1.8 - 2026-08-18

1. 根据 `modelica-model-help-template-simple.md`、`modelica-example-help-template(1).md` 和 `modelica-test-case-template-simple.md` 提取并启用组件/模型、示例/案例和测试用例说明三套内置模板。
2. 三套模板统一采用 `modelica-documentation-v1` 元数据、六段式文件结构、输出区间标记、中文占位符、GFM 表格及必需/可选字段约束。
3. 模板只保留各场景特有的信息字段、章节规则、图片槽位和一致性检查；通用事实、同步、HTML 与写回规则继续集中维护，符合渐进加载原则。
4. 测试用例模板将“观察结果”规范为“观察对象”，并继续禁止测试执行、测试报告、实际结果及 PASS/FAIL 结论。
5. 同步更新 Documentation 工作流、中文审核镜像、使用说明和结构化版本信息，三个模板状态均改为 `ready`。

## 1.7 - 2026-08-17

1. 新增独立的 Modelica Documentation 生成与同步更新能力入口，覆盖模型帮助、案例帮助和测试用例文字设计，并与普通建模及帮助问答路由隔离。
2. 新增 Documentation 内容规则和工作流，明确显式触发、模板优先级、真实 `.mo` 事实来源、局部同步、HTML 写回、一致性检查、图片降级及独立成败规则。
3. 建立三套内置默认模板的固定路径和人工待补状态；本版本不生成模板正文，也不创建测试报告或测试报告模板。
4. 同步更新运行时入口、中文审核镜像、使用说明、结构化元数据和 UI 元数据。
5. 补充 Modelica 组件/模型命名长度规则：英文类名默认不超过 15 个字符，类声明中的中文简短描述默认不超过 20 个可见字符；用户或项目明确规范优先，现有类不因此强制重命名。
