# Modelica 组件/模型帮助默认模板

## 1. 模板契约

- 适用于 Modelica `.mo` 基础组件或模型的帮助信息新建与同步更新。
- 只将“默认输出结构”区间生成的成品转换为 HTML；模板说明、规则、占位符和检查清单不得进入最终 `Documentation.info`。
- 通用触发、事实、同步、HTML 和写回规则遵循 `references/modelica-documentation-rules.md` 与 `workflows/modelica-documentation.md`。

## 2. 字段与事实来源

| 字段 | 必需性 | 事实来源与无证据处理 |
|---|---|---|
| 模型名称 | 必需 | 使用目标 `.mo` 中的准确类名，不按文件名或语义猜测。 |
| 功能简介 | 必需 | 基于类描述，并由实际接口、方程、算法、继承或公开类文档佐证。 |
| 工作原理 | 必需 | 基于核心数学/物理关系、方程、算法、连接或继承行为；无必要时不强制公式。 |
| 主要参数 | 存在时必需 | 读取实际参数名、绑定值/默认值、单位和说明；未显式设置时如实说明，不猜测。 |
| 主要接口 | 存在时必需 | 读取真实输入、输出或物理连接器及类型；条件接口同时记录启用条件。 |
| 使用说明 | 必需 | 基于真实连接方式、配置、参数关系、断言和使用前提。 |
| 初始化与特殊行为 | 存在时必需 | 读取初始化、初值、复位/重新赋值、条件端口、事件逻辑等实现。 |
| 注意事项 | 可选 | 仅写当前模型直接相关的限制、重要关系或易误用配置；无内容时省略。 |
| 已有帮助信息 | 更新时必需 | 用于局部同步并保留仍有效的人工内容。 |

## 4. 章节生成规则

| 章节 | 生成要求 | 省略条件 |
|---|---|---|
| 标题与功能简介 | 准确说明主要功能和用途。 | 不得省略。 |
| 工作原理 | 说明核心数学关系、物理关系或运行逻辑。 | 不得省略；证据不足时先报告缺口。 |
| 参数说明 | 只列用户需要关注且真实存在的主要参数。 | 没有可确认参数时省略整节。 |
| 接口说明 | 只列真实存在的主要接口，并注明条件接口启用条件。 | 没有接口时省略整节。 |
| 使用说明 | 说明连接/配置、关键参数关系和主要前提，不要求完整示例。 | 不得省略。 |
| 初始化与特殊行为 | 只描述实际存在的相关机制。 | 不存在相关机制时省略整节。 |
| 注意事项 | 只写有直接证据的重要限制或易误用点。 | 没有明确事项时省略整节。 |

## 5. 图片增强

| 槽位 | 插入位置 | 使用条件 |
|---|---|---|
| `overview-image` | 功能简介之后 | 可使用真实组件图标或模型结构图时添加，并提供替代文本、图注和来源。 |
| `result-image` | 工作原理之后 | 仅在存在与模型行为直接相关的真实结果图时添加，不用示意图冒充仿真结果。 |

图片不可用时省略槽位，以纯文字完成。

## 6. 专项一致性检查

- [ ] 模型名称与目标 `.mo` 类完全一致。
- [ ] 参数名、默认值/绑定值、单位和说明均可追溯。
- [ ] 接口真实存在，类型与条件启用逻辑正确。
- [ ] 工作原理能追溯到实际方程、算法、连接、继承或公开证据。
- [ ] 初始化、复位、事件和条件端口说明与实现一致。
- [ ] 图片、曲线和具体数值均有真实来源，未把未验证结果写成实际结果。
- [ ] 更新时只修改受影响内容，并保留仍有效的人工内容。
- [ ] 成品不含未替换占位符、模板指令或检查清单。
