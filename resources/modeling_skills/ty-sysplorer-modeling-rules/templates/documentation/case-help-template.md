# Modelica 示例/案例帮助默认模板

## 1. 模板契约

- 适用于 Modelica `.mo` Example、Demo 或系统案例的帮助信息新建与同步更新。
- 只将“默认输出结构”区间生成的成品转换为 HTML；模板说明、规则、占位符和检查清单不得进入最终 `Documentation.info`。
- 通用触发、事实、同步、HTML 和写回规则遵循 `references/modelica-documentation-rules.md` 与 `workflows/modelica-documentation.md`。

## 2. 字段与事实来源

| 字段 | 必需性 | 事实来源与无证据处理 |
|---|---|---|
| 案例名称 | 必需 | 使用目标 `.mo` 中的准确类名，不按文件名或用途猜测。 |
| 案例简介 | 必需 | 基于类描述、实际组成和当前案例用途，说明演示或验证的内容。 |
| 模型组成 | 必需 | 读取主要组件/子系统、关键连接及其作用，不罗列无助于理解的底层细节。 |
| 关键参数 | 存在时必需 | 只读取明显影响运行或结果的真实参数、设置值、单位和说明。 |
| 仿真设置 | 存在时必需 | 读取案例或实际运行配置中的仿真时间、输入、边界及其他必要条件；无证据时省略对应项。 |
| 运行与观察 | 必需 | 基于真实运行方式和实际存在的关键结果变量。 |
| 实际结果 | 可选 | 只使用真实仿真结果；未执行仿真时只说明建议观察变量，不写具体结果或趋势。 |
| 注意事项 | 可选 | 仅写当前案例直接相关的限制、参数关系、初始化要求或特殊条件。 |
| 已有帮助信息 | 更新时必需 | 用于局部同步并保留仍有效的人工内容。 |

## 4. 章节生成规则

| 章节 | 生成要求 | 省略条件 |
|---|---|---|
| 标题与案例简介 | 说明案例功能以及演示或验证目的。 | 不得省略。 |
| 模型组成 | 说明理解案例所需的主要组件/子系统、关键连接及作用。 | 不得省略；证据不足时先报告缺口。 |
| 关键参数 | 只列对运行或结果有明显影响的参数。 | 没有可确认关键参数时省略整节。 |
| 仿真设置 | 只保留真实且必要的设置项，不保留空占位项。 | 没有可确认设置时省略整节。 |
| 运行与结果 | 说明运行方式和观察变量；实际结果只在已有真实证据时生成。 | 章节不得省略；没有实际结果时省略结果描述。 |
| 注意事项 | 只写有直接证据的重要限制、关系或特殊条件。 | 没有明确事项时省略整节。 |

## 5. 图片增强

| 槽位 | 插入位置 | 使用条件 |
|---|---|---|
| `structure-image` | 模型组成之后 | 可取得真实案例结构图时添加，并提供替代文本、图注和来源。 |
| `result-image` | 运行与结果之后 | 仅在存在真实关键结果曲线时添加，不根据预期或推测生成结果图。 |

图片不可用时省略槽位，以纯文字完成。

## 6. 专项一致性检查

- [ ] 案例名称与目标 `.mo` 类完全一致。
- [ ] 模型组成、组件作用和关键连接来自当前实际案例。
- [ ] 关键参数、设置值和单位真实存在。
- [ ] 仿真设置来自当前案例或实际运行配置。
- [ ] 观察变量真实存在；未运行时未编写具体结果或趋势。
- [ ] 图片和曲线有真实来源，未把推测描述成实际仿真结果。
- [ ] 更新时只修改受影响内容，并保留仍有效的人工内容。
- [ ] 成品不含未替换占位符、模板指令或检查清单。
