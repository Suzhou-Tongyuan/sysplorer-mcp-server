# Modelica 测试用例说明默认模板

## 1. 模板契约

- 适用于 Modelica `.mo` 模型、组件或系统的测试用例文字设计新建与同步更新。
- 本模板只设计未来如何测试和判定，不执行测试、不生成测试报告，也不记录实际结果或 PASS/FAIL 结论。
- 只将“默认输出结构”区间生成的成品转换为 HTML；模板说明、规则、占位符和检查清单不得进入最终 `Documentation.info`。
- 通用触发、事实、同步、HTML 和写回规则遵循 `references/modelica-documentation-rules.md` 与 `workflows/modelica-documentation.md`。

## 2. 字段与事实来源

| 字段 | 必需性 | 事实来源与无证据处理 |
|---|---|---|
| 测试用例名称 | 必需 | 使用准确测试对象或用例名称，不按语义猜测。 |
| 测试说明 | 必需 | 基于目标对象、测试范围和需要验证的实际行为，不写执行结果。 |
| 测试目的 | 必需 | 来自真实模型功能、用户要求或已有规范。 |
| 测试条件 | 必需 | 读取参数、输入、初始/边界条件、仿真时间及必要设置；具体数值只能来自模型、用户要求或已有规范，缺失时使用符号条件或标记待确认，不自行选择代表性数值。 |
| 测试步骤 | 必需 | 基于可用模型与条件设计简洁、可执行、可复现的未来步骤。 |
| 观察对象 | 必需 | 只列实际存在且与目标直接相关的输出、状态、物理量、事件或状态变化。 |
| 预期结果 | 必需 | 来自方程、算法、初始化、理论依据、用户需求或现行规范；不得根据自行选择的测试输入生成具体预期数值。 |
| 判定标准 | 必需 | 使用用户要求、规范、理论/参考值或可证实行为；无依据时明确缺口，不创造容差。 |
| 注意事项 | 可选 | 仅写直接影响测试设计或结果解释的限制和特殊条件。 |
| 已有帮助信息 | 更新时必需 | 用于局部同步并保留仍有效的人工内容。 |

## 4. 章节生成规则

| 章节 | 生成要求 | 省略条件 |
|---|---|---|
| 标题、测试说明与目的 | 准确说明测试对象、范围和待验证功能/性能。 | 不得省略。 |
| 测试条件 | 只保留复现测试所需的核心参数、输入、初始/边界条件和仿真设置；缺少数值时使用符号条件或明确待确认项。 | 不得省略；证据不足时先报告缺口。 |
| 测试步骤 | 使用有序列表描述未来执行过程；“运行仿真”不代表已经执行。 | 不得省略。 |
| 观察对象 | 只列与测试目标直接相关且真实存在的变量、物理量、事件或状态。 | 不得省略。 |
| 预期结果 | 描述有依据的预期数值、趋势、状态或行为，不使用完成时态冒充实测结果。 | 不得省略；证据不足时先报告缺口。 |
| 判定标准 | 定义未来的通过/失败依据，不给出本次 PASS/FAIL；无数值依据时不创造阈值。 | 不得省略；依据不足时明确待确认项。 |
| 注意事项 | 只写与当前测试直接相关的重要限制或特殊条件。 | 没有明确事项时省略整节。 |

## 5. 图片增强

| 槽位 | 插入位置 | 使用条件 |
|---|---|---|
| 不适用 | 不适用 | 测试用例说明默认不依赖截图、模型图片或仿真曲线，不创建图片槽位。 |

## 6. 专项一致性检查

- [ ] 测试对象、测试说明和测试目的对应当前真实模型功能。
- [ ] 参数、输入、初值、边界和仿真条件均可追溯。
- [ ] 未自行选择无依据的测试输入、边界值、仿真时间或其他代表性数值。
- [ ] 观察对象真实存在，且与测试目标直接相关。
- [ ] 预期数值、趋势、状态或行为具有模型、理论、需求或规范依据。
- [ ] 未编造误差阈值、容差或其他判定数值。
- [ ] 未声称测试已经执行，未生成实际结果、测试状态、测试结论或 PASS/FAIL。
- [ ] 更新时只修改受影响内容，并保留仍有效的人工内容。
- [ ] 成品不含未替换占位符、模板指令或检查清单。
