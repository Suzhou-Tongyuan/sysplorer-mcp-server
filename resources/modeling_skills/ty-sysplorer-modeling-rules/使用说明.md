## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|---|---|
| **Skill 名称** | `ty-sysplorer-modeling-rules` |
| **Skill 中文名称** | Sysplorer 建模总规则 |
| **Skill 描述** | 用于处理具体的 Modelica 物理模型、商业库模型、Modelica 库与 Modelica+Sysblock 混合建模，并在用户明确要求时生成或同步 Modelica `Documentation(info=...)` 帮助信息。 |
| **版本信息** | `1.9.2` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 用户要求规划、评审、修改、执行验证或交付具体的 Modelica 物理、商业库、模型库或混合模型时触发。
- 用户要求物理 Modelica 顶层与 Sysblock 控制器/算法分层协同时触发。
- 用户明确要求为 Modelica 模型、Example/Demo 或测试对象生成、编写、更新或同步帮助信息时触发 Documentation 路径。
- 普通 Sysblock 框图或 StateMachine 任务直接使用 `ty-sysblock-diagram-modeling`；Sysblock 信号与通信任务直接使用 `ty-sysblock-signal-modeling`。
- 纯 API 查询、纯结果读取不触发；纯帮助问答优先由 `sysplorer-mds-docs` 处理，仅在其失败时使用本 Skill 的文档降级。
- 普通建模不自动触发文档生成；第一阶段不为 Sysblock 生成本文档体系。

---

已有模型的具体故障诊断/修复由独立调试入口主导：Modelica 使用 `ty-physical-model-debugging`，Sysblock 使用 `ty-sysblock-model-debugging`，未知或混合故障使用 `ty-sysplorer-debugging`。涉及物理修改和交付时按需引用本 Skill，不重启主流程。新建过程中的故障保持原任务上下文。

### 三、核心功能

- 区分计划、评审、修改/搭建、执行/验证和交付意图，控制验证深度。
- 路由标准库、自建、商业领域 Modelica 与 Modelica+Sysblock 混合建模；未指定库时标准库优先，不足时保留标准组件并商业补足。版本、子系统责任、MCP 0.4 调用和副作用以 references 内对应权威规则为准。
- 保留商业库公开文档、公开内省和最小黑盒验证边界。
- 协调 Modelica 物理顶层、Sysblock 子模型、下游领域 Skill 和 `modelica-library-workflow`。
- 在图形交付前执行适用的 Gate 6 布局与图面验收，并记录结构化证据。
- 处理 Modelica 模型帮助、案例帮助和测试用例文字设计的新建/同步更新，按模板读取真实 `.mo` 事实并写回 `Documentation(info=...)`。
- 支持用户提示词模板和 Markdown 模板；默认不导出独立 Markdown，不执行测试，不生成测试报告或 PASS/FAIL 结论。
- 三套内置默认模板均已就绪，统一使用 `modelica-documentation-v1` 元数据、字段事实表、输出区间、章节规则、图片增强和专项一致性检查结构。

---

### 四、维护导航

- `SKILL.md`：唯一运行时权威与按需加载入口。
- `SKILL_ZH.md`：中文阅读与审核镜像，应与 `SKILL.md` 保持语义一致。
- `版本说明.md`：版本和主要变更。
- `skill_info.json`：供维护工具读取的结构化定位。
- `references/` 和 `workflows/`：均由 `SKILL.md` 直接导航，不形成深层引用链。
- `templates/documentation/`：三套已就绪的内置默认模板；每次只按场景读取其中一份。
