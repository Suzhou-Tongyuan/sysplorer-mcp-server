# scripts 说明

## 目的

本目录用于放置 `modelica-library-workflow` 的高频辅助脚本，例如：

- `package.order` 一致性检查
- 顶层骨架完整性检查
- 交付输出项完整性检查

## 当前状态

当前 skill 暂无强依赖脚本，默认以 `references/` 中的工作流和检查清单作为主执行依据。

## 何时新增脚本

仅当某个检查动作同时满足以下条件时再新增脚本：

1. 被重复执行
2. 规则稳定
3. 手工执行成本明显高
4. 输出结果容易标准化

## 新增脚本的要求

- 脚本名应表达用途，不使用临时名。
- 新增脚本后，要同步回写本文件说明用途、输入、输出和触发时机。
- 脚本只能做辅助检查或生成，不得绕过本 skill 中已定义的结构与验证约束。
