# 中文化修订

## 适用场景

用户希望把模型库中的说明、文档、示例和测试入口统一成中文。

## 步骤

1. 复用 `references/shared-standards.md`，确认库级本地化范围；普通单模型的文字修订交回父级。
2. 区分用户可见文本和技术标识符，默认保留后者及公共接口。
3. 只修订请求的类说明、参数说明、文档和 Examples / Tests 说明；涉及已有文档时保留引用一致。
4. 按需查 `references/common-errors.md` 的中文化章节，不读取整个建库执行链。
5. 做文本、编码、链接与标识符静态检查；纯文案且未改图形对象时 Gate 6 为 `not_required`，不默认加载/检查/仿真。
6. 用 `references/input-output-contract.md` 说明覆盖范围和未覆盖范围，不自动新建成套文档。

## 模板优先级

优先级从高到低：

1. 现有中文文案规范
2. 已修订过的同类组件说明
3. 通用中文输出模板

## 输出重点

1. 本次中文化覆盖范围
2. 保留英文标识符的原因
3. 是否同步修订了示例、测试和文档入口
4. 剩余未统一项
