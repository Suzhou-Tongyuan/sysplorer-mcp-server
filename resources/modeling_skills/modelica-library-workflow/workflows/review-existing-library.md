# 评审现有模型库

## 适用场景

用户给了已有模型库，希望找出结构问题、缺口、错位项和整改顺序。

## 步骤

1. 复用 `references/shared-standards.md`，明确只读范围和关注问题；评审发现不授权自动修改。
2. 按需读 `references/workflow-checklist.md` 中受评对象的章节；已知异常才查 `references/common-errors.md`。
3. 检查实际请求的结构、公共接口、示例/测试、本地化或图面，不默认全库全层级验收。
4. 模板约定仅在库已采用该模板时适用；保留既有兼容结构与接口。
5. MCP 0.4 的 check/translate/simulate 可能自动布局写回，不能作为默认只读动作；没有获授权的验证副本或可控能力时只报告静态证据及未验证项。
6. 按严重度列出保留项、缺口、错位项和建议顺序，用验收清单及输出契约表达评审已完成。

## 模板优先级

优先级从高到低：

1. 现有真实库结构
2. 模板包结构方案
3. 通用检查清单

## 输出重点

1. 哪些结构值得保留
2. 哪些问题会阻塞后续扩展
3. 哪些问题只是文案层，哪些已经影响验证与交付
4. 首批整改顺序
