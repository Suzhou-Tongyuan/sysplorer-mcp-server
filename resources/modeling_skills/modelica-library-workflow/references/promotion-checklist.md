# 推广发布检查清单

## 1. 名称与元数据

- `agents/openai.yaml` 的 `display_name` 是否为“Modelica 模型库开发流程”
- `short_description` 是否清楚表达用途
- `default_prompt` 是否仍指向 `$modelica-library-workflow`
- `SKILL.md` 标题、说明与 `openai.yaml` 是否一致

## 2. 文案一致性

- 主技能是否为中文
- `references/` 是否为中文或以中文为主
- 是否还残留对外可见的英文说明、英文章节标题、英文交付话术

## 3. 结构完整性

- 是否保留最小必要文件：`SKILL.md`、`agents/openai.yaml`、必要的 `references/`
- 是否存在失效链接
- 是否存在重复规则或互相矛盾的规则

## 4. 内容可执行性

- 是否明确了适用任务
- 是否明确了不该怎么做，例如占位包名不能直接交付、图形模型必须补连线注解
- 是否明确了默认中文化策略
- 是否明确了输出结构和交付内容

## 5. 推广前测试

- 至少用真实任务做一次“新建模型库”测试
- 至少用真实任务做一次“评审已有模型库”测试
- 至少用真实任务做一次“中文化修订”测试
- 至少用真实任务做一次“图形视图连线修复”测试

## 6. 环境说明

- 若使用 `skill-creator` 自带脚本校验，确认本机 Python 环境可用
- 若校验脚本依赖缺失或受默认编码影响，至少进行一次人工校验，并在推广时提前说明
