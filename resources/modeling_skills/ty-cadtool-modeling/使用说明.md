# 使用说明

## 这个 Skill 做什么

把真实 **CAD 装配几何**（STEP/IGES/sldasm/CATProduct/ty3d）经 Sysplorer MCP 调用同元 **CAD 工具 Python API（CADToolbox）**，转换为 Sysplorer 中的 **Modelica 多体（TYMultibody）或流体油箱模型**，并走完“检查 → 生成 → 翻译 → 仿真 → 读结果 → 动画”的闭环。质量、惯量、质心由实体自动算出，拓扑由你在零件上放置的运动副决定。

## 什么时候触发

- 出现 CAD / STEP / IGES / 装配体 / sldasm / CATProduct / ty3d / 几何模型转多体 / CAD 工具 / CADToolbox / 油箱切片 / 肋板 / 流体端口 / 由三维模型生成仿真 等信号。

## 什么时候**不要**用

- 用户只用文字描述机构、**没有几何文件**，要从零手写 TYMultibody/TYMechanics 等库组件——那是 `ty-mechanical-modeling` 的活。本 skill 是**几何驱动**的。

## 快速开始

1. 确保 Sysplorer 就绪：`session_manager(action="ensure")`。
2. 用一次 `call_code(mode="run_sysplorer_api")` 导入并探查（脚本里先 `import mworks.sysplorer.CADToolbox as cadtool`）：
   - `cadtool.ImportCad(r"C:\work\xxx.step")` —— **绝对、纯 ASCII 路径**；
   - `cadtool.SwitchWorkbenchType(cadtool.CadWorkbenchType.MultiBody)`；
   - `RUN_SCRIPT_RESULT = cadtool.GetParts()` 看顶层零件，**据此命名**。
3. 再用 run_sysplorer_api 建元素（分组 → 运动副 → 驱动 → 标架/设计点/接触），其中务必有一个对 `"Ground"` 的固定副锚定世界。
4. `cadtool.CheckDesign()` 修问题；闭环平面机构记得切割铰。
5. `cadtool.SaveCadFiles()` → `cadtool.GenerateMoModel("", cadtool.ModelicaModelType.ModelMultiBody)`。可仿真顶层模型名为 `<包>.<模型>.<模型>_main`（如 `Default.crank_rocker_mechanism.crank_rocker_mechanism_main`），按包名与文件名拼接或用 `model_manager(action="get_components")` 查询。**注意：`cadtool.GetModels()` 返回的是 CAD 浏览器标识**（如 `Default.crank_rocker_mechanism.step`），供 `OpenModelInCadBrowser` 使用，而非仿真目标名。
6. 校验：MCP `check_model` → `translate_model` → `simulate_model` → `result_manager` / `plot_manager`（多体看动画）。

详细模板见 `templates/run-script-skeleton.md`，分步流程见 `workflows/`。

## 注意事项与常见坑

- **导入路径含中文/特殊字符会失败**——先拷到 ASCII 路径。
- **工作台不符会被拒绝**——建多体元素前 `SwitchWorkbenchType(MultiBody)`；**流体须在导入前**先切到 `...Fluid` 再 `ImportCad`。
- **官方五阶段心智模型**——多体：导入→分组→连接和驱动→生成→仿真；流体：导入(切流体台)→切片→端口/介质/重力→生成→仿真。盲操作时每阶段=用 API 复刻对应 UI 步骤（详见 `SKILL.md` 与 `workflows/`）。
- **商用 CAD 导入**（sldasm/CATProduct）会自动求解运动副，可能产生**红色未知运动副**，生成前必须 `ModifyUnknownConnector` 修正或删除，否则报错。
- **实体名不要臆造**：多体点分（`base.gear`、`base.Marker1`、`upperarm.Point1`），运动副/驱动用裸名（`Revolute1`）；流体用裸名（`Tank1`）。先 `Get*` 查询。
- **平面闭环分两种、用不同工具（勿混淆）**：①**过约束** → 优先靠分组干净让 `GenerateMoModel` 自动切割，兜底生成后用 `RevolutePlanarCut`；②**平面环仿真初始化失败**（CAD 精度 ~1e-6 < 求解 1e-10）→ 生成前用 `PlanarLoopConstraint`（**姿态统一，非切割**）。
- **切片是阻塞操作**，返回结果路径，期间勿发其他调用；湿面/孔/端口只能选平面。
- **赋值前先 `Get*Params` 查真实参数键**；球副/重力方向用 `"{a, b, c}"` 字符串。
- **硬禁项**：run_sysplorer_api 中绝不调用 `ClearAll`、`ChangeDirectory`、`Exit()`；CAD 工具函数文档用 `help(cadtool.x)`，**不要**用 `get_api_document`。
- **流体不支持迭代设计**；多体可用 `OpenModelInCadBrowser` 整体/局部迭代。
- 纯参数微调（不改几何/拓扑）通常无需重进工具，直接对生成模型 `set_model_param` 后重仿即可。
