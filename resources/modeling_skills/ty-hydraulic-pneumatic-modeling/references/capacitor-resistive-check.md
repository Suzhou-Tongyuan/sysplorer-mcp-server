# 容阻检查

本文件用于把 Sysplorer 26a 文档中的“容阻检查（Capacitor-Resistive Check）”落到液压/气动 skill 的执行闭环中。参考页面为 Sysplorer 本地文档 `DevelopingModels/CheckAndCompileModel/CapacitiorResistiveCheck.html`。

## 适用范围

- 自动容阻检查机制当前按官方文档适配 `TYHydraulics` 和 `TYHydraulicComponents`。
- `TYPneumatics`、`TYThermalHydraulics`、`TYThermalHydraulicComponents` 的手册同样要求遵守容阻相连原则；若工具未提供自动检查入口，按本文规则做人工拓扑复核。
- 自建液压接口若要参与自动检查，需要在端口注解中标记容阻性。

## 触发时机

遇到下列情况时读取本文件，并按下文任务授权选择静态复核或实时检查；触发条件本身不授予启动软件或修改模型的权限：

1. 新建或修复含泵、阀、管路、节流、容腔、蓄能器、油缸、油箱的 `TYHydraulics` / `TYHydraulicComponents` 模型。
2. `check_model`、翻译或仿真出现 NaN、发散、步长极小、压力异常偏高、预期动作下长期零流量等症状。
3. 修改了液压主回路拓扑、`UseVolumeA`、`UseVolumeB`、接口容腔、`Pipe_C`、`OilVolume*` 或同类容性/阻性组件。

## 容阻相连原则

1. 两个以上阻性件直接相连时，中间一般需要增加容性件，或只在其中一个相邻阻性元件上打开接口容腔。
2. 两个以上容性件直接相连时，中间一般需要增加阻性件。
3. 采用“打开接口容腔”的方式时，相连阻性元件之间只打开一个接口容腔；不要两侧同时打开造成过度容性连接。
4. 无容阻标识的自建端口不会参与自动容阻检查，不能把自动检查通过等同于自建接口已经物理合理。

常用修复候选（只读诊断仅提出建议，执行修改须在用户已授权范围内）：

- 在阻性元件之间插入 `Pipe_C`、`OilVolume*`、气腔或对应库中的容性件。
- 对具备 `UseVolumeA` / `UseVolumeB` 的元件，只打开当前连接集需要的一侧接口容腔。
- 在容性元件之间插入节流、阻尼、管阻、孔板或对应库中的阻性件。
- 对嵌套模型中的问题，定位子系统源码中的连接集；仅在授权实时修复时打开子系统并执行适用修复。

## 执行闭环

1. 先继承父级 Gate 1 的任务范围：区分离线文件任务、只读诊断和授权实时修复；明确是否允许实时访问、启动软件和修改目标。能力可用不等于获得这些授权，检查失败也不自动授予修复权限。
2. **离线文件任务：**仅根据获准读取的源码、已有索引/文档、介质与拓扑表，静态复核容阻连接、`UseVolume*` 和自建接口注解。若请求了文件修改，只实施该范围内的最小补丁并复核受影响源码；只读任务仅输出发现和修复建议。不得为本检查探测 MCP、启动或加载 Sysplorer、运行 `check_model`、官方容阻检查、翻译或仿真。
3. **只读诊断：**离线只读沿用第 2 项；仅在已授权实时访问时，通过 MCP 使用符合只读边界的查询或检查。先按父级 shared-standards 核对检查及其前置动作的写回副作用；不能保证目标只读时，使用已授权副本或退回静态复核并说明限制。不得执行“修复全部”、手工模型补丁或因检查失败修改参数/拓扑。
4. **授权实时修复：**在已授权会话和修改范围内，按父级完成路径、库、介质、拓扑表、图解语义及本次必需的 `check_model`。通过 MCP 查询官方容阻检查能力，核对其可调用接口后再使用；无入口时采用静态拓扑复核并记录限制。未获启动授权时，不能因当前会话不可用而自行启动。界面“主页 > 仿真 > 检查下拉菜单 > 容阻连接检查”仅为功能名称线索，不通过 computer use 操作。
5. 记录实际采用的检查方式、发现的连接集及其位置。工具标红、不能自动修复或位于嵌套模型内的项目，先定位根因；仅对已获修复授权的项目执行最小手工或自动修复。使用“修复全部”前确认其影响范围全部属于授权对象，否则使用定点修复；自动修复结果仍须源码/图面复核。
6. 修复后按原任务模式复核受影响阶段：离线修改只重做静态复核；授权实时修复才重跑本次必需的容阻检查和 `check_model`。翻译/仿真仅推进至父级约定终点，目标变量验证仅在结果范围内。图形对象有改动时完成适用 Gate 6，显式布局调用按父级条件执行。
7. 授权实时修复不符合预期时，在原授权目标内撤销本次变更；需要追溯自动修复步骤时，仅在获准工作目录日志中搜索 `MwCapresCheck`。

## 自建接口标识

自建液压接口要参与自动容阻检查时，在端口注解中添加 `__MWORKS(isCapacitive = ...)`：

```modelica
FluidPort_a port_A annotation(__MWORKS(isCapacitive = true));
FluidPort_a port_B annotation(__MWORKS(isCapacitive = false));
```

- `isCapacitive = true` 表示容性端口。
- `isCapacitive = false` 表示阻性端口。
- 未添加该标识时，端口视为非容性非阻性端口，不参与容阻性检查。

## 交付记录

当本检查被触发时，交付中补充：

- 本次任务模式、静态复核依据和已执行的检查方式；未运行自动检查时明确说明，不能把静态复核结论标为 Sysplorer 自动检查通过。
- 实际发现的连接集及主要位置、已授权并执行的修复或只读建议；没有实时检查时不编造工具错误集数量。
- 静态复核、自动容阻检查、`check_model` 和请求的后续验证分别记录状态；离线任务未要求的实时检查、翻译、仿真和目标变量项为 `not_required`。已要求但受权限/能力限制未执行的项记录 `blocked` 及具体限制。
