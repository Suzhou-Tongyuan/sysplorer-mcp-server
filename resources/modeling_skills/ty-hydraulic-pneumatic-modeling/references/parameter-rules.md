# 参数规则

本文件用于约束液压、热液压、气动任务的首轮必设参数、默认设置顺序和高风险参数。

## 参数设置顺序

1. 先设边界与介质。
2. 再设主设备和执行器。
3. 最后设控制、测量与可选修饰参数。

## 首轮必设参数

| 参数类别 | 适用对象 | 是否必设 | 默认来源 | 备注 |
|---|---|---|---|---|
| `medium package` | 液压 / 热液压 / 气动模型 | 是 | `TYOilMedia` / `TYGasMedia` | 介质未确认时不得假定已正确加载 |
| `source pressure / flow` | 压力源、流量源、气源 | 是 | 用户输入或工程假设 | 需要说明范围和单位 |
| `return / exhaust boundary` | 油箱、回油、排气、大气边界 | 是 | 回路闭合要求 | 缺失时常导致零流量或不动作 |
| `valve center type` | 4/3、3 位阀 | 条件必设 | 用户输入 | 未说明时必须标 `待确认` |
| `actuator geometry` | 缸径、杆径、行程、容腔参数 | 是 | 用户输入或模板默认 | 影响方向、速度和压力水平 |
| `load definition` | 机械负载、外力、阻尼、质量 | 是 | 用户输入 | 方向错误常导致结果反向 |
| `temperature / thermal boundary` | 热液压、热交换问题 | 条件必设 | 用户输入或工况设定 | 决定是否切换热液压库 |
| `InterfaceSwitch*` | 元件设计库 | 条件必设 | 手册和模板 | 不清楚边界含义时不要随意改值 |
| `useHeatPort` | 热耦合元件 | 条件必设 | 手册和模板 | 开关状态需解释原因 |

## 域别参数重点

### 液压

- 先确认 `TYOilMedia` 已正确选择。
- 先确认压力源、回油箱、溢流支路是否闭合。
- 阀类重点检查 `P / T / A / B` 端口语义。
- 液压缸重点检查腔体连接方向、初始位置和负载方向。

### 热液压

- 只要涉及温度、焓流、换热或热边界，就优先切到 `TYThermalHydraulics`。
- 明确热边界、入口温度、换热路径和 `useHeatPort`。
- 明确哪些变量需要同时看压力 / 流量和温度。

### 气动

- 先确认 `TYGasMedia` 已正确选择。
- 明确气源、排气路径和环境边界。
- 检查可压缩效应相关设置是否与目标工况一致。
- 气缸和阀类重点检查 `GasPort_*` 连接语义。

## 工程单位规则

- 参数表优先保留常见工程单位：`mm`、`ml`、`l/min`、`bar`。
- 如同时给出 SI 单位，必须说明换算关系。
- 不允许在同一参数表中混用单位却不说明。
- 换向阀 `Signal` 控制输入口的电流型命令必须先换算成 `mA` 数值后输入，电压型命令必须先换算成 `V` 数值后输入。
- 不得因其他参数声明或底层 SI 单位是 `A`，就把用户给出的 `40 mA` 自动折算成 `0.04` 后再作为换向阀 `Signal` 控制输入值；该场景下输入值必须是 `40`。
- 对三位换向阀的控制值，必须采用“左位负值、右位正值、中位 `0`”的符号约定；若项目采用相反极性，必须在输入资料或交付说明中显式写明。

## 默认值使用规则

1. 模板默认值只能作为首轮占位值，不能静默当成最终确认值。
2. 来自手册、样例或经验的默认值必须说明来源和适用前提。
3. 当默认值会明显影响性能判断时，必须标记为待确认而不是直接定值。
