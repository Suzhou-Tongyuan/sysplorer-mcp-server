# 模型库介绍

## 模型库概述

热流介质模型库V1.4.0作为产品货架体系中一款专业基础库，提供了多种热流系统中的常用介质，包括基于Helmholtz方程的介质、CoolProp介质、不可压缩流体介质和固体介质，同时支持用户同时调用TYMedia和Modelica.Media中的介质。该模型库主要应用于热流相关模型库对介质物性的调用，可计算工作介质在单相或两相状态下的物性参数，实现介质物性最大程度的复用，满足不同场景下热流系统的建模需求。

## 模型库目录

热流介质模型库TYMedia架构如**图****2****-1**所示，将介质模型按种类归类，提供了基于Helmholtz方程的介质库（Helmholtz）、CoolProp介质库（CoolProp）、不可压缩流体介质库（Incomprssible）和固体介质库（Solid），以及用户指南（UsersGuide）。此外，TYMedia库中还提供了多个介质调用与物性计算示例，供初学者练习参考，具体获取方式可参考模型库中的案例入口指南。

基于Helmholtz方程的介质库包含CO2、氮、氧等，以及R134a、R410a、R1234yf、R125等多种制冷剂介质。通过Helmholtz状态方程可以计算介质的各种热力学性质，如密度、比焓、比熵、比容、饱和状态参数等。

使用CoolProp库，用户可以通过输入流体的组分和状态参数，例如压力、温度和质量分数，来计算流体的各种热力学性质，例如密度、比热容、粘度、导热系数等，主要用于热力学模拟和工程计算中，广泛应用于能源、化工、制冷和空调等领域。

不可压缩流体介质库可计算铅铋合金、铅和铋的物性以及水溶液的基础属性。

固体介质库中包含常见固体介质，如不锈钢、石墨等，可计算固体介质的密度、定压比热和导热系数。

## 应用场景

介质物性计算

支持建立和模拟多种介质的物性参数计算，包括密度、粘度、比热、导热系数等，可以准确计算介质在不同状态下的物性值。

热流系统仿真计算

支持热流系统获取和设置介质的物理特性参数，比如密度、粘度、比热、导热系数等，对于热流系统的设计具有重要意义，可用于计算和仿真介质在系统中的流动和传热性能。

## 功能特点

应用本热流介质模型库，可以实现介质调用与物性计算。

热流介质模型库提供多种介质模型，包括基于Helmholtz方程的介质、CoolProp介质、不可压缩流体介质和固体介质。

热流介质模型库可以描述介质在不同热力学过程中的行为特征。

热流介质模型库可以模拟设备中流动与传热过程中的介质状态；

热流介质模型库可以配合其他专业库实现在能源、航空、船舶、综合能源等领域的应用。
