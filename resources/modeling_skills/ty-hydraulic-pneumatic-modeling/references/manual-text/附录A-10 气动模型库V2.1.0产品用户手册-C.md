| 定常流动和非定常流动 | 速度、压力和密度等状态量不随时间改变的流动称为**定常流动**。定常流动可表示为<br>流动状态随时间变化的流动称为**非定常流动**，通常流体的流动均为非定常流动。按照流动随时间变化的速率，非定常流动可分为三类：<br>流场变化速率极慢的流动<br>流场中任意一点的平均速度值随时间变化非常缓慢，此时可忽略加速度效应。该流动又可成为准定常流动，大容器中的液体从小口的出流过程就属于这种流动。准定常流动的每一瞬时都可认为服从定常流动的方程，时间效应只是以参量形式体现出来。<br>流场变化速率很快的流动<br>此时要考虑加速度效应，该流动和定常流动有本质区别，活塞式水泵所造成的流动就属于这一类。<br>流场变化速率极快的流动<br>此时流体的弹性力显得十分重要。瞬间关闭水管阀门时的水击现象就属于这一类。<br>除上述三种流动外，某些状态反复出现的流动，如流场各点的平均速度和压力随时间周期性变化的流动，也可认为是一种非定常流动。活塞泵和压气机进出口管道流就属于这类。 |
| 层流和紊流 | 当流体的速度、压力等物理参数随时间和空间的变化都很平滑时的流动称为**层流**。在这种流动中，流体微团的轨迹没有太大的不规则脉动，相临两流层之间的动量、热量和质量的输运均是由分子热运动引起的。<br>当流体的速度、压力等物理参数随时间和空间的变化都很不规则、很不平滑时的流动称为**紊流**，该流动中流体微团作随机运动。流体微团不仅有横向脉动，而且有相对于流体平均运动的反向运动，因而流体微团的运动轨迹非常紊乱，流体质点的运动随时间变化很快。其中动量、热量和质量的传递速率比层流高几个数量级。<br>流体的流动状态一般根据雷诺数来判断，对于内部流动和外部流动所对应的临界雷诺数不同，具体数值可参见《流体力学》。<br>式中：—流速；<br>—运动粘度；<br>—特征长度，对于圆管来说为管径。 |
| 可压缩流动和不可压缩流动 | 在压力作用下流体体积发生变化的流动称为**可压缩流动**，真实流动的流体存在不同程度的可压缩性。在流体力学中常用密度的变化来代替体积的变化。一般而言，液体的密度只是在很高的压力下才有微小的变化，所以可视为**不可压缩流动**，而气体的密度却很容易随压力变化而变。在空气动力学中，要根据气体流动的马赫数确定气体的密度的变化是否可忽略。<br>在本模型库中，考虑了流体的压缩性的影响，即均视为可压缩性流体。 |
| 静压 | **静压**是指物体在静止或者匀速直线运动时表面所受的压强。其单位为：bar。**静压**加上动压等于全压。这里所谓的“静”只是指流体宏观质点之间没有相对运动，达到了相对的平衡，至于流体作为一个整体则完全可以同刚体一样地运动。由于流体质点之间没有相对运动，流体内并不存在切向的剪切应力，因此流体内只有法向的压应力，即**静压**。 |

# 模型库介绍

## 模型库概述

气动模型库V2.1.0作为产品货架体系中一款专业基础库，主要内容包括压气机库、气动阀类、执行机构、管路、流阻、换热器、气动辅件、边界源和各种传感器等模型，该版本模型库在架构和内容上进行了一定程度升级优化，包括支持二次开发功能与新增压气机库和换热器库等升级内容。该库可用于航空航天、车辆船舶、工程机械等领域气动系统的设计、仿真及优化，能够为更多的气动系统设计和优化提供方案，同时满足用户在多层次多研发阶段的应用，为工程行业气动系统仿真提供强有力支撑。

## 模型库目录

气动模型库V2.1.0提供了复杂气动系统构成所需的零部件模型，根据设备功能划分，主要包括：压气机库（压气机、射流泵等）、气动阀库（压力控制阀、流量控制阀、方向控制阀）、执行机构库（气动缸）、气动管路库（容性管路、阻性管路等）、流阻库（弯管、三通管、渐缩管路和突变管路等）、换热器库（气液换热器、气体半热交换器）、气动辅件库（容腔、空气弹簧等）、边界源库和传感器库设备模型，采用搭积木和连线的模块化建模方式，易于快速实现气动部件的开发和复杂系统模型的仿真分析。此外，TYPneumatics库中还提供了多个气动系统模型案例，供初学者练习参考，具体获取方式可参考模型库中的案例入口指南。

## 应用场景

气动模型库是一个行业通用的基础专业模型库，适用于航天、航空、车辆、船舶以及能源等众多行业的多个研发阶段的应用。

气动系统的方案设计

在方案设计阶段，可用于选择合适的气动组件，包括压气机、阀门、气缸等，以满足系统的工作条件和性能要求，并进行组合、调整和优化，支撑系统功能和性能的初步验证评价，实现系统多方案优选分析。

- **气动****系统关键设备的快速选型**

气动系统进行设计选型时，首先明确系统的需求，并选择合适的气及执行机构，搭配恰当的气动模型进行系统搭建，在该过程中还需要考虑系统效率、环境适应性等问题，因此借助气动组件库可以有效的模拟该过程，节省实验投入的人力和物力，提高选型的效率。

气动系统的详细设计

在详细设计阶段，可用于确定气动系统中每个组件的具体规格和参数，包括气动管路管径和长度、阀门动态特性等，能够合理做出组件参数信息调整，模拟和评估各个组件参数调整对整个系统的影响程度，以辅助详细设计决策。

- **气动支撑与支架系统优化设计**

在气动支撑与支架系统中，通过选择气缸、比例阀、蓄能器等关键组件的规格参数，可精确模拟支撑系统在不同工况下的受力特性，尤其是动态载荷下的迟滞效应和缓冲需求，为结构强度设计提供理论依据。

气动系统的实验验证

在实验验证阶段，可用于性能验证、控制策略验证、故障模拟和故障诊断，以及参数调整和系统优化等应用场景，能够更加准确和有效地验证和调整气动系统，确保其性能和可靠性符合设计要求。

- **气动系统性能分析与优化**

支持对气动系统在不同工况下进行全面分析和模拟，确保其在预定工作条件下高效、稳定、可靠地运行。具体包括分析气动系统在不同负载、速度和压力变化下的响应特性，评估系统在动态负载和冲击载荷下的表现，分析瞬态响应特性，确保系统在启动、停机或负载波动时能够平稳过渡。此外，还可以分析气动系统在各种工作环境和外部条件下的性能，确保其在复杂工况下依然能稳定运行。

气动系统运行维护

在运维维护阶段，可用于搭建实时在线的数字化气动系统，进行运行状态监测和故障模拟，以帮助运维人员进行系统的日常维护和故障排除，保证系统的稳定运行和可靠性。

- **气动系统热交换过程分析**

支持对气动系统中的热交换、热流传递等过程进行详细分析，为故障诊断提供理论依据。例如，在气动执行器中，气流的压缩和膨胀过程会导致温度波动，通过热仿真模拟，可以预测执行器在不同工作条件下的温度变化，评估温度变化对执行器性能（如响应速度、输出力等）的影响，从而快速判断出故障出现的位置及原因。

## 功能特点

支持气缸、气阀、压气机等气动设备的准确模拟

- 模型库包含丰富的气动模型，支持多种常用气动设备的高精度模拟，如压气机、汽轮机、风扇、各类阀门、气缸、管路、流阻、换热器等。各个模型均基于精确的物理原理或实验数据进行建模，且经过验证和优化，能够准确地预测模型的行为和性能，提供可靠的仿真结果。

具备瞬态特性与动态响应模拟能力

- 支持准确模拟气动系统在短时间内的快速变化，如启动、停机及负载波动等情况，帮助分析系统在不同工况下的动态行为，评估系统在动态负载和快速操作中的稳定性与响应性能。

支持气动系统换热过程的模拟

- 模型库包含多种与换热器构建相关的组件，能够与热模型库紧密配合，构建不同类型的换热器系统。模型库中的部分组件设计了热接口，可以与外部环境进行热交换，全面分析气动系统在不同工况下的热管理效果，优化换热器设计，提高系统的热效率和性能表现。

支持多种气体介质选择

- 适配34种气体介质，包括空气、氨气、丁烷及二氧化碳等，调用气体物性数据，包括密度、定压比热容、定容比热容、热导数、动力粘度、运动粘度、比焓和比热率等。

# 注意事项

1. 介质调用和传递（Sysplorer2024a以上版本支持介质传递功能）

在进行系统模型搭建时，需要进行介质调用，使用气动模型库构建的系统中介质种类的选择在组件参数中进行，不需要实例化气体，但需要加载气体介质库，发布版气体模型库已绑定气体介质库。

介质种类可在任一组件中进行选择，然后通过接口传递至其它组件，因此相连的组件会选择相同的介质，而不相连的组件可以选择不同的介质。


图6-1介质传递说明

1. 建模规则

进行系统建模时，一般需要遵守阻容相连建模规则，如**图****6****-2**所示，两个以上阻性件相连，中间一般需要增加一个容性件；两个以上容性件相连，中间一般需要增加一个阻性件，可以减少系统的非线性、提高求解效率。



图6-2容阻连接规则
