# 常见错误与排查顺序

本文件用于液压、热液压、气动模型的高频故障排查。

| 现象 | 可能原因 | 优先排查顺序 | 修复建议 |
|---|---|---|---|
| 模型不动作 | 介质未选对、边界缺失、阀位不对、回路未闭合 | 介质 -> 边界 -> 阀口语义 -> 回路闭合 -> 负载方向 | 先补齐介质和边界，再确认阀与执行器方向 |
| 压力异常偏高 | 回油 / 排气路径堵塞、溢流支路缺失、阀口接反 | 回油 / 排气 -> 溢流支路 -> 阀口语义 -> 负载 | 恢复回路泄放路径，复核阀口方向 |
| 容阻检查失败或修复后仍不稳定 | 阻性件直连、容性件直连、接口容腔两侧同时打开或均未打开、自建端口缺容阻标识 | 容阻连接集 -> `UseVolumeA/B` -> `Pipe_C`/容腔/阻性件 -> 子系统 -> 自建端口注解 | 按 `references/capacitor-resistive-check.md` 选择离线复核、只读诊断或授权实时修复；仅修复已授权对象，并按原模式复验受影响的必需阶段，目标验证仅在请求范围内 |
| 流量长期为零 | 断线、边界缺失、阀未导通、源未真正驱动 | 连线 -> 边界 -> 阀状态 -> 源参数 | 先验证真实 `connect(...)` 和边界 |
| 位移方向相反 | A/B 腔接反、负载方向相反、命令极性错误 | 腔体连接 -> 负载方向 -> 控制极性 | 修正连接方向并重新验证变量符号 |
| 模型树里有元件，但图形层看不到模型 | 缺 `Placement`、实例未真正落图、`Diagram` 缺失、图层被写坏 | `Placement` -> `Diagram` -> 可见实例数 -> 图面闭环复核 | 不把“模型树有元件”当成完成，补齐图形实例化并复核图面 |
| 图面只有元件没有关键连线 | 缺 `Line` 注解、连线未落到图形层、路由被遮挡 | `Line` -> 可见连线数 -> 图层分离 -> 图面闭环复核 | 补齐关键连线图形注解并确认图中可见 |
| 图面没有连线 | 缺 `Line` 注解、缺 `Placement`、缺 `Diagram` | `Placement` -> `Line` -> `Diagram` | 补齐图面注解后重新复核 |
| 图面是红色虚线 / 悬空端点 | connector 锚点不稳、外露端口缺 `iconTransformation`、Line 异常 | connector 注解 -> `iconTransformation` -> `Line` | 对实例级 connector 注解补齐放置和锚点 |
| 图元拉伸变形 | `extent` 非等比缩放 | `extent` -> 旋转 -> 图面闭环复核 | 改为对称 `extent` 并复核图面 |
| 热液压结果没有温度变化 | 误用了普通液压库、热边界未设、`useHeatPort` 未启用 | 库选择 -> 热边界 -> `useHeatPort` | 切回热液压路径并补热边界 |
| 气动模型异常 | 气源 / 排气缺失、介质错误、可压缩边界不合理 | 气源 -> 排气 -> `TYGasMedia` -> 阀状态 | 先闭合气路边界，再核对介质与阀状态 |
| 编译或仿真失败 | 库依赖、Modelica 版本、接口类型、关键开关参数不匹配 | Sysplorer 状态 -> `Modelica 4.0.0.TY.1` -> 介质库 -> 接口类型 -> `InterfaceSwitch*` | 按手册依赖顺序复核并只修当前阻塞链路 |

## 总体排查纪律

1. 先查会导致完全失败的最短链路，再做样式优化。
2. 先查介质、边界、端口语义和回路闭合性，再查高阶控制逻辑。
3. 图面异常优先排查注解层，不先默认怀疑 `connect(...)` 无效。
4. 图形层不可见时，优先排查 `Placement`、`Line`、`Diagram` 并完成图面闭环复核，不把“模型树里有元件”当成完成依据。
5. 任何修复后都要回到父级闭环重新验证；若只改后处理，可只重跑结果读取和验证。
