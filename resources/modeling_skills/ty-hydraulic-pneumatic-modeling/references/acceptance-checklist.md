# 验收清单

以下各项按父级已选验收范围填写 `passed` / `failed` / `blocked` / `not_required`，不自动追加仿真、取值、图片或正式报告。

## 通用验收

- 已说明任务类型、目标系统和实际使用的 TY 库。
- 需要真实平台动作时记录当前实际会话版本与 MCP 分类证据；不为离线任务启动软件或为了“最新”而切换会话。商业组合的 Modelica 依赖固定为 `4.0.0.TY.1`。
- 已说明哪些动作通过 MCP 实际执行成功。
- 未把猜测值写成确认值。

## 模型与仿真验收

- `check` 已成功，或失败原因已明确说明。
- 若当前路径需要 `translate`，则 `translate` 已成功，或失败原因已明确说明。
- 请求仿真时记录成功或阻塞证据；未请求时为 `not_required`。
- 请求结果验证时，确认关键变量可读取；未请求则结果读取、KPI、曲线、动画均为 `not_required`。
- 结果验证属于范围时给出判断结论、数据来源及插值/端点回退 warning，不拿旧结果证明当前仿真成功。

## 图面验收

- 本次新建或实际修改图形目标时，按父级 Full Gate 6 完成结构化证据复核，图片按需求和能力补充；明确要求而未提供图片时记录缺口。只读、Documentation-only、纯代码无图形对象或图形未改时为 `not_required`，不展开未修改的继承层级。
- 对创建模型任务，关键元件已实例化并在图形界面中可见，用户可直观看到模型结构。
- 对创建模型任务，关键连线已在图形图面中可见，而不是只存在于文本或模型树中。
- 已检查 `Placement` 注解。
- 已检查 `Line` 注解。
- 已检查 `Diagram(coordinateSystem(...))` 注解。
- 已记录结构化证据：脚本、实例/连线数、坐标、锚点、路由及图形层状态；图片作为适用补充，未看图不声称目视检查。
- 已确认图形层正常显示；若未正常显示，已明确说明未闭环。
- 长标签没有遮挡阀、缸或关键端口。
- 没有关键断线、明显乱线或明显拉伸变形图元。

## 未闭环说明

- 若存在待确认参数，已明确列出。
- 若当前流程未闭环，已说明剩余阻塞点。
- 已提供下一步可执行建议。
