## Skill 简要介绍（能源系统建模调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-energy-modeling` |
| **Skill 中文名称** | TY 能源系统建模 |
| **Skill 描述** | 用于在 MWORKS / Sysplorer 中基于 TY 光伏发电库、风力发电库、电池库、综合能源系统库以及 `Modelica 4.0.0.TY.1` 完成能源系统模型的新建、修复、验证、翻译、仿真与结果复核。 |
| **版本信息** | `1.1.1` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 当用户明确要求使用 TY 光伏发电库、风力发电库、电池库、综合能源系统库或 `Modelica 4.0.0.TY.1` 完成能源系统建模时触发。
- 当任务明确限定必须在上述五个允许库范围内完成光伏、风电、储能、综合能源或跨域能源协调模型时触发。
- 适用于修复这五个允许库范围内模型的边界条件、连线、接口匹配、参数、单位、检查、翻译、仿真或结果读取问题。
- 适用于验证 TY 能源库官方样例、企业样例或用户已有模型，并输出关键变量与结论。
- 仅出现能源场景词不足以触发商业选型；父规则或有效上下文已选 TY 能源组件时使用本 Skill。未指定库先评估标准库，满足则标准库，不足则保留可用标准库并补足商业组件。
- 本 Skill 默认在已经应用 `ty-sysplorer-modeling-rules` 之后作为领域补充层使用。

---

### 三、核心功能

- 五库范围约束能源子系统；保留父规则项目总库集合中已选标准库及支持领域组件，按请求完成建模、修复与结果复核。
- 支持主能量路径、控制链、边界源、观测量、经济性或调度辅助模块的组件映射。
- 支持并网发电、储能充放电、热电联供、制氢储氢、多能耦合和跨域协调等典型场景。
- 支持初始化、参数、接口维度、单位一致性、连线拓扑、仿真发散和结果异常的修复。
- 支持图形化建模任务中的 GUI 可编辑性、连线可审阅性和图面闭环复核。
- 支持按需读取四个能源模型库用户手册，在精简参考不足时再查手册原文。

---

### 四、适用场景

- 使用 TY 光伏发电库搭建最大功率点跟踪、并网光伏或光伏故障分析模型。
- 使用 TY 风力发电库搭建 PMSG、DFIG、并网风电或 MPPT 控制相关模型。
- 使用 TY 电池库搭建 SOC 估计、CCCV 充电、热管理、能量效率或储能并网模型。
- 使用 TY 综合能源系统库搭建区域综合能源、氢能系统、CHP、锅炉制热或多能协同模型。
- 修复已有 TY 能源模型的边界缺失、连线错误、接口不匹配、参数缺失、翻译失败或仿真不收敛问题。
- 在交付前整理模型结构、组件映射、参数摘要、仿真设置、验证变量和已知限制。
