# Energy Typical Scenarios

Use these scenario families to orient modeling decisions quickly.

## Photovoltaic

- 光伏板故障模拟
- 光伏发电最大功率点跟踪
- 光伏并网发电系统

## Wind

- 直驱发电机 MPPT 控制
- 直驱发电机并网系统
- 双馈发电机并网系统

## Battery

- 电芯 SOC 状态估计
- 集中式电池包能量效率
- 离散电池包充放电循环
- 恒流恒压充电
- 冷却板冷却电池包

## Integrated Energy

- 区域综合能源系统
- 光伏-氢燃料电池热电联产系统
- 制氢储氢系统
- 锅炉制热系统
- 燃料电池 CHP 热回收系统

## Modeling Advice

- Start from the nearest scenario family when the request matches one of these examples closely.
- If the user asks for a hybrid system, map the dominant energy path first and then add the coupled subsystems one by one.
