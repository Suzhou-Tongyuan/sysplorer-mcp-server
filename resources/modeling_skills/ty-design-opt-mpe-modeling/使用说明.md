# ty-design-opt-mpe-modeling 使用说明

本技能用于 Sysplorer 参数估计工具箱 `DesignOptMpe` 的 Python API 辅助，并提供基于批量仿真的自定义优化路径。

## 适用任务

- 编写参数估计、标定、参数优化脚本。
- 处理多边界工况与稳态工况的参数估计。
- 使用统一残差层级计算多边界目标值。
- 借助 `DesignOptExp` 批量仿真评价大量候选参数。
- 接入 `lshade` / `basic-de` 之外的外置优化算法。
- 在模型依赖 `Modelica` 之外的库时完成依赖推导与加载。

## 两条执行路径

1. **原生 MPE 路径**：使用内置算法（默认 `Bobyqa`，另有 `Cobyla`、`GA`、`PSO`、`Praxis`），走标准实验配置与 `StartEstimate()`。
2. **自定义批量优化路径**：用 `InitialBatchSimulate` / `BatchSimulate` 批量评价候选参数，由 `lshade`（默认）或外置算法适配器驱动搜索。

需要自定义算法、高性能外部算法、混合策略，或内置算法受限时，走第 2 条路径。

第 2 条路径针对长时间优化提供两项保障：正式优化前先做配置预检（校验模型、参数范围、测量映射等，不启动仿真），以及优化过程中输出实时进度（当前阶段、当前最优残差、各边界残差与失败标记）。

## 关键默认值

- 默认自定义算法：`lshade`（兼容基线 `basic-de`）。
- 默认残差函数：`Mean Absolute Percentage Error`。
- 某组候选参数在必需边界上仿真失败时，该组结果按最差处理并直接淘汰，不影响其余候选的搜索。
- `lshade` 推荐配置：种群规模 `20`、最大迭代次数 `100`；长时间批量仿真推荐并行数 `10`。

## 与其他设计优化技能组合

五个设计优化技能可以搭配使用。常见方式是先用 `ty-design-opt-exp-gui-modeling` 生成实验设计或蒙特卡洛样本，再由 `ty-design-opt-exp-modeling` 执行批量仿真，结果可继续用于 PSA 敏感度分析、MRO 响应优化或本技能的参数估计与自定义优化。

## 安全约定

不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。如需卸载模型，使用 MCP 的 `model_manager(action="unload")`。
