# 自定义批量参数估计说明

## 1. 目标

该说明文档用于约束 skill 在“自定义算法 + 参数估计”场景下的默认实现方式。

核心目标：

- 支持高性能外部优化算法
- 统一单边界、多边界、稳态多边界
- 通过批量仿真加速候选参数评价
- 输出稳定、可解释的总残差

## 2. 默认执行框架

### 2.1 场景归一化

无论用户给出的场景是：

- 单边界
- 多边界
- 稳态单边界
- 稳态多边界

都统一转换为：

- 参数列表
- 边界列表
- 变量映射列表
- 测量数据容器
- 残差配置

### 2.2 虚拟边界

如果用户没有显式定义边界：

- 自动生成 1 个虚拟边界

这样后续算法、批量仿真和残差计算不需要再分支。

### 2.3 模型依赖库

用户提供模型文件后，先确认模型是否依赖 `Modelica` 之外的库。

- 用户给出依赖库时，将库名写入运行配置的 `scenario.extra_libraries`
- 用户未给出或不确定依赖库时，从模型文本和 Sysplorer 安装目录中的库名做自动推导
- 依赖库加载必须早于模型检查、模型翻译、短仿真检查和 `InitialBatchSimulate(...)`
- 缺库时 `CheckModel` / `TranslateModel` 可能阻塞，因此不要把它们作为第一层缺库探测手段

可选配置：

```json
{
  "scenario": {
    "extra_libraries": ["TAThermalSystem"],
    "auto_infer_libraries": true
  }
}
```

## 3. 批量仿真

推荐接口：

```python
import mworks.sysplorer.DesignOptExp as exp
```

流程：

1. `InitialBatchSimulate(...)`
2. 构造 `list[dict[paramName, value]]`
3. `BatchSimulate(...)`
4. 按候选参数与边界回组

展开规则：

- 设候选参数组为 `N`
- 边界数为 `B`
- 平铺后的批量仿真数为 `N * B`

## 4. 统一残差公式

### 4.1 单点偏差

`e(b,v,k) = sim(b,v,k) - measure(b,v,k)`

### 4.2 单变量残差

`R(b,v) = phi(e(b,v,k))`

`phi` 可为：

- `Mean Error`
- `Mean Absolute Error`
- `Mean Percentage Error`
- `Mean Absolute Percentage Error`
- `Mean Squared Error`

### 4.3 单边界残差

`B(b) = mean_v(R(b,v))`

说明：

- 该值只用于诊断边界拟合程度

### 4.4 总残差

`J = sum_b sum_v abs(w(b,v) * R(b,v))`

说明：

- 这才是优化器真正最小化的目标
- 不再对边界做额外加权平均
- 边界重要性通过变量权重体现

## 5. 稳态时间规则

稳态场景中：

- 应提供目标稳态时刻
- 若未设置，则默认使用参数估计结束时间
- 仿真结果没有该时刻时，必须插值
- 残差只对比该时间点

## 6. 失败惩罚

任意一个候选参数组只要出现：

- 边界仿真失败
- 缺少必需变量
- 无法完成插值
- 必要结果为空

则：

- 该组总残差直接赋值 `1e300`

## 7. 算法选择

### 7.1 支持算法

- `lshade`
- `basic-de`
- 外置算法适配器

### 7.2 当前默认优选

- `lshade`

### 7.3 兼容基线

- `basic-de`

### 7.4 外置算法适配器

当用户指定未内置算法时，不直接宣称可运行，而是先做适配性判断。

适配条件：

- 算法能优化越小越好的标量目标
- 候选解能表示为与待估参数顺序一致的数值向量
- 能处理有限上下界，或能通过变换/修复处理边界
- 能接受 Sysplorer 这种昂贵仿真评估
- 不强依赖解析梯度、Hessian、模型方程或可微性

接入方式：

1. 调研算法和可用实现
2. 判断适配性和预算风险
3. 编写本地 Python 适配器模块
4. 适配器只通过统一批量评估接口评价候选参数
5. 适配器输出 `algorithm`、`best`、`history`
6. 后续沿用统一批量仿真和残差计算流程

框架在调用外置适配器前会统一执行预检并完成一次参数初始值评估；适配器返回的历史记录必须保留该初始评估作为第一项。

对外说明时，只说“外置算法适配器”。内部入口名、配置字段名、回调名和实现类名只在用户明确要求生成配置或脚本时输出。

### 7.5 推荐长时间优化配置

使用 `lshade` 做正式优化时，推荐先采用：

- 种群规模：`20`（推荐值；未显式配置时由脚本按参数维数自动取值）
- 最大迭代次数：`100`（脚本默认值）
- 批量仿真并行数：`10`

其中种群规模、最大迭代次数和随机种子属于算法搜索配置；求解器、数值仿真容差、仿真时间和批量仿真并行数属于仿真执行配置。数值仿真容差用于每次模型仿真的求解器，不作为 `lshade` 的收敛退出条件。

## 8. 结果输出建议

每次自定义优化至少输出：

- 最优参数
- 总残差
- 每个边界的边界残差
- 每个变量的变量残差
- 仿真失败标记
- 算法名
- 算法配置
- 迭代摘要，第一条为参数初始值评估结果
- 进度日志，运行时逐条写出每个阶段的边界残差

## 9. 推荐脚本

- [`../scripts/custom_batch_optimizer.py`](../scripts/custom_batch_optimizer.py)

该脚本负责：

- 读取配置
- 执行预检模式
- 处理额外依赖库配置与自动推导
- 优化搜索前先评估参数初始值
- 自动选算法
- 加载本地 Python 优化算法适配器
- 调度批量仿真
- 计算统一残差
- 输出 JSON 结果和实时进度日志
