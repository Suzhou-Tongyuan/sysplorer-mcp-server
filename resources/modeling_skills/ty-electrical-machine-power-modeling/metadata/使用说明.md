# 使用说明

## 技能名称

- 英文名：`ty-electrical-machine-power-modeling`
- 中文名：TY 电气、电机与电力系统建模技能

## 触发条件

- 需要在 Sysplorer 中使用 `TYMotor`、`TYElectricPower`、`TYElectrical` 进行电机、电力系统、基础电气建模
- 需要复现 Simulink 模块或官方 `openExample`
- 需要交付可运行组件 package、测试、案例、对标结果或帮助文档输入材料

## 前置依赖

- 必须先使用 `ty-sysplorer-modeling-rules`
- 本技能只补充领域约束，不替代总规则技能

## 核心能力

- 库优先级约束
- 组件 package 与案例交付结构约束
- Simulink 对标与求解器策略
- 可执行交付门禁
- 帮助文档阶段衔接

## 非运行时说明

- 本文件仅供维护和人工查阅，不是 Codex 运行时执行指令
