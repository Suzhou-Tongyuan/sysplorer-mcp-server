# Package And Document

## Goal

在组件通过对标后，完成 package 清理、测试收口和帮助文档交付。

## Steps

1. 检查 package 文件是否齐全
2. 确认 `Tests` 至少 2 个
3. 确认参数面板与接口注释完整
4. 整理 `Resources` 中的对标数据
5. 生成误差报告
6. 读取 `references/help-doc-integration.md`
7. 调用 `$sysplorer-help-doc-writer`
8. 输出最终交付摘要

## Final Output

- 组件 package 路径
- tests 路径
- 对标报告
- 帮助文档路径
- 已知限制
