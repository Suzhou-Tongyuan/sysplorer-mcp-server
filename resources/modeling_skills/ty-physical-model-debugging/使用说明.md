# 物理模型调试 使用说明

版本：1.1.0。唯一运行时入口为 `SKILL.md`，中文审核见 `SKILL_ZH.md`。

独立诊断或修复已有 Modelica 物理模型的具体故障；只诊断不修改，物理修改和交付按需引用主规则。

无需先经过主分流 Skill；已知 Modelica/Sysblock 故障可直接进入对应专业调试。原任务为新建时，故障处理复用原上下文后继续建模。

用户只要求解释/定位原因时不打补丁，明确离线审查不运行模型。首次实时访问经 MCP 确认目标会话，同一有效会话复用。未知 API 在写前定向确认，不使用独立客户端直连。

修复仅修改核验后的任务自有副本；根据实际变更对象读取对应建模约束。静态/链接验收不强制完整仿真；用户未要求且故障验收不依赖结果时 KPI 为 `not_required`。结果异常必须核验相关行为。

`references/report-contract.md` 定义诊断与修复状态；`references/current-mcp-recipes.md` 定义调用、副本、设置和回滚。辅助脚本只处理文件：帮助查询、证据提取及工作区检查点。

`debug_workspace.py restore` 会预检全部备份；执行失败会返回补偿状态和保留的 `recovery_dir`，须检查每个文件，不能将失败补偿报告当成成功。它不保证进程崩溃时的跨文件事务。

产品安装/索引由对应集成流程负责。本仓库没有执行真实 MCP/Modelex 发现及模型修复验收，不据此承诺现场能力。
