# 版本说明

## v1.0.1 (2026-09-01)

- 错误码改为直接查询当前安装版本的 FAQ，不在 Skill 中固化产品错误正文。
- 支持 0 至 99 等低位错误码，并校验帮助正文与物理模型失败阶段是否一致。
- 区分产品诊断号、API 返回码与编译器/进程退出码。

## v1.0.0 (2026-08-27)

- 首次对外交付物理模型调试 Skill。
- 覆盖检查、翻译、初始化、状态选择、数值问题和有源码外部 C 故障。
- 增加当前安装版本帮助查询、工作副本、补偿回滚和深度证据预算。
- 限定自动修改边界，不把求解器参数对照当作模型修复。
