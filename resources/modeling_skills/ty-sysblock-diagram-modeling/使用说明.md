## Skill 简要介绍

`ty-sysblock-diagram-modeling` 用于在 Sysplorer 中通过官方 API 构建、修复、布局、审计和验证 Sysblock 框图及 StateMachine Chart。

已有模型的具体故障由独立的 `ty-sysblock-model-debugging` 主导，并按改动类型引用本 Skill 的约束。读取约束后保持原调试上下文，不重复分流或复现；普通 Sysblock 仍直接使用本 Skill。版本：1.3.1。

生产入口只有四个：

- `api_contract_resolver.py`：按准确名称解析 API 契约，降低试错；
- `layout_input_tool.py`：准备/审计无几何布局输入；
- `layout_plan_tool.py`：规划普通框图或状态机；
- `audit_sysblock_model.py`：审计最终保存模型和原始结构化证据。

使用时先读 `SKILL.md`，再按任务类型只读取它指向的一个或两个权威引用。普通建模不得运行 `tests/` 下的 skill 修订评测。

StateMachine 布线前必须先满足状态框投影重叠；不足时先平移或缩放/推移状态框，不能死磕角点连接。
