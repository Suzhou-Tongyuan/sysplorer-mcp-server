# ty-sysblock-batch-param-modeling 使用说明

本 Skill 用于指导 Sysplorer Python API 中模块整组参数对象的读取与整体回写，适用于 `GetModelParamValues` 和 `SetModelParamValues` 两个接口。

## 适用任务

- 一次性读取某个 Sysblock 模块的完整参数配置
- 修改多个参数字段后整体回写模块配置
- 在脚本、MCP 调用或外部桥接中传递 `dict`、JSON string 或 DataClass 参数对象
- 需要区分标准模块返回 `dict` 与复杂模块返回 DataClass 的场景
- 需要把模块参数对话框字段映射到批量参数对象 key 的场景

## 快速开始

```python
import mworks.sysplorer as ModelingPy

cfg = ModelingPy.GetModelParamValues("model1", "Gain1")
cfg["Gain"] = "10"
ok = ModelingPy.SetModelParamValues("model1", "Gain1", cfg)
print(ok)
```

复杂模块示例：

```python
import mworks.sysplorer as ModelingPy

cfg = ModelingPy.GetModelParamValues("model1", "CCaller1")
cfg.FunctionName = "calc_sum_diff"
cfg.SampleTime = "0.01"
ok = ModelingPy.SetModelParamValues("model1", "CCaller1", cfg)
print(ok)
```

LookupTable1D 示例：

```python
import copy
import mworks.sysplorer as ModelingPy

cfg = ModelingPy.GetModelParamValues("model1", "LookupTable1D1")
new_cfg = copy.deepcopy(cfg)
new_cfg["Table"] = "{1, 10, 7, 12, 16}"
new_cfg["BreakpointsForDimension1"] = "{5, 6, 7, 11, 30}"
new_cfg["InterpMethod"] = "线性点-斜率"
ok = ModelingPy.SetModelParamValues("model1", "LookupTable1D1", new_cfg)
print(ok)
```

BusCreator 示例：

```python
import copy
import mworks.sysplorer as ModelingPy

cfg = ModelingPy.GetModelParamValues("model1", "BusCreator1")
new_cfg = copy.deepcopy(cfg)
new_cfg["InputsNum"] = "4"
new_cfg["OutDataTypeStr"] = "inherit: auto"
new_cfg["ShowSignalNames"] = "true"
new_cfg["PortConfig"] = [
    {"Name": "signal1"},
    {"Name": "signal2"},
    {"Name": "signal3"},
    {"Name": "signal4"},
]
ok = ModelingPy.SetModelParamValues("model1", "BusCreator1", new_cfg)
print(ok)
```

## 与单参数接口的关系

- 单字段快速修改：继续使用 `SetModelParamValue(model, block, param, value)`
- 多字段联动修改：优先使用 `GetModelParamValues` + `SetModelParamValues`
- 局部查看字段：使用 `GetModelParamValues(..., fields=[...])`

## 输入输出约定

- `GetModelParamValues(modelName, component)`
  - 如果模块类型已在 `block_params.py` 的 `BLOCK_PARAM_CLASS_MAP` 中注册，则可能返回对应 DataClass
  - 其他标准模块统一返回 `dict`
- `GetModelParamValues(modelName, component, fields=[...])`
  - 固定返回筛选后的 `dict`
- `SetModelParamValues(modelName, component, params)`
  - 支持 `dict`
  - 支持 DataClass
  - 支持 JSON string

## 未补充模块的默认处理

- `GetModelParamValues` / `SetModelParamValues` 支持的模块参数说明会逐步补充，不要求一次覆盖全部模块。
- 如果某个模块还没有对应的批量参数专项说明，优先参考 `SetModelParamValue` 的单参数配置流程和现有参数说明文档。
- 在单参数流程里确认了参数名、界面含义和取值形式后，再映射回批量参数对象的 key。
- 对没有专项说明的模块，避免臆测隐藏字段；优先先读取完整对象，再基于已确认字段做最小修改。

## 注意事项

- `Utils/param_normalize.py` 仅负责内部归一化和编码保护，不作为外部 API 使用说明的一部分。
- DataClass 返回结构都定义在 `block_params.py` 中。
- 未注册模块不要按对象属性访问，应按 `dict` 处理。
- 回写 JSON string 时，字段名必须与底层配置 key 完全一致。
- 修改参数后如涉及模型行为变化，建议补做 `check_model` 或 `simulate_model` 验证。
- `LookupTable` 系列建议按具体模块类型读取对应参考文档，不要把 1D/2D/Dynamic/ND 字段混用。
- `LookupTableND` 这类对象规模较大的模块，建议始终先完整读取，再复制修改并整体回写。
- `BusCreator` 这类存在字段耦合的标准模块，也建议先读取完整对象，再整体回写。
- 如果模块尚无批量参数专项说明，默认回退到 `SetModelParamValue` 的参数说明流程。
- 模块参数专项说明统一维护在 `references/模块参数专项说明/` 目录下。
