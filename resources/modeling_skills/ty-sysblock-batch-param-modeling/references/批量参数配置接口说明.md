# 批量参数配置接口说明

本文档说明新增公开接口 `GetModelParamValues` 与 `SetModelParamValues` 的推荐用法。

## 1. 接口定位

- `GetModelParamValues`：读取指定模块的完整参数配置对象。
- `SetModelParamValues`：整体提交指定模块的参数配置对象。
- 与现有 `GetModelParamValue` / `SetModelParamValue` 的区别：
  - 旧接口面向单个参数字段
  - 新接口面向整个模块配置对象或一组字段

## 2. GetModelParamValues

### 2.1 完整读取

```python
cfg = ModelingPy.GetModelParamValues("model1", "Gain1")
```

返回规则：

- 只有当该模块的数据结构已定义在 `block_params.py` 且已注册到 `BLOCK_PARAM_CLASS_MAP` 时，才返回 DataClass
- 其他模块统一返回 `dict`
- 读取失败：返回 `None`

### 2.2 局部字段读取

```python
cfg = ModelingPy.GetModelParamValues(
    "model1",
    "CCaller1",
    fields=["FunctionName", "SampleTime"],
)
```

此时返回值固定为 `dict`，例如：

```python
{
    "FunctionName": "calc_sum",
    "SampleTime": "0.01"
}
```

## 3. SetModelParamValues

### 3.1 dict 输入

```python
ok = ModelingPy.SetModelParamValues(
    "model1",
    "Gain1",
    {"Gain": "10", "SampleTime": "-1"},
)
```

### 3.2 DataClass 输入

```python
cfg = ModelingPy.GetModelParamValues("model1", "CCaller1")
cfg.FunctionName = "calc_sum_diff"
cfg.SampleTime = "0.01"
ok = ModelingPy.SetModelParamValues("model1", "CCaller1", cfg)
```

### 3.3 JSON string 输入

```python
ok = ModelingPy.SetModelParamValues(
    "model1",
    "Gain1",
    "{\"Gain\": \"10\"}"
)
```

## 4. 推荐调用顺序

1. 加载并打开模型
2. 先读取当前配置对象
3. 只改需要变更的字段
4. 整体回写
5. 需要时补充检查或仿真

## 5. 适用场景

- CCaller 一类复杂模块的完整配置编辑
- MCP 外部系统传递 JSON 配置并写回模块
- 前后端或脚本工具需要保留参数对象结构时
- 多字段参数联动修改，而不是逐字段独立提交时
