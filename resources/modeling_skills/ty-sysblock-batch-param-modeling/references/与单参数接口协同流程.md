# 与单参数接口协同流程

新增批量参数对象接口并不替代现有单参数接口，而是补齐“整组配置读写”的能力。

## 1. 选择原则

- 只改一个参数：优先 `SetModelParamValue`
- 只读一个参数：优先 `GetModelParamValue`
- 需要模块完整配置上下文：优先 `GetModelParamValues`
- 需要一次性提交多字段：优先 `SetModelParamValues`

## 2. 推荐协同方式

### 方式 A：先整组读取，再局部改写，再整组提交

```python
cfg = ModelingPy.GetModelParamValues("model1", "Gain1")
cfg["Gain"] = "10"
cfg["SampleTime"] = "-1"
ModelingPy.SetModelParamValues("model1", "Gain1", cfg)
```

适合字段之间存在联动关系，或调用方需要保留完整对象状态。

### 方式 B：先整组查看结构，再回到单参数接口精修

```python
cfg = ModelingPy.GetModelParamValues("model1", "Gain1")
print(cfg)
ModelingPy.SetModelParamValue("model1", "Gain1", "Gain", "10")
```

适合排查字段名、熟悉模块参数布局后，再做少量精确修改。

### 方式 C：只读取部分字段，避免获取整包对象

```python
partial_cfg = ModelingPy.GetModelParamValues(
    "model1",
    "CCaller1",
    fields=["FunctionName", "SampleTime"],
)
```

适合状态探测、UI 展示或轻量查询。

## 3. 常见注意事项

- 单参数接口的值通常是字符串表达式。
- 批量接口的提交虽然支持多种 Python 形态，但底层仍会统一归一化后再发送。
- 当模块配置较复杂时，优先保留“先读后改再写”的模式，减少字段遗漏风险。
