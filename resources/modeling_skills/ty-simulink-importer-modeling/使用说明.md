# ty-simulink-importer-modeling 使用说明

本技能用于 Sysplorer Simulink 模型导入工具箱 `SimulinkImporter` 的 Python API 辅助。

## 适用任务

- 编写 Simulink 模型导入脚本。
- 启停 Simulink 导入工具。
- 导入 `.slx` 文件（R2017b–R2024b）为 Sysblock 模型。
- 配置 Link 子系统模型库路径。
- 导入 `.slxdata` 数据文件。

- `SKILL.md`：面向 Codex/MCP 的技能入口。
- `SKILL_ZH.md`：中文概览。

## 参考源码

- `simulink_importer_api_demo.py`：官方 Demo 脚本（引用模型 + 主模型批量导入）。

## 安全约定

不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。如需卸载模型，使用 MCP 的 `model_manager(action="unload")`。
