# 版本说明

## 1.0.0

- 新增 `ty-simulink-importer-modeling` 技能目录。
- 根据 `SimulinkImporter.py` 源码签名整理 API（`OpenSimulinkImporter`、`CloseSimulinkImporter`、`ImportSimulinkModel`、`ListFunctions`）。
- 根据《Simulink模型导入工具 Python API说明.md》整理接口规范和示例。
- 根据 `simulink_importer_api_demo.py` 补充"引用模型+主模型"导入模式、`LoadLibrary("SysplorerEmbeddedCoder")` 前置依赖。
- 标注所有路径参数仅支持绝对路径，`LibraryPath` 多个路径以分号（`;`）分隔。
- 明确调用顺序约束：`LoadLibrary` → `OpenSimulinkImporter` → 引用模型 → 主模型 → `CloseSimulinkImporter`。
- 说明 `ImportSimulinkModel` 支持位置参数和关键字参数混合传参。
