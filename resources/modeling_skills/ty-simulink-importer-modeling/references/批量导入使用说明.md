# 批量导入使用说明

本文面向通过 Python API 使用 `mworks.sysplorer.SimulinkImporter` 的场景。

## 基本导入

```python
import mworks.sysplorer.SimulinkImporter as slxImporter
```

SimulinkImporter 是独立工具箱模块，不能假设函数存在于主 `mworks.sysplorer` 命名空间中。

## 推荐流程

1. 启动或连接 Sysplorer。
2. 预加载 Sysblock 建模库。

```python
import mworks.sysplorer as eng
eng.LoadLibrary("SysplorerEmbeddedCoder")
```

3. 打开导入工具。

```python
slxImporter.OpenSimulinkImporter()
```

4. 导入引用/子模型（含 Link 子系统）。

```python
slxImporter.ImportSimulinkModel(
    SimulinkFilePath="C:/path/to/referenced_model.slx",
    LibraryPath="C:/path/to/custom_libs",
    OpenReport=False,
)
```

5. 导入主模型（含数据文件）。

```python
slxImporter.ImportSimulinkModel(
    SimulinkFilePath="C:/path/to/main_model.slx",
    ExportPath="C:/path/to/output/",
    LibraryPath="C:/path/to/custom_libs",
    DataFilePath="C:/path/to/SimulinkImport_main_model_Data.slxdata",
    ClearBaseWorkSpace=True,
    OpenReport=False,
)
```

6. 关闭导入工具。

```python
slxImporter.CloseSimulinkImporter()
```

## 参数说明

| 参数 | 说明 |
|---|---|
| `SimulinkFilePath` | 必填，`.slx` 文件的绝对路径 |
| `ExportPath` | 生成 Sysblock 模型的路径；空时使用 Sysplorer 工作路径 |
| `LibraryPath` | Link 子系统库文件夹，多个以 `;` 分隔；空时不导入 Link 子系统 |
| `DataFilePath` | `.slxdata` 数据文件绝对路径；空时不导入数据 |
| `ClearBaseWorkSpace` | 导入前是否清空基础工作区，默认 `True` |
| `OpenReport` | 导入后是否自动打开报告，默认 `True` |

## 导入顺序说明

- **引用模型（含 Link 子系统）必须先于主模型导入**。主模型引用了子模型时，需确保子模型在工作区中已存在。
- 批量导入多个独立模型时，顺序无要求。

## 注意事项

- **所有路径参数仅支持绝对路径**。
- 调用 `ImportSimulinkModel` 前必须先调用 `OpenSimulinkImporter`。
- 支持的 Simulink 版本：R2017b–R2024b。
- 导入成功后，生成的 Sysblock 模型会自动在 MWORKS.Sysplorer 中加载。
- 完成所有导入后应调用 `CloseSimulinkImporter` 释放资源。
- `LibraryPath` 使用分号（`;`）分隔多个文件夹，`ExportPath` 和 `DataFilePath` 为单个路径。
- 预加载 `SysplorerEmbeddedCoder` 可确保导入后的 Sysblock 模型正常使用。
- MCP 环境中禁止 `ClearAll`、`Exit`、`StartSysplorer`（由 `session_manager` 管理）。
