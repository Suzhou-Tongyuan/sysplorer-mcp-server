## 一、强化 Sysplorer / Syslab MCP 工具边界

请在 Agent 系统提示或 MCP 工具使用文档中补充说明：

1. Sysplorer MCP 用于图形建模、创建模型、添加组件、连线、设置参数、Check、Translate、Simulate。
2. Syslab MCP 用于脚本运行、算法验证、数据处理、M 语言 / Julia / Python 类任务，不应用于 Sysplorer 图形建模。
3. 建模任务中禁止混用 Syslab 和 Sysplorer 工具，除非任务明确涉及脚本算法验证。
4. 禁止把 Syslab 报错处理方式套用到 Sysplorer API 建模。

## 二、补充 Sysplorer API 正确调用规范

请在现有 MCP 工具文档或新增 `reference/sysplorer_api_usage.md` 中补充以下内容：

1. `NewModel` 创建普通模型时，`restriction` 使用默认值 `"model"`，不要随意传入 `"block"`、`"package"` 等。
2. `AddComponent` 使用组件类型路径、实例名、位置等必要参数，不要把 `annotation` 作为 API 参数传入。
3. 组件参数设置建议优先通过直接写 `.mo` 文件的方式内联到组件声明中，例如：

```modelica
NPSLibrary.xxx.Component comp1(parameterA = 1, parameterB = 2)
  annotation(Placement(transformation(origin={0,0}, extent={{-10,-10},{10,10}})));
```

4. 对复杂 annotation、Diagram、Icon、Placement、参数面板等内容，优先通过生成或修改 `.mo` 文件完成，不建议反复调用参数设置 API。

## 三、为 NPSLibrary 建立高频组件快速索引

请新增文件：

```text
reference/nps_component_quick_index.md
```

该文件用于建立 NPSLibrary 高频组件检索路径索引，减少 Agent 逐层查询库文档的开销。索引内容请按照以下路径整理：

### 1. 接地与参考点组件

接地组件优先使用 Modelica 标准库：

```modelica
Modelica.Electrical.Analog.Basic.Ground
```

如果三相系统缺少中性点接地，可以使用：

```modelica
Modelica.Electrical.Polyphase.Basic.Star
```

说明：

* NPSLibrary 中如果找不到 Ground，不要反复搜索。
* 单相或直流参考点优先使用 `Modelica.Electrical.Analog.Basic.Ground`。
* 三相系统需要中性点时，优先使用 `Modelica.Electrical.Polyphase.Basic.Star` 汇集三相中性点后接地。
* 如果接口不兼容，不要强行连接，应提示需要适配组件或人工确认。

### 3. 使用规则

请在索引文件中明确：

1. 高频组件优先查 `reference/nps_component_quick_index.md`。
2. 快速索引能命中时，不要从 NPSLibrary 根目录逐层遍历。
3. 只有索引路径不足以确定具体模型时，才调用 `get_lib_model_document` 查询具体组件文档。
4. 对同一类别组件，优先批量查询，不要多次单点查询。
5. 对语义相近的组件检索结果进行合并，例如“电压源”“三相电压源”“AC voltage source”不要重复展开。
6. 对同一路径不要重复调用 `get_lib_model_document`。
7. 单个建模任务中，除非确有必要，应控制深度遍历和重复文档查询次数。

## 四、建立 Ground 等缺失组件的降级策略

请新增或更新：

```text
reference/component_fallback_strategy.md
```

该文件用于说明 NPSLibrary 中缺失常见基础组件时的降级策略，重点包括 Ground、Reference、ElectricalReference、Neutral、Terminal 等参考点组件。

请写入以下规则：

1. 如果 NPSLibrary 中找不到 Ground，不要反复搜索。
2. 单相或直流系统接地优先使用：

```modelica
Modelica.Electrical.Analog.Basic.Ground
```

3. 三相系统如果缺少中性点接地，可以使用：

```modelica
Modelica.Electrical.Polyphase.Basic.Star
```

将三相连接到 Star 后，再使用 Ground 接参考点。

4. 如果 NPS 接口和 Modelica 标准库接口不兼容，不要强行连接，应采取以下策略：

   * 优先寻找 NPSLibrary 内部等效参考点组件；
   * 其次考虑同库适配组件；
   * 仍无法连接时，提示需要人工确认接口适配方式。
5. Ground、Reference、ElectricalReference、Neutral、Terminal 等常见参考点组件最多搜索 2 次；仍找不到时触发降级策略。
6. 对库中缺失的常见基础组件，应优先参考 fallback 文档，而不是继续逐层遍历库。

## 五、补充 NPSLibrary 示例案例检索路径

请在 Agent 提示词、README、SKILL.md 或新增参考文件中补充 NPSLibrary 示例模型的检索路径。

NPSLibrary 案例检索路径位于软件安装目录下，一般情况下为：
```text
Sysplorer 2026a\Docs\EleLib\Samples\NPSLibrary
```

请明确以下规则：

1. 当用户要求“参考已有案例”“查找 NPS 示例模型”“基于案例搭建模型”“参考官方样例”时，优先检索该路径。
2. 高频案例不要通过库模型文档深度遍历查找，应优先从 Samples 路径检索。
3. 如果任务是电力系统、变压器、线路、负荷、电力电子、新能源、电机等 NPSLibrary 相关建模，应优先考虑该 Samples 路径中是否存在可复用案例。
4. 检索案例时应先根据场景关键词过滤，例如：

   * Line / Transmission / Distribution；
   * Transformer；
   * Load / RLC / ConstantPowerLoad；
   * PowerElectronics / Rectifier / Inverter / PWM；
   * RenewableEnergy / PV / Battery；
   * Motors / Synchronous / Asynchronous / Wind。
5. 找到案例后，应优先复用其组件路径、参数写法、连线方式和 annotation 风格，而不是重新从零搜索库组件。
6. 如果案例路径不存在或未配置，应提示用户确认 Sysplorer 安装路径，而不是继续无目的检索。
