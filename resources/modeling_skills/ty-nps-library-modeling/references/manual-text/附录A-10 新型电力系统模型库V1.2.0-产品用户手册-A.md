# 模型库介绍

## 模型库概述

新型电力系统模型库V1.2.0作为产品货架体系中一款专业基础库，包括电力电子库、基础组件、电机库、电力系统库等组件模型。该版本模型库在架构和内容上进行了一定程度升级优化，包括适配同元标准库Modelica4.0.0.TY.1，完善模型文档浏览器内容及优化部分模型等。该库可应用于电气系统、电机系统、电力电子系统的设计、验证、与优化，用户可根据实际需求搭建所需的系统模型，应用于复杂电气系统快速设计与仿真验证、电机控制策略的开发、电力系统电磁暂态分析等。

## 模型库目录

电力电子库面向电力电子系统的主电路与控制建模，集成升降压变换器、整流器、逆变器等变换器拓扑以及 PWM 发生器等控制组件，并提供二极管、IGBT、晶闸管等半导体器件模型，其特殊性在于开关动作，对步长、采样周期、死区与测量滤波等设置较为敏感，适合用于变换与并网接口等场景的细节分析与控制验证。

电机库用于建立电机及其机电耦合系统模型，包含永磁同步电机与基础同步电机、三相/单相异步电机以及风力发电机等模型，其特殊性在于电磁—机械—控制之间存在紧密耦合，且涉及坐标变换、转差与启动过程等动态特性，对初始转速、负载转矩与控制参数匹配要求较高，适合电驱、拖动与风电发电链路的系统级仿真。

电力系统库侧重于电网一次设备与系统级对象的建模，覆盖可再生能源（光伏、储能如电池与超级电容等）、发电控制（励磁系统、PSS、调速器等）、输配电设备（断路器、传输线、变压器等）、负载模型（RLC 串并联负载、恒功率负载等）、控制与保护（单相/三相锁相环等）以及故障与辅助设备（如三相故障等），其特殊性在于模型规模大、运行工况多（稳态/暂态/故障），需要兼顾网络参数、控制策略与保护逻辑的协调，适用于并网稳定性、故障穿越与潮流分配等综合研究。

电源库提供三相电源、直流电源等基础供能器件，用于构建电网侧或直流母线侧的边界条件，其特殊性在于电源幅值、频率、相位以及等特性会直接影响并网控制效果，因此能够支持多种电气系统的电源输入。

公用组件库提供 PI 积分器、控制器、坐标变换等可复用的通用功能模块，用于支撑各类控制与信号处理的快速搭建，其特殊性在于这些模块跨多个子系统复用频繁，增益整定、限幅与抗饱和等细节会显著影响控制稳定性与动态响应，是构建可靠控制链路的基础“积木”。

传感器库提供单相与三相电压/电流传感器等测量模块，用于从一次系统中提取观测量并输出给控制与保护环节，其特殊性在于测量量的定义方式（瞬时值、RMS、相量等）以及必要的滤波与采样策略会影响控制环的实时性与准确性，特别是在含电力电子开关的模型中更需要合理处理纹波与噪声对控制判断的干扰。

## 应用场景

电气系统的方案设计

在方案设计阶段，可用于选择合适的电气组件，包括电源、负载、电机、线路、变换器等，以满足系统的工作条件和性能要求，并进行组合、调整和优化，支撑系统功能和性能的初步验证评价，实现系统多方案优选分析。

- 典型电路设计的快速验证

电路或电力系统在进行搭建前需要根据需求进行工况的分析，并初步拟定电路拓扑，包括基本电路的设计，如负载电路、变换电路等以及控制回路的设计，如电机驱动、变换器控制。为了能够更高效准确的对电路进行设计，可使用新型电力系统模型库进行系统化、模块化的设计方法，支撑系统功能及性能的初步验证，确保系统设计合理、运行高效。

- 电气系统关键设备的快速选型

电气系统进行设计选型时，首先明确系统的需求，并选择合适的电源及电路组件，搭配恰当的负载模型进行系统搭建，因此借助新型电力系统模型库可以有效的模拟该过程，节省实验投入的人力和物力，提高选型的效率。

电气系统的详细设计

在详细设计阶段，基于NPSLibrary可进一步确定电气系统各组成部分的具体规格与参数设置，包括电源侧边界条件、输配电网络参数、负载特性以及电力电子开关与控制策略等。通过在模型库中选取合适模型进行系统搭建，并结合 潮流分析工具完成稳态工作点与初始化配置，可在参数层面对关键部件进行迭代调整，评估如线路阻抗、变压器接线方式、控制器增益、PWM 频率与死区、半导体器件特性等变化对系统电压稳定、功率分配、故障响应与动态性能的影响，从而为详细设计提供量化依据并降低设计风险。

- 电力电子变换与控制参数设计

电力电子主电路与控制参数直接决定系统效率、纹波水平、动态响应与稳定裕度，因此可利用电力电子库中的变换器模型（升降压、整流、逆变等）与控制组件（PWM 等）建立电源变换环节，并结合半导体器件模型对开关特性进行配置，通过调整开关频率、滤波器参数、控制器增益、限幅与抗饱和策略等开展仿真对比，验证在不同工况下的安全性与可靠性，最终形成满足指标的参数组合。

- 电力系统网络与设备配置设计

在系统级配置方面，可借助电力系统库与电源库搭建包含电源、断路器、传输线、变压器、负载与可再生能源/储能的网络结构。在此基础上对配电拓扑、线路与变压器参数、负载模型类型（RLC/恒功率等）以及保护与同步环节（如单相/三相 PLL）进行组合与整定，并利用潮流与初始化能力保证系统稳态一致性，从而在保证结构紧凑清晰、逻辑可维护的前提下，获得电压水平合理、功率分配可控、故障响应正确的最优系统方案。

电气系统的实验验证

在实验验证阶段，基于新型电力系统模型库可对电气系统开展性能与可靠性验证，覆盖控制策略有效性评估、典型工况与极端工况复现、故障模拟与诊断验证，以及参数整定与系统优化等应用场景。从而在“仿真试验—问题定位—参数修正—再验证”的闭环中逐步收敛到满足设计要求的系统方案。

- 电气系统的故障模拟

为验证系统在异常情况下的鲁棒性与保护正确性，可在电力系统的故障与开关类设备基础上构建开路、短路、接地、三相不平衡等典型故障场景，并在不同故障位置、故障电阻与故障持续时间条件下开展批量对比试验。通过监测故障前后的电压跌落、故障电流、功率波动、频率偏移与控制量变化，验证断路器动作逻辑、保护定值合理性以及PLL等同步环节在扰动下的稳定性，最终为降低事故发生率、提升系统可用性与可维护性提供依据。

## 功能特点

应用本新型电力系统模型库可实现电气系统的快速建模与复用搭建，并在统一的模型框架下开展系统级仿真分析工作。结合工程实际的拓扑结构、运行工况与控制策略，可对系统稳态、动态与瞬态特性进行全面评估，同时可将电气系统与电机系统、控制系统等进行联合仿真，形成从参数选型到方案验证的闭环分析流程，从而提升设计效率并降低试验与调试成本。

(1). 基于模型库开展电气系统稳态性能分析时，可在额定工况或典型负载条件下确定系统的基础拓扑与关键器件/参数配置，完成系统平衡计算与功率分配校核，并进一步引入电网强弱变化、负载波动等干扰因素进行分析，通过系统调整计算与试验数据对比验证稳态指标与设计假设的一致性。

(2). 开展电气系统动态性能分析时，可在初步设计基础上对关键参数进行校正与迭代，综合考虑开环与闭环动态响应特性，评估控制器增益、滤波参数、采样周期等对超调、调节时间与稳定裕度的影响，确定参数最佳匹配关系。

(3). 进行电气系统电磁暂态分析时，可在模型库基础上构建包含电源、输配电网络、变换器与负载的完整系统，并针对开关操作、故障切除/重合闸、并离网切换、负载突加/突卸、变压器励磁涌流等典型暂态过程开展仿真。通过对电压、电流、功率及关键器件应力的时域波形进行分析，评估暂态过电压、冲击电流、振荡与谐波等现象的产生机理及传播路径，同时结合保护与控制策略验证其动作正确性与协调性，进而为器件选型、滤波参数整定以及系统稳定运行提供依据。

## 控制离网（VSG_Control_Off_Grid–VSG）

1. 介绍

本案例展示了一种基于虚拟同步发电机（VSG）技术的离网型逆变器控制系统。系统主电路采用三相全桥拓扑，通过LC滤波器连接本地负载，模拟同步发电机的机电特性。在离网模式下，VSG无需依赖电网信号，自主建立电压和频率支撑，为孤岛负载提供稳定供电。核心控制层包含有功-频率环、无功-电压环及内嵌的电压电流双闭环，共同实现功率动态调节与输出波形质量控制。

描述

SG的控制策略通过有功环模拟同步机转子运动方程，引入惯性和阻尼系数，使系统具备频率自适应能力；无功环则模拟励磁调节特性，维持输出电压幅值稳定。电压电流双环作为内层控制，快速跟踪外环指令并抑制负载扰动，保障电能质量。离网运行时，VSG通过调节有功功率平衡负载需求，维持系统频率稳定；同时通过无功环动态补偿负载变化，确保电压幅值恒定，有效解决了传统逆变器离网运行时抗扰动性差、过载能力不足的问题。系统原理图如下：

_图55虚拟同步发电机离网系统_

分析

模型维度设置

在电力系统控制策略验证仿真过程中，经常会出现多输入多输出或多输入单输出的情况，有时需要将多个通道合并输出。面对这种情况，可以采用三种解决方案：

（1）在组件属性更改模型维度：右击模型，点击属性，在组件属性编辑框的名字后加数组维度，如下图所示，如果是长度为6的矢量模型，则在模型名字后加[6]。同样地，也可以自定义子系统输入输出接口的输出维度。

图 64 组件属性更改模型维度示意图

（2）在文本代码的组件代码后添加数组维度：如下图所示，在gain组件代码名字后面加数组维度[2]，这样在连接的时候会自动跳出弹窗，选择需要连接的维度。

图 65 文本代码更改模型维度示意图

图 66模型维度修改后连接方式示意图

（3）使用组件：使用单输入多输出组件将模型扩展至矢量模型，用户可自定义配置组件的输出维度参数

图 67组件修改模型维度示意图

电路仿真设置要求

在有频率周期信号的仿真模型中，例如交流系统、带有脉冲控制开关电路系统，在仿真时为使信号不失真，一般将仿真步长取信号源周期T的1/10以上，即为步长≤T/10，如果模型中有采样时间的参数，建议和仿真步长设置的大小保持一致。
