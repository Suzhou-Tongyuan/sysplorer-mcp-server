# Manual Index

Large manual copies are reference data, not execution rules. Do not load `references/manual-text/*.md` by default. First use the concise files linked from `SKILL.md`; read a manual only when a component, parameter, topology family, example, or original wording cannot be resolved from those concise files.

## Manual Files

| File | Use Only When |
|---|---|
| `manual-text/附录A-10 新型电力系统模型库V1.2.0-产品用户手册-A.md` | Need original NPSLibrary component, parameter, example, or workflow wording. |
| `manual-text/NPSlibrary模型清单.md` | Need a compact model-name list or Chinese display-name lookup. |

## Search First

Use targeted search terms before opening a whole manual: class name, component display name, converter type, bus type, `Powergui`, `LoadFlowBus`, port name, or parameter name.
