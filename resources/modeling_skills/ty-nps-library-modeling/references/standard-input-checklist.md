# Standard Input Checklist

NPSLibrary 建模开始前，优先按本清单收集输入。缺失信息允许进入最小闭环建模，但必须在需求识别结果中显式标记“当前信息缺口”。

---

## 1. 需求输入

- 建模对象
  例如：并网逆变器、Boost、双向DCDC、PMSM 驱动、三相供电网络、IEEE14 潮流
- 建模目标
  例如：功能验证、控制验证、稳态分析、暂态分析、故障分析、潮流分析
- 拓扑类型
  例如：两电平/三电平、三相供电、储能并网、变压器-线路-负载网络
- 系统边界
  哪些部分详细建模，哪些部分简化
- 输入信号 / 参考量
  例如：电压源、P/Q 指令、`id/iq` 参考、转速参考、占空比参考
- 输出指标
  例如：电压、电流、有功、无功、频率、转速、转矩、SOC、节点电压与相角
- 额定电气参数
  例如：电压、电流、功率、频率、变比、线路长度、阻抗
- 控制参数
  例如：开关频率、采样周期、PI 参数、PLL 参数、死区、滤波参数
- 仿真时长与步长要求
- 所用库约束
  默认优先 `NPSLibrary`
- 交付要求
  例如：模型文件、结构说明、参数表、关键波形、校核结论

---

## 2. 补充输入

- 电气原理图 / 单线图
- 拓扑草图
- 用户手册
- 对标案例
- 参考模型
- 历史报错日志
- 并网规范、故障工况、潮流边界条件

---

## 3. 最低通过标准

在进入组件映射前，至少应能回答：

1. 要建什么 NPS 系统
2. 为什么建
3. 用 `NPSLibrary` 的哪些子库建
4. 看哪些电气或机电结果
5. 怎样算建模成功
