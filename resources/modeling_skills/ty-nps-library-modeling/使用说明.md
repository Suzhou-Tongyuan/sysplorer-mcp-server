## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-nps-library-modeling` |
| **Skill 中文名称** | NPSLibrary 电气系统建模 |
| **Skill 描述** | 用于在 MWORKS / Sysplorer 中基于内置商业 `NPSLibrary` 完成电力电子、电机驱动、电源网络、故障保护、潮流相关模型的新建、修复、验证、结果复核与图面闭环。 |
| **版本信息** | `1.0` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 当用户明确提到 `NPSLibrary` 并要求进行电力系统、电力电子、电机驱动、电源网络、故障保护或潮流相关建模时触发。
- 当用户明确要求使用 Sysplorer 内置库 / 商业库路径完成相关 NPS 场景任务时触发。
- 适用于修复 `NPSLibrary` 模型的初始化、接地/参考、连线、接口匹配、`Powergui`、潮流设置、参数、仿真或结果读取问题。
- 适用于验证 `NPSLibrary` 官方样例、企业样例或现有模型，并输出关键变量与结论。
- 仅出现 `Boost`、`Buck`、`DCDC`、`inverter`、`motor drive` 等场景词，但未明确 `NPSLibrary` 或内置库 / 商业库路径时，不应单独触发本 Skill。
- 本 Skill 默认在已经应用 `ty-sysplorer-modeling-rules` 之后作为领域补充层使用。

---

### 三、核心功能

- 支持 `NPSLibrary` 范围内的电力电子、电机驱动、电源网络、故障保护和潮流模型建模。
- 支持主功率路径、控制链、接地/参考、`Powergui`、传感器、边界和结果探针的组件映射。
- 支持并网逆变器、三相供电网络、Boost/DCDC、电机驱动、负载和潮流网络等典型场景。
- 支持初始化、参数、接口维度、单相/三相匹配、仿真发散和结果异常的修复。
- 支持图形化建模任务中的 GUI 可编辑性、连线可审阅性和图面闭环复核。
- 支持按需读取手册索引，在精简参考不足时再查手册原文。

---

### 四、适用场景

- 使用 `NPSLibrary` 搭建或修复电力电子、电机驱动、电源网络、故障保护或潮流模型。
- 修复 `NPSLibrary` 模型的接地/参考缺失、连线错误、接口不匹配、`Powergui` 或潮流初始化异常。
- 验证 `NPSLibrary` 官方样例、企业样例或用户已有模型的关键结果。
- 对三相电源、变压器、线路、负载、逆变器、PWM、PLL、光伏、电池、Boost、DCDC、电机驱动等任务做建模与结果整理。
- 在交付前整理模型结构、组件映射、参数摘要、仿真设置、验证变量、图面审阅结果和已知限制。
