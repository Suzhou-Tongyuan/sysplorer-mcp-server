# ty-design-opt-exp-modeling 使用说明

本技能用于 Sysplorer 批量仿真工具箱 `DesignOptExp` 的 Python API 辅助。

## 适用任务

- 编写批量仿真脚本。
- 初始化批量仿真求解器目录和工作目录。
- 对多组模型参数进行仿真。
- 为每次仿真指定结果变量。
- 读取批量仿真的时序结果。
- 接收 `DesignOptExpGui` 生成的实验设计矩阵或蒙特卡洛样本，并执行实际批量仿真。
- 仿真结束后主动询问用户是否使用 `matplotlib` 绘制结果图（直接弹出显示，不保存文件）。

## 与其他设计优化技能组合

五个设计优化技能可以搭配使用。常见方式是先用 `ty-design-opt-exp-gui-modeling` 的实验设计或蒙特卡洛函数生成参数数据，再转换为 `DesignOptExp.BatchSimulate` 的参数列表，由本技能执行批量仿真。仿真结果可继续用于 PSA 敏感度分析、MRO 响应优化或 MPE 参数估计。

## 安全约定

不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。如需卸载模型，使用 MCP 的 `model_manager(action="unload")`。
