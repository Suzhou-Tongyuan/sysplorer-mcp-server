# 批量仿真使用说明

本文面向通过 Python API 使用 `mworks.sysplorer.DesignOptExp` 的场景。

## 基本导入

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptExp as exp
```

DesignOptExp 是独立工具箱模块，不能假设函数存在于主 `mworks.sysplorer` 命名空间中。

## 推荐流程

1. 启动或连接 Sysplorer。
2. 设置 64 位编译求解器。

```python
sysplorer.SetCompileSolver64(1)
```

3. 加载依赖库并打开模型。

```python
sysplorer.LoadLibrary("Modelica")
sysplorer.OpenModelFile(r"C:\path\to\WaterTank.mo")
```

4. 准备批量仿真选项。

```python
options = {
    "startTime": 0,
    "stopTime": 1,
    "outputStep": 0.02,
    "saveEvent": False,
}
```

5. 初始化批量仿真（返回 `bool`，建议检查）。

```python
ok = exp.InitialBatchSimulate(
    modelName="WaterTank",
    solverPath=r"E:\SolverPath\WaterTank",
    storePath=r"E:\BatchSimRes",
    instNum=10,
    options=options,
)
if not ok:
    raise RuntimeError("InitialBatchSimulate failed")
```

6. 执行批量仿真。

```python
params = [
    {"PI1.k": 1, "PI1.T": 1},
    {"PI1.k": 1.2, "PI1.T": 1.2},
]

result_names = [
    ["y"],
    ["y", "PI1.y"],
]

res = exp.BatchSimulate(params, result_names)
```

7. 读取结果。

```python
print(res[0]["y"])
print(res[0]["time"])
```

## 结果变量自动补齐

如果每组参数都读取相同变量，可只给一个结果变量列表：

```python
params = [{"length": 100}, {"length": 50}]
result_names = [["area"]]
res = exp.BatchSimulate(params, result_names)
```

接口会按参数组数自动补齐 `result_names`。

## 注意事项

- 2026a 的 `InitialBatchSimulate` 需要 `modelName`，返回 `bool`。
- `solverPath` 可以是空目录或已有求解器目录。
- `storePath` 应为可写目录。
- `options` 为非必填项，按需添加 key/value；示例脚本中旧写法 `outputStepInterval` 不应优先使用，2026a docx 明确继续使用 `outputStep`。
- `param` 和 `resultName` 类型必须分别是 `list[dict]` 和 `list[list[str]]`。
