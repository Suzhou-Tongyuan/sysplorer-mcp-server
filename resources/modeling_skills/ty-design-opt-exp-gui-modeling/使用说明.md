# ty-design-opt-exp-gui-modeling 使用说明

## 用途

本技能用于 `mworks.sysplorer.DesignOptExpGui` 模型试验 Python API 的脚本编写与文档维护，覆盖固定参数批量研究、实验设计、蒙特卡洛、时变参数研究及结果读取。

## 开始使用

1. 确保 Sysplorer 会话已就绪并打开待研究模型。
2. 阅读 `references/模型试验demo说明.md` 了解基础调用顺序。
3. 查阅 `references/DesignOptExpGui.md` 确认接口签名和默认值。
4. 按研究类型阅读 `references/模型试验使用说明.md` 或复用 `references/模型试验示例.md` 的代码片段。

导入工具箱：

```python
import mworks.sysplorer.DesignOptExpGui as exp
```

## 标准流程速记

1. `InitialApp(modelName)` 初始化模型试验。
2. `GetParameter()` / `GetVariable()` 查询可用名称。
3. `SelectParameter(...)` / `SelectVariable(...)` 选择输入输出。
4. 使用 `NewBatch(...)`、`NewExperimentDesign(...)`、`NewMentoCarlo(...)` 或 `NewTimeParameter(...)` 创建研究。
5. `SetParameterMatrix(...)` 提供运行输入。
6. 按需设置 `SetSimulationOption(...)`。
7. 使用 `SetExperimentOption(resultPath, parallel=10, longestSimulateTime=864000)` 设置输出位置、并行数及最长仿真时间。
8. `StartSimulation(...)` 执行研究。
9. `GetResultData(...)` 获取结果。

## 注意事项

- 工具箱函数名以源码为准，保留 `NewMentoCarlo`、`MultionmialSampling`、`RayleihSampling` 等源码拼写。
- `ListFunctions()` 可用于枚举当前安装版本公开的 API。
- `DesignOptExpGui.InitialBatchSimulate(...)` 是兼容接口，签名不包含 `modelName`；纯批量仿真任务优先使用 `ty-design-opt-exp-modeling`。
- 禁止在执行脚本中调用 `ClearAll` 或 `ChangeDirectory`。

## 与其他设计优化技能组合

五个设计优化技能可以搭配使用。常见方式是用本技能的实验设计或蒙特卡洛采样函数生成参数数据，再交给 `ty-design-opt-exp-modeling` 的 `DesignOptExp.InitialBatchSimulate(...)` / `DesignOptExp.BatchSimulate(...)` 执行批量仿真。仿真结果可继续进入 PSA、MRO 或 MPE。
