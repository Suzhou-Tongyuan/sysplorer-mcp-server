# 模型试验使用说明

## 标准准备

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptExpGui as exp

sysplorer.SetCompileSolver64(1)
sysplorer.LoadLibrary("Modelica")
sysplorer.OpenModelFile(r"C:\path\to\rectangle_area.mo")

exp.InitialApp("rectangle_area")
parameters = exp.GetParameter()
variables = exp.GetVariable()
exp.SelectParameter(["length"])
exp.SelectVariable(["area"])
```

## 固定参数批量研究

适用于直接给出多组参数值的场景。

```python
exp.NewBatch("batch1")
exp.SetParameterMatrix("batch1", {"length": [50, 35]})
exp.StartSimulation("batch1")
data = exp.GetResultData("batch1", "area")
```

## 实验设计研究

先使用设计函数生成采样矩阵，再根据选中的参数组织为 `SetParameterMatrix` 所需字典。

```python
matrix = exp.FullFactorialDesign([[0, 1], [10, 20, 30]])
matrix = exp.OrthogonalDesign([[0, 1], [10, 20, 30]])
matrix = exp.LatinHypercubeDesign(20, [-1, -1], [1, 1])
matrix = exp.CenterCompositeDesign([-1, -1], [1, 1], [1, 1], 0, 0)
matrix = exp.DOptimalDesign([-1, -1], [1, 1])
```

创建实验设计研究：

```python
exp.NewExperimentDesign("doe1")
# 将 matrix 的各列映射为已选择参数的值列表，再传给 SetParameterMatrix。
```

## 蒙特卡洛研究

```python
exp.NewMentoCarlo("mc1")
length_values = exp.UniformSampling(number=20, lower=9.5, upper=10.5)
exp.SetParameterMatrix("mc1", {"length": length_values})
exp.StartSimulation("mc1")
```

源码函数名为 `NewMentoCarlo`，不是 `NewMonteCarlo`。

## 时变参数：内置波形

```python
exp.NewTimeParameter("time1")
exp.SetParameterMatrix(
    "time1",
    {
        "sampleNum": 1,
        "length": {
            "sampleType": 0,
            "min": -1e100,
            "max": 1e100,
            "value": [0, 1, 0, 1, 0, 1, 0, 1],
        },
    },
)
exp.StartSimulation("time1")
```

`sampleType`：

- `0`：正弦波，`value` 为频率、相位、振幅、基线各自的最小值/最大值，共 8 项。
- `1`：三角波，`value` 同为 8 项。
- `2`：方波，`value` 为频率、相位、振幅的最小值/最大值，共 6 项。

## 时变参数：CSV 自定义数据

```python
exp.NewTimeParameter("custom_time")
exp.SetParameterMatrix(
    "custom_time",
    {
        "path": r"C:\path\to\input.csv",
        "engineTorque1.tau_0": "acc",
        "engineTorque1.w_max": "speed",
    },
)
exp.StartSimulation("custom_time")
```

字典键为模型参数名称，值为 CSV 列名。

## 仿真配置与结果

```python
exp.SetSimulationOption(
    "batch1",
    startTime=0,
    stopTime=1,
    outputStep=0.002,
    algorithm="Dassl",
    tolerance=0.0001,
    saveEvent=True,
)
exp.SetExperimentOption(
    r"C:\path\to\results",
    parallel=10,
    longestSimulateTime=864000,
)

data = exp.GetResultData("batch1", "area")
time = data["time"]
area_first_run = data["area-Run1"]
```

## 返回值与接口边界

- `GetResultData(studyName, varName)` 的源码说明返回 `dict`；配套示例中可以读取 `data["time"]` 和 `data["area-Run1"]`。
- `SetSimulationOption(...)` 和 `SetExperimentOption(...)` 源码的 docstring 说明返回 `bool`，但 Python 签名未标注 `-> bool`。
- `SetExperimentOption(...)` 的最新源码新增 `longestSimulateTime=864000`，用于指定最长允许仿真时间，超时后自动终止。
- `ListFunctions()` 返回当前模块接口名称及中文注释，可用于核查安装版本提供的接口。
- `DesignOptExpGui.InitialBatchSimulate(solverPath, storePath, instNum=50, options={})` 是兼容接口，不包含 `modelName`；不要与 `DesignOptExp` 2026a 批量仿真接口混用。

## 注意事项

- 使用源码实际模块名 `DesignOptExpGui`。
- 参数名、变量名和研究名大小写敏感。
- 应在 `SetParameterMatrix` 前先创建研究并选择相应参数/变量。
- 不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。
