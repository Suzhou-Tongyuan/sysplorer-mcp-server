# 模型试验示例

以下示例由参考目录中的五个 Python 脚本整理，导入模块已统一为当前安装源码对应的 `DesignOptExpGui`。

## 基础批量研究

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptExpGui as exp

sysplorer.LoadLibrary("Modelica")
sysplorer.OpenModelFile(r"C:\path\to\rectangle_area.mo")
exp.InitialApp("rectangle_area")

exp.SelectParameter(["length"])
exp.SelectVariable(["area"])
exp.NewBatch("batch1")
exp.SetParameterMatrix("batch1", {"length": [50, 35]})
exp.StartSimulation("batch1")

result = exp.GetResultData("batch1", "area")
print(result)
```

## 实验设计函数

```python
full = exp.FullFactorialDesign([[0, 1], [10, 20, 30]])

lhs = exp.LatinHypercubeDesign(20, [-1], [1])
ccd = exp.CenterCompositeDesign([-1, -1], [1, 1], [1, 1], 0, 0)
d_opt = exp.DOptimalDesign([-1, -1], [1, 1])
spaced = exp.EquallySpacedSampling(initialValue=100, stepLength=5.5, lowerNum=10, upperNum=3)
```

## 时变参数波形

```python
exp.SelectParameter(["length"])
exp.SelectVariable(["area"])
exp.NewTimeParameter("time1")
exp.SetParameterMatrix(
    "time1",
    {
        "sampleNum": 1,
        "length": {
            "sampleType": 0,
            "min": -1e100,
            "max": 1e100,
            "value": [0, 1, 0, 1, 0, 1, 0, 1],
        },
    },
)
exp.StartSimulation("time1")
result = exp.GetResultData("time1", "area")
```

## 时变参数 CSV

```python
exp.NewTimeParameter("custom_time")
```
