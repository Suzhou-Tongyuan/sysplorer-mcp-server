# 敏感度分析使用说明

本文面向通过 Python API 使用 `mworks.sysplorer.DesignOptPsa` 的场景。

## 基本导入

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptPsa as psa
```

DesignOptPsa 是独立工具箱模块，不能假设函数存在于主 `mworks.sysplorer` 命名空间中。

## 推荐流程

1. 加载库并打开模型。

```python
sysplorer.LoadLibrary("Modelica")
sysplorer.OpenModelFile(r"C:\path\to\EyeTracking.mo")
```

2. 初始化敏感度分析。

```python
psa.InitialApp("EyeTracking.eyeTrackingModel")
```

3. 查询可用参数和变量。

```python
print(psa.GetTunerParam())
print(psa.GetVariable())
```

4. 创建参数集。

```python
psa.NewParameterSetAttachParam("set1", ("Tc", "Tp", "gainK"))
psa.SetCurrentParameterSet("set1")
```

5. 配置采样。方式一：显式采样数据。

```python
psa.SetParamSamplingData("Tc", psa.NormalSampling(100, 15, 3))
psa.SetParamSamplingData("Tp", psa.UniformSampling(100, 0.005, 0.05))
psa.SetParamSamplingData("gainK", psa.UniformSampling(100, 0.2, 1))
```

方式二：分布配置后启动采样。

```python
psa.SetSampleOption(100, "Random", True)
psa.SetParamSampleDistribution("Tc", "Normal Distribution", (15, 3))
psa.SetParamSampleDistribution("Tp", "Uniform Distribution", (0.005, 0.05))
psa.SetParamSampleDistribution("gainK", "Uniform Distribution", (0.2, 1))
psa.StartSampling()
```

6. 创建需求。变量匹配需求直接配置 CSV 和变量映射：

```python
psa.NewVariableMatchingRequirement("req")
psa.ConfigVariableMatchingRequirement(
    "req",
    r"C:\path\to\eyedata.csv",
    {"y": "eyedata"},
)
psa.SelectRequirement(("req",))
```

7. 设置仿真和评估选项。

```python
psa.SetSimulateOption(startTime=0, endTime=14, stepNumber=500)
psa.SetEvaluateOption(continueEvaluate=True, saveEvaluate=True, parallelNum=4)
```

8. 执行评估并读取需求偏差。

```python
psa.StartEvaluate()
eval_results = psa.GetEvaluateResult()
eval_data = psa.GetEvaluateResultData(eval_results[0])
```

9. 执行量化分析。

```python
psa.SelectEvaluateResult(eval_results[0])
psa.SetQuantifiedMethod(correlation=True, standardizedRegression=True, partialCorrelation=True)
psa.SetQuantifiedType(linear=True, ranked=True, kendall=True)
psa.StartQuantifiedAnalysis()
quant_results = psa.GetQuantifiedResult()
quant_data = psa.GetQuantifiedResultData(quant_results[0])
```

`GetQuantifiedResultData(resultName)` 当前源码返回列表，结构为：

```python
[量化类型, 需求名称, {参数名称: 相关性数值}]
```

10. 关闭工具箱。

```python
psa.CloseApp()
```

## 需求类型选择

- 有测量数据 CSV，并需要比较仿真变量与测量列时，用变量匹配需求。
- 只关心终值、最大值、最小值、平均值等标量属性时，用变量属性需求。
- 关心阶跃响应性能指标时，用阶跃响应需求。
- 要限制变量曲线不越过线性边界时，用线性边界需求。
- 要让变量跟踪目标曲线时，用变量追踪需求。

## 注意事项

- 分布配置接口只针对当前参数集，使用前确认 `SetCurrentParameterSet(...)`。
- 显式采样列表长度应一致。
- 变量匹配需求的 `variable` 字典中，键是仿真变量，值是 CSV 测量变量。
- 非变量匹配需求通常需要变量集绑定。
- 量化分析前必须先选择评估结果。
- 在 MCP 工作流中不要调用 `ClearAll` 或 `ChangeDirectory`。
