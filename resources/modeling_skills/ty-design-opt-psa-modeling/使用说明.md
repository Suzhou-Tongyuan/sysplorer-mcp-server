# ty-design-opt-psa-modeling 使用说明

本技能用于 Sysplorer 敏感度分析工具箱 `DesignOptPsa` 的 Python API 辅助。

## 适用任务

- 编写敏感度分析脚本。
- 查询 DesignOptPsa API 签名、参数和返回值。
- 创建参数集并配置采样分布。
- 使用内置采样函数生成显式样本。
- 创建变量匹配、变量属性、阶跃响应、线性边界和变量追踪需求。
- 执行评估计算并读取需求偏差。
- 进行相关性、标准化回归、偏相关等量化分析。

## 主要资料

- `SKILL.md`：面向 Codex/MCP 的技能入口。
- `SKILL_ZH.md`：中文概览。
- `references/DesignOptPsa.md`：API 参考。
- `references/敏感度分析使用说明.md`：工作流说明。
- `references/敏感度分析demo说明.md`：EyeTracking 示例说明。

## 安全约定

不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。敏感度分析结束后使用：

```python
psa.CloseApp()
```

如果脚本自己启动并拥有 Sysplorer 进程，可再调用：

```python
sysplorer.Exit()
```
