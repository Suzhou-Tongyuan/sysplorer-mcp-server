# 结果核验规则

本文件负责结果核验的详细规则，不承担任务入口职责。仅在用户要求结果或约定验收标准确需时应用；只要求检查、翻译或仿真成功时结果核验为 `not_required`，不追加 KPI 或默认变量。

适用于：

- 查关键结果变量
- 结果复核
- 写仿真结论
- 确认模型是否达到任务目标

## 车辆结果核验补充规则

本文件只补充 TA 车辆模型的领域变量、结果口径和汇报重点；仿真、KPI 判断和交付证据链仍服从父级 `ty-sysplorer-modeling-rules`。

- 先确认关键变量名，再读取关键结果并汇报。
- 先核对变量名，再读取数值，不猜结果变量名称。
- 只汇报验收所需的核心变量；解释性变量仅在同一验收目标确需时补充，不因汇报结构而追加结果读取。
- 未核验结果不得按已确认结果表述。

## 核验顺序

1. 先明确任务最关心的输出，不要一上来全量扫变量。
2. 仿真前确认 stop time / StopTime / stopTime 等终止时间设置等于用户目标时长或目标工况结束时间；不要把 `target_time`、采样时刻或结果探针误当 stop time。
3. 需要结果核验时，通过 MCP 读取本次成功仿真或显式结果文件的目标变量；仿真失败后可读旧结果不能反证本次成功。
4. 对关键变量至少核验“变量存在 + 数值可读 + 含义匹配”。
5. 汇报时区分“已核验结果”和“仅预期应存在结果”。
6. 如果变量名不稳定，先通过结果变量列表确认实际名称，再读取数值。保留数值时刻读取返回的 warning，区分官方采样、线性插值和区间外端点回退，不将插值或端点值当成原始采样。

## 常见领域关注点

- `TAEconomy`：
  车速、目标车速偏差、里程、加速时间、SOC、油耗、电耗、驱动功率、发动机或电机转速扭矩
- `TADynamics`：
  纵向速度、横向速度、侧偏、横摆角速度、车身姿态、纵横向加速度、悬架位移、轮胎力、轮速、制动力矩
- `TAThermalSystem`：
  制冷剂高低压侧温压、关键换热器进出口温度、冷却液温度流量压差、换热量、压缩机功耗、舱内热舒适指标
- `TAEngine`：
  转速、扭矩、燃油流量、进排气压力流量温度、增压器状态、热负荷
- `TABattery`：
  电压、电流、功率、SOC、单体/模组/整包温度、温差、热流、老化相关状态
- `TAElectronic`：
  低压母线电压电流、DCDC 输入输出功率、关键负载功率、附件工作状态、热管理附件电功率

## 汇报规则

1. 按用户目标与验收范围选择核心变量，没有最低数量要求；仅要求一个末时 SOC 时只核验该变量。综合分析可参考 3 到 8 个变量组织内容，但该数量既不授权凑数读取，也不限制完成明确验收所需的变量。
2. 只在同一验收目标确需时补充解释性变量；不需要时该部分记 `not_required` 或省略，不额外读取变量。
3. 若仿真成功但变量找不到，不猜变量名，先回到结果变量列表确认。
4. 若结果只是预期而未核验，要明确写“未核验”，不能按已确认结果表述。
