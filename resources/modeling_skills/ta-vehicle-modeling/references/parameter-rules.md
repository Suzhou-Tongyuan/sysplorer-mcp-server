# 参数规则

本文件只补充 TA 车辆库参数处理规则；通用建模、检查、翻译和仿真顺序由 `ty-sysplorer-modeling-rules` 管控。

## 参数来源优先级

1. 用户给定的车型、工况、部件表或试验数据。
2. 已选主库卡片中的 `Samples` 与速查案例。
3. 当前 Sysplorer 安装目录下 `Docs\VehLib\Samples\<库名>` 的官方样例。
4. 已加载模型的类文档、参数默认值和组件说明。
5. 工程经验假设；必须标记为 `to confirm`。

## 赋值规则

- 先定车辆架构和主库，再定子系统参数。
- 不跨层直接写内部变量；外层只通过真实参数、接口、总线或边界条件配置子系统。
- 参数单位必须与组件声明一致；不因结果变量使用 SI 单位就擅自重标用户输入。
- 成组部件的编号、数量和总线索引必须一致，例如电池包/模组/电芯、四轮、悬架、制动器、电机和低压负载。
- 调试性参数只用于定位问题，不能未经说明保留到最终交付模型。

## 车辆领域重点

- `TAEconomy`：整备质量、风阻、滚阻、传动比、驱动源额定参数、循环工况、目标车速和初始 SOC。
- `TADynamics`：轴距、轮距、质心、惯量、轮胎、悬架硬点、弹簧阻尼、转向、制动和道路参数。
- `TAThermalSystem`：环境温度、流量、压降、换热面积、制冷剂/冷却液边界、压缩机/泵/阀控制参数。
- `TAEngine`：转速扭矩边界、进排气边界、燃油供给、增压器、热边界和控制信号。
- `TABattery`：串并联数、容量、SOC、内阻/热容、初始温度、热接口和老化参数。
- `TAElectronic`：低压母线电压、DCDC 功率、负载功耗、附件启停策略和热管理执行器电功率。
