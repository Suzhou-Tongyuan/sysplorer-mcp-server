# Dynamics Whole Vehicle Skeleton

## 定位

- 本文件不是任务入口，不负责判定“是否属于动力学任务”或“主库该选谁”。
- 只有在 `../../references/library-selection.md` 已将任务收敛到 `TADynamics`，并且已进入 `../../workflows/build-from-scenario.md` 后，才用它快速套动力学整车骨架。
- 它提供的是高频场景的默认落地骨架，不替代 `../../references/build-rules.md` 与 `../../references/diagram-layout-rules.md`。

## 适用范围

- `TADynamics` 主框架整车动力学
- 悬架、K&C、操稳、平顺性、转向、制动相关整车级任务

## 默认骨架

| 项目 | 默认做法 |
| --- | --- |
| 主库 | `TADynamics` |
| 默认车身 | 未指定时使用 `KC / 集成车身` |
| 常见辅助库 | 仅当驱动或传动细化必须影响动力学响应时补 `TAEconomy` |
| 详细规则 | `../../references/build-rules.md`、`../../references/diagram-layout-rules.md` |
| 优先案例来源 | `../../references/library-cards/TADynamics.md` 中的 Samples 与速查起步 |

## 最小闭环

1. 驾驶员或工况输入
2. 车身 / 悬架 / 轮胎 / 道路主链
3. 转向、制动和驱动接口闭合
4. 顶层图面完成基本布局

## 首轮必锁信息

| 必锁项 | 说明 |
| --- | --- |
| 车型骨架 | KC / 集成车身还是其他车身类型 |
| 工况入口 | 阶跃转向、双移线、蛇形、K&C 等 |
| 驱动 / 制动作用点 | 是否真正落到轮端 |
| 结果变量 | 车速、横摆角速度、侧偏、加速度、悬架位移、轮胎力 |

## 首轮必查

- 车身、悬架、轮胎、道路接口是否匹配
- 驱动或制动力是否真正作用到轮端
- 图面是否能一眼看出主框架、关键链路和边界接口

## 不得做的简化

- 不得把四轮压成不区分左右/前后的抽象串行结构
- 不得为了先跑起来长期用纯信号或占位块替代关键动力学链
- 不得把局部子系统案例直接包装成整车正式交付
