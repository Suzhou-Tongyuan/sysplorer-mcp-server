# Economy Main Framework

## 定位

- 本文件不是任务入口，不负责判定“是否属于经济性/续航任务”或“是否需要联合其他库”。
- 只有在 `../../references/library-selection.md` 已将任务收敛到 `TAEconomy`，并且已进入 `../../workflows/build-from-scenario.md` 后，才用它快速套整车主框架。
- 它提供的是高频场景的默认骨架，不替代 `../../references/build-rules.md` 或主库卡片中的详细说明。

## 适用范围

- `TAEconomy` 主框架任务
- 动力性、经济性、续航、驾驶循环和车型架构分析

## 默认骨架

| 项目 | 默认做法 |
| --- | --- |
| 主库 | `TAEconomy` |
| 常见辅助库 | `TAEngine`、`TABattery`、`TAElectronic` |
| 默认思路 | 先搭整车纵向性能和能耗主链，再补细化子系统 |
| 详细规则 | `../../references/build-rules.md` |
| 优先案例来源 | `../../references/library-cards/TAEconomy.md` 中的 Samples 与速查起步 |

## 最小闭环

1. 驾驶员 / 驾驶循环输入
2. 动力源、传动、制动和车身链路闭合
3. 关键编号、总线和驱动链映射一致
4. 顶层图面按中轴结构排布，驾驶员放最左

## 首轮必锁信息

| 必锁项 | 说明 |
| --- | --- |
| 车型架构 | 燃油、纯电、混动还是增程 |
| 驱动主链 | 发动机 / 电机 / 变速器 / 车桥的连接关系 |
| 关键编号 | 电机数量、编号、总线、驱动链映射 |
| 结果变量 | 车速、里程、SOC、油耗、电耗、驱动功率 |

## 首轮必查

- 驾驶员 / 循环工况是否真正驱动车辆
- 电机数量、编号和总线是否一致
- 结果变量是否覆盖车速、里程、SOC、油耗或电耗

## 不得做的简化

- 不得把动力学或热管理任务误路由到该模板
- 不得忽略编号和总线一致性问题
- 不得在正式交付路径保留来源不清的临时动力源替代件
