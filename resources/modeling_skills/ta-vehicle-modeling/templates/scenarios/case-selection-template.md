# Case Selection Template

## 定位

- 本文件不是任务入口，不负责判方向、选主库或决定先读哪些规则。
- 只有在 `../../references/requirement-map.md`、`../../references/library-selection.md` 或对应 workflow 已确定本轮任务方向后，才用它记录参考案例。
- 它只负责留下“参考了哪个案例、借鉴了什么、哪些地方不能直接照搬”的记录，方便后续复核。

## 使用方式

在开始建模或编写布局注解前，先按下面结构记录本轮参考案例，避免只说“参考了官方案例”而没有可核对依据。

## 先判断

| 问题 | 记录要求 |
| --- | --- |
| 当前主任务是什么 | 新建 / 修复 / 图面 / 结果核验 |
| 当前主库是什么 | 只能写一个主库 |
| 本轮参考案例解决什么问题 | 拓扑 / 参数 / 图面 / 结果变量 / 工况 |
| 案例与当前任务的主要差异是什么 | 至少写 1 到 3 条 |
