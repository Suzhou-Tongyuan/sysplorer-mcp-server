# Result Summary Template

## 使用说明

- 仅在结果核验属于本轮范围时使用本模板，不自动创建正式报告。未要求结果时标记 `not_required`；数值注明本次结果来源及原始采样/插值/端点回退 warning。本文件不负责最终完成判定。
- 只填写已按验收范围核验的变量，没有最低数量要求；单变量请求只填该变量。综合分析可参考 3 到 8 个变量组织内容，但不得为凑数量或填表而追加读取。解释性变量仅在同一验收目标确需时填写，否则省略该节或记 `not_required`。
- 若变量名存在歧义，先回到结果变量列表确认后再填写本模板。
