# 模板选择器

## 用途

本文件用于在展开任何 Sysblock 信号或通信方案之前，先选择最小足够模板。
不要跳过模板选择，直接进入模块堆砌。
本文件只负责“选哪个模板”，不负责展开模板内部细节；选定模板后，应继续阅读 `playbooks.md`。

## 模板映射

- `A`：QPSK + AWGN + BER 这类基带通信验证
- `B`：滤波链路与频谱验证
- `C`：基础 Sysblock 模块主导的通用信号处理原型
- `D`：基础骨架加通信增强模块
- `E`：混合信号扩展专题
- `F0`：DSSS 单模型参数切换，基础优先
- `F1`：在 F0 基础上进行 DSSS 专业增强

## 选择规则

1. 先做任务归类
2. 选择最小足够模板
3. 除非有证据支持升级，否则优先选择 `L0`
4. 通信类任务要显式说明 Tx、信道、Rx、同步与可观测性
5. DSSS 类任务除非存在明确增强需求，否则优先从 `F0` 开始

## 与 `playbooks.md` 的关系

- 当前文件负责模板选择与初步映射
- `playbooks.md` 负责被选模板的目标、最小链路、最小关注点与专题细化
- 推荐顺序：先读本文件，确定模板后再读 `playbooks.md`

## 典型映射

- 振动特征提取 -> `C`
- 滤波与频谱检查 -> `B`
- QPSK 或 BER 验证 -> `A`
- 带增强模块的通信骨架 -> `D`
- DSSS 参数切换与契约校验 -> `F0`
- 混合信号扩展专题 -> `E`
