# 参数契约

## 用途

本文件用于在宣称执行闭环完成前，审计参数契约与可观测性。

## 通用契约

- 采样率
- 符号率
- 每符号采样数
- 插值与抽取因子
- 输入、索引与系数维度
- 调制映射与相位偏移
- 判决类型
- 仿真起始时间、终止时间、求解器与步长
- 关键可观测变量

## 通信专项契约

- Tx 与 Rx 的采样假设必须一致
- 映射假设必须一致
- 同步假设必须一致
- BER 或符号判决的可观测性必须显式存在
- 关键参数必须能够从模型意图追溯到执行结果

## DSSS 专项契约

- 默认优先从 `F0` 开始
- 保持 `PG`、PN 长度、选择器绑定以及 Tx/Rx 对称性一致
- 显式核查断言逻辑
- 显式核查 `CounterLimited` 与 `LookupTable1D` 的维度约束

## 闭环规则

在参数契约、可观测性和证据读取路径全部明确之前，不要将任务报告为完成。
