# 排障与回退

## 用途

本文件用于在结构失败、执行失败、指标失败和检索失败时提供统一排障与回退入口。

## 失败分类

- 结构失败：`check_model` 未通过
- 执行失败：仿真未完成或结果不可读
- 指标失败：KPI 未达到阈值
- 检索失败：检索资料不足以支持当前决策

## 排障顺序

1. 先识别失败类型
2. 结构失败优先回查连线、维度、采样配置
3. 执行失败优先回查求解设置、时序设置、参数一致性
4. DSSS 失败优先回查选择器绑定、Tx/Rx PN 对称、PG 联动与断言
5. 指标失败回到 `playbooks.md` 与 `modeling-methods.md` 复核方案

## 检索失败回退

- 不得因为检索失败直接中断建模闭环
- 改用模板法、库文档与 API 文档回退
- 记录 `fallback_used=true` 与原因
- 明确当前仍然存在的信息缺口

## 报告规则

- 结构失败时，只能报告“未通过结构检查”
- 执行失败时，只能报告“未通过行为验证”
- KPI 不达标时，必须附改进方向与下一轮计划
