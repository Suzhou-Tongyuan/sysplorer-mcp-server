## Skill 简要介绍（模型开发调试类）

### 一、简要概述

| 字段 | 内容 |
|------|------|
| **Skill 名称** | `ty-sysblock-signal-modeling` |
| **Skill 中文名称** | Sysblock 信号与通信建模 |
| **Skill 描述** | 用于在 Sysplorer 中执行 Sysblock 信号处理、通信链路、频谱验证、多速率处理、BER、同步和混合信号相关建模与验证。 |
| **版本信息** | `1.0` |
| **Skill 类型** | 模型开发调试（Model Development & Debugging） |

---

### 二、触发条件

- 当 `ty-sysplorer-modeling-rules` 已将任务分流到 Sysblock 路径，且任务属于信号处理或通信链路建模时触发。
- 适用于滤波、频谱验证、多速率处理、特征提取、基带链路、BER、QPSK/QAM、同步、DSSS 和混合信号任务。
- 适用于 `TYDSPSystem`、`TYCommunication`、`TYMixedSignal` 或 `SysplorerEmbeddedCoder` 相关任务。
- 不适用于 Modelica 物理模型、纯 API 查询或不需要信号领域工作流的孤立端口/参数核对。

---

### 三、核心功能

- 支持信号处理和通信任务分类、模板选择、playbook 选择和参数契约整理。
- 支持构建最小可运行信号链，再扩展频谱、BER、同步状态或时序指标验证。
- 支持通过官方 Sysplorer API 创建和编辑 Sysblock 拓扑。
- 支持排查参数、可观测变量、结果异常、降级策略和验证证据。

---

### 四、适用场景

- 搭建滤波器、频谱分析、多速率处理或特征提取模型。
- 搭建 QPSK/QAM、BER、同步、DSSS 或基带通信链路。
- 验证信号链输出变量、频谱、误码率、同步状态或时序指标。
- 输出任务类别、模板/playbook、库范围、关键参数、观测变量和验证结论。
