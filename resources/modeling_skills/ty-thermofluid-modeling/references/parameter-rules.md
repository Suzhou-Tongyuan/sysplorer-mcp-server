# 参数规则

本文件用于定义热流体与空气处理模型的关键参数、默认来源和设置顺序。

## 设置顺序

1. 先设介质与相态假设。
2. 再设边界工况。
3. 再设主设备额定参数。
4. 再设主管段和阻力件参数。
5. 再设换热与热边界参数。
6. 最后设初值、控制器和仿真设置。

## 关键参数表

| 参数类别 | 适用对象 | 是否必设 | 默认来源 | 设置要点 |
| --- | --- | --- | --- | --- |
| 介质包与介质基类 | 所有流体系统 | 是 | 用户工况或介质约束 | 先决定 `TYMedia` 还是 `Modelica.Media`，再决定基类约束范围 |
| 相态与相变假设 | 热流体、制冷剂、蒸汽系统 | 是 | 用户工况 | 未确认前不要直接锁死两相换热器或单相管道 |
| 气体组分 | 湿空气、空气品质控制系统 | 是 | 用户工况 | 涉及湿度必须含水蒸气，涉及净化必须含 `CO2` |
| 入口边界压力/温度/流量 | 开环主链路 | 是 | 设计输入、样例工况或用户要求 | 入口边界要先于主管段和负载段设置 |
| 出口边界压力或回收条件 | 开环或闭环系统 | 是 | 设计输入、样例工况或用户要求 | 先开环时优先用边界，闭环时再替换为回路组件 |
| 泵/风机/压缩机额定参数 | 机械设备 | 是 | 设备要求或样例工况 | 先设额定量，再调整控制或开度 |
| 阀门开度、孔径或阻力参数 | 阻性件 | 是 | 设计输入或经验范围 | 卡滞、除零和过大压降优先回查这一组参数 |
| 管径、长度、分段数 | 管段 | 是 | 几何设计输入 | 受热段和测试段优先显式给出几何信息 |
| `frictionDistribution` | 离散管道 | 条件必设 | 上下游组件交错关系 | 不要保留默认值而不说明原因 |
| 换热面积、热流边界、传热系数 | 换热段 | 条件必设 | 设计输入或样例工况 | 先保证热边界和流体边界分离清晰 |
| 初始压力、初始温度、初始液位 | 动态系统 | 建议 | 经验初值或样例工况 | 初始化困难时优先补齐 |
| 控制器采样周期、限幅和初值 | 控制闭环 | 条件必设 | 控制策略约束 | 在开环完成本次所需校核前不要过早复杂化控制器；不据此追加仿真 |
| 仿真终止时间、步长或输出粒度 | 所有仿真任务 | 是 | 验证目标 | 验证瞬态和稳态时使用不同时间尺度 |

## 离散管道选择规则

| 上下游关系 | 推荐 `frictionDistribution` | 说明 |
| --- | --- | --- |
| 上游偏容性，下游偏阻性 | `FricVol` | 让边界与相邻组件尽量交错 |
| 上游偏阻性，下游偏容性 | `VolFric` | 让边界与相邻组件尽量交错 |
| 两侧都偏阻性 | `FricFric` | 仅在确有必要时使用 |
| 两侧都偏容性 | `VolVol` | 仅在确有必要时使用 |

## 参数来源优先级

1. 用户明确给出的设计输入。
2. 用户指定的样例或现有模型参数。
3. 组件手册或模板中的推荐工况。
4. 经验默认值。

使用经验默认值时，必须在交付中标明其为暂定值。
