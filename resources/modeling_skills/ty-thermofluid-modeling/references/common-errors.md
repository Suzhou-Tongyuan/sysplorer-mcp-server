# 常见错误

本文件用于汇总热流体与空气处理模型的常见问题、优先排查顺序和修复建议。

## 排查总原则

1. 先确认任务当前卡在 `check`、`translate`、`simulate` 还是 `result verify`。
2. 先查介质与拓扑，再查参数与图面。
3. 优先做最小修复，不同时改动多个物理假设。
4. 闭环系统出问题时，优先退回开环或分段验证。

## 常见问题表

| 现象 | 可能原因 | 优先排查顺序 | 修复建议 |
| --- | --- | --- | --- |
| `replaceable package Medium` 不匹配 | 连续回路介质不一致、介质基类约束过窄 | 介质包 -> 基类约束 -> 连续回路连接 | 统一连续回路介质，必要时放宽到更合适的基类 |
| `check` 失败，端口或连接不兼容 | 连接方向错误、接口类型不一致、缺少必要边界 | 主回路拓扑 -> 端口类型 -> 边界组件 | 先补齐边界，再修正连接方向和接口匹配 |
| 热流体系统 `NaN`、除零、卡滞 | 阀孔径过小、流量过大、管段参数不合理 | 阀门参数 -> 边界工况 -> 管径长度 -> 开闭环结构 | 优先降低流量、放大孔径、调整几何，必要时退回开环 |
| 空气处理系统算不动 | 介质成分不满足组件要求 | 气体组分 -> 处理器件适配性 -> 传感器变量 | 使用包含水蒸气或 `CO2` 的混合气体介质 |
| 湿度处理前后几乎无变化 | 没有水蒸气组分、传感器放置位置不当、处理段未真正起作用 | 介质组分 -> 处理段参数 -> 传感器位置 | 先确认混合气体定义，再检查处理段和测点布置 |
| 结果变量缺失 | 没有成功打开结果、变量名判断错误、仿真未完成 | 结果文件 -> 仿真状态 -> 变量命名 | 先确认仿真成功，再按组件与端口路径重找变量 |
| 图面严重变形 | `Placement` 非等比例、旋转镜像误用 | `extent` -> 旋转 -> 组件间距 | 恢复对称 `extent`，重新分区布局 |
| 图面重叠或连线难辨认 | 先连线后排布、间距不足 | 主体布局 -> 热边界 -> 传感器与标签 | 先粗布局，再重拉连接线，保持水平/垂直走线 |
| 闭环系统难以定位问题 | 同时引入回流、旁通、控制器 | 开环骨架 -> 回流段 -> 控制器 | 每次只引入一类新增要素，并在每步后重新检查 |

## 介质相关优先检查项

- 是否明确了单相/两相。
- 是否允许或预期发生相变。
- 湿空气是否真的包含水蒸气。
- `CO2` 净化任务是否真的包含 `CO2` 组分。
- 浓度型介质是否已按文本建模显式声明。

## 管道与离散方式优先检查项

- 是否误把需要分布效应的主管段简化成集总管道。
- `frictionDistribution` 是否与上下游偏阻性/偏容性关系一致。
- 受热段、冷却段和测试段是否具有合理几何参数。
- 乙二醇或丙二醇回路是否已明确浓度定义和介质来源。
