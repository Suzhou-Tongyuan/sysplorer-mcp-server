# 模型库介绍

## 模型库概述

空气处理与通风模型库V1.1.0作为产品货架体系中一款专业基础库，提供了空气处理与通风系统构成所需的零部件模型，包括阀类、管路、压缩机和风扇、空气处理、换热器、控制器、传感器设备模型，典型示例覆盖了空气处理与通风系统的常见应用场景。该模型库支持快速构建空气处理与通风系统数字化模型，进行系统的设计与性能优化，涵盖从空气净化、湿度调节、温度控制到能效优化的各个方面。

此外，空气处理与通风模型库和基础热流体模型库、热流介质模型库及行业模型库配合使用可满足建筑暖通、环控领域设计、验证和运维阶段建模仿真需求。

## 模型库目录

空气处理与通风模型库是采用模块化建模思想，基于多领域统一建模规范Modelica，建立的通用空气处理与通风系统模型库。如**图2‑1**所示，空气处理与通风模型库将空气处理与通风模型按功能归类，提供了阀门（Valves）、管路（Pipes）、压缩机和风扇（CompressorsAndFans）、空气处理组件（AirTreatment）、换热器（HeatExchangers）、控制器（Controllers）、边界（Sources）、传感器（Sensors）、辅件（Auxiliaries）等组件模型，以及用户指南（UsersGuide）、自定义混合气体介质（Media）和可用于二次开发的接口（Interfaces）等。此外，空气处理与通风模型库中还提供了5个空气处理与通风系统模型，供初学者练习参考，具体获取方式可参考模型库中的案例入口指南。

阀库包含了空气处理与通风系统中常用的阀类模型，如节流阀、减压阀、温度控制阀和三通阀等。阀类模型的建模方式是选择合适的气阻模型作为阀孔，再根据不同阀的功能对各阀孔的通流状态进行合适控制，能够实现气体流量、压力、流向和温度的精确调节。

管路库包含不同管路类型和常用接头。其中管路考虑了气体流动过程中的压损和气体压缩产生的压力变化，同时根据应用场景的不同分为侧重于效率的集总参数管路和侧重于精度的分布式管路，以满足不同长度、直径和精度要求的管路建模；接头包括直角三通、突变管路和直角弯管三种常用的类型，考虑了局部压力损失，可以根据不同需求设定不同的规格，便于用户进行复杂的气体输送管网设计。

压缩机和风扇库包含常用的压缩机和风扇类型。其中压缩机模型在建立时综合考虑了结构类型、压缩、泄露，并考虑了气体经过压缩机后的能量变化，满足空调与制冷系统、天然气输送等场景对压缩机的需求；风扇模型支持修改结构参数、性能参数获得不同规格的风扇模型。

空气处理库包含对空气中水蒸气含量、CO2含量进行控制的各种组件，如不同类型干燥器、增湿器、分离器、CO2净化器，用户可以选择不同的设备实现气流的湿度控制。

换热器库包含管翅式换热器和通用换热器。其中通用式换热器不考虑结构形式、介质状态对换热过程的影响，管翅式换热器考虑结构对换热性能的影响，用户可以设定不同的结构参数模拟不同规格的管翅式换热器。

控制器库包含PI控制器和PID控制器，这两个控制器都支持输出限制和抗绕组补偿。

传感器库中包括检测气体流动状态的各类传感器，用于监测系统中的压力、流量、湿度、焓值等量变化，实现对气体流动过程的精确控制。

边界库中包含压力边界、质量流量边界、温度边界和热流边界，能够支持多种空气处理与通风系统的边界输入假设。

气体介质库中提供自定义混合气体介质的示例，帮助用户按需求自定义混合气体介质。

辅件库中提供气体状态显示模块，实时显示系统特定节点的气体状态变化情况，R134a压焓图和焓湿图辅助进行空调系统优化设计和湿度控制，体积模块用于模拟腔室内的压力、温度、组分变化。

## 应用场景

1. 方案设计阶段

在方案设计阶段，可用于选择合适的组件，包括压缩机、换热器、管路和阀类等，以满足空气处理与通风系统的工作条件和性能要求，并进行组合、调整和优化，支撑系统功能和性能的初步验证评价，实现系统多方案优选分析。

* 空调系统组件选型

在优化设计空调系统时，需要根据具体的工作条件和性能要求，选择合适的各类组件。首先，压缩机应根据系统的功率需求、气体流量和压力要求进行选择，以确保能够提供稳定的气体压缩和流量调节。换热器的选择则需考虑热交换效率、散热能力以及与空气流量和温度要求的匹配，以实现高效的热能转换和空气温度控制。膨胀阀等应根据系统的控制需求、压力范围来选型，确保系统在不同工作状态下具备灵活的调节能力和安全性。综合考虑这些组件的特性和相互配合，能够有效保障空调系统在多变的环境条件下高效稳定运行，满足温湿度、空气质量等性能要求。

* 建筑通风方案选择

通过模拟不同的通风策略分析和评估其效果，比较不同通风模式（如自然通风、机械通风、混合通风等）对室内空气流动、温湿度调节以及污染物（如二氧化碳、颗粒物、挥发性有机化合物等）的去除效率的影响。通过综合分析，设计人员能够选择最适合特定空间需求的通风方案，确保室内空气质量符合健康标准，提升舒适度，并减少能耗和运行成本，最终实现高效、可持续的室内环境管理。

* 通风系统节能设计

对比不同的通风类型（如自然通风、机械通风、热回收通风等）及其设备配置时，综合考虑各方案的能效、舒适性、成本和环境影响。自然通风依赖建筑的自然气流和外部环境差异，不需要额外的能源消耗。机械通风通过风机等设备强制空气流通，能够实现精确控制，但需要消耗电力，可能增加能源费用。热回收通风通过回收排气中的热量来预热进入的新鲜空气，从而显著提高能效，降低对加热和制冷的需求，可在保持舒适的室内环境的同时，减少能源消耗。

1. 实验验证阶段

在实验验证阶段，采用空气处理与通风模型库，完成不同场景下的空气质量控制系统设计，如舱室氧气供给系统、建筑通风系统等，可用于性能验证、控制策略验证、故障模拟、故障诊断以及参数调整和系统优化等应用场景，能够更加准确和有效地验证暖通系统和环控系统，确保其性能和可靠性符合设计要求。

* 空气质量优化系统性能验证

空气质量优化系统性能验证需要通过建立精细的数值模拟模型来动态模拟室内空气中二氧化碳、挥发性有机化合物、颗粒物等污染物的浓度变化。通过模拟空气流动、室内温湿度变化以及不同污染源（如人员呼吸、家电使用、家具材料等）污染物排放过程，验证空气质量优化系统对污染物的控制性能。

* 空气处理与通风系统控制策略验证

验证通风系统控制策略是否能够有效应对不同的负荷需求和环境变化，涉及对通风量、温度和湿度控制系统的动态建模和仿真分析。通过仿真可以验证不同控制策略（如基于室内温湿度、CO₂浓度、空气质量的需求响应控制）在面对环境变化时的响应能力，分析系统是否能够在多变的室内外环境条件下持续优化通风效率，确保能源消耗最小化的同时，达到最佳的舒适性和空气质量控制效果。

1. 运行维护阶段

在运行维护阶段，可用于搭建在线的数字化空调系统，进行运行状态监测和故障模拟，以帮助运维人员进行系统的日常维护和故障排除，保证系统的稳定运行和可靠性。

* 空调系统状态监控

通过仿真能够监测到空调系统的关键设备（如压缩机、冷凝器、风机、膨胀阀等）的状态，还能够在出现故障或性能下降时，提前发出预警信号，帮助运维人员及时掌握系统的运行状况。

## 功能特点

* 提供丰富的空气系统组件模型

模型库涵盖了常用的空气系统组件模型，包含多种类型压缩机和风扇、加湿器和干燥器、不同结构的换热器、阀类、管道以及各种传感器等，覆盖多个行业的空气系统建模需求，帮助用户快速实现系统设计和验证。

* 提供准确可靠的物理模型

模型库采用精确的物理模型来描述空气系统中的各种组件，包括压气机、换热器、空气处理组件等。这些模型经过验证和优化，能够准确地预测组件的行为和性能，提供可靠的仿真结果。

* 满足多领域环境控制需求

模型库满足航空、航天、船舶领域温度控制、湿度控制、压力调节、空气供应、空气净化等需求；满足核能领域的核辅助厂房送风、排风、换气、温度控制和压力控制需求，从而限制房间内污染物浓度、维持屋内温度。

* 匹配多种介质

适配多种气体介质和制冷剂介质（如：单质气体、混合气体、冷凝气体、R134制冷剂等），满足空气系统建模需求

## 案例介绍

## 空调系统(AirConditiongingSystem)

1. 介绍

空调系统回路是由多个部件构成的系统，包括压气机、冷凝器、膨胀阀、蒸发器等，制冷剂在其中循环流动，实现能量的搬运和温度控制。空调系统中压缩机负责压缩低压气态制冷剂，将其转化为高压高温气体；冷凝器将高温高压气态制冷剂冷却，释放出热量加热周围环境，达到制热效果，同时制冷剂由高温高压气态变为低温高压液态；膨胀阀控制制冷剂的流量和压力，将其由低温高压液态变为低温低压液态；蒸发器从周围环境吸收热量将制冷器蒸发，达到制冷效果，同时制冷剂由低温低压液态变为低温低压气态，并准备进入压缩机开始新的循环。

1. 描述

结合空调系统实际拓扑结构完成**图5‑2**空调回路模型搭建，空调系统回路包括压气机、冷凝器、膨胀阀、蒸发器、风扇、气源等，系统原理图如下所示：

图5‑2空调系统模型

1. 分析

通过仿真能够准确模拟制冷剂在回路中的流动及相应的物态变化，并计算转移的热量和对周围环境的温度调节效果，进而实现对空调系统的优化设计，达到节能增效目的。

**图5‑3**展示了空调系统在运行中转移能量的变化量，从仿真结果可知，在空调系统达到稳定运行后转移的能量为1138W，而压缩机消耗的功率为449W，即空调系统COP为2.53。

图5‑3蒸发器转移热量变化曲线

**图5‑4**展示了空调系统在运行回路内R134a制冷剂的状态变化，从仿真结果可知，在空调系统稳定运行过程中，制冷剂经压缩机加压后变为全气态，经过冷凝器冷却后变为全液态，经膨胀阀减压后变为气液混合状态，经过蒸发器蒸发后变为全气态。

## 循环复合系统(CirculatoryCompositeSystem)

1. 描述

## 氧气供给系统(OxygenSupplySystem)

1. 介绍

氧气供给系统中氧气由氧气源提供，经控制阀输送至腔室中，以供给负载的消耗使用，同时产生的二氧化碳由二氧化碳净化器进行吸收，从而保证腔室内的空气各组分浓度处于合理范围。

1. 描述

氧气供给系统包括气源、电磁阀、减压阀、节流阀、容腔、风扇、二氧化碳净化器和负载模块等，系统原理图如**图5‑12**所示：

1. 介质选择

空气处理与通风模型库中部分组件要求气体介质中包含特定的成分才能进行计算，因此在进行介质选择时需要考虑系统中各个组件对介质的支持情况：

|  |  |  |
| --- | --- | --- |
| * 干燥器、增湿器、分离器以及湿度传感器等模型主要针对气体介质中的水蒸气进行处理，因此需要气体成分中包含水蒸气 | * 管翅式换热器、通用换热器不仅可以应用于气体之间的换热，也可以进行气体与热流体之间的换热（如制冷剂），因此介质类型支持所有流体。同时，简单压缩机也可以对热流体进行压缩处理 | * CO2净化器针对气体中的CO2 进行去除，因此要求混合气体中包含CO2 |
|  |  |  |
