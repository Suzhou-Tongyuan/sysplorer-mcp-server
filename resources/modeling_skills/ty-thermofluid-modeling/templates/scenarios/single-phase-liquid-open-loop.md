# 液体单相开环主回路模板

## 适用场景

- 水、油、乙二醇等液体单相主回路。
- 需要先做最小可运行骨架，再逐步闭环。

本模板继承父级确认的请求终点：文件交付或离线评审不自动触发软件启动；无实时操作请求时只做适用静态检查，明确请求的实时只读查询遵守本技能通用动作规则；check-only 不追加翻译或仿真；结果变量仅在结果验收需要时读取。

## 默认拓扑

`入口边界 -> 泵或驱动件 -> 主管段 -> 阀或测试段 -> 受热段/冷却段/负载 -> 出口边界`

## 必配要素

- 入口边界
- 出口边界
- 主驱动件
- 至少一段主管段
- 至少一组关键传感器

## 按需验证量（仅结果验收适用时）

- 入口压力
- 出口压力
- 质量流量
- 主段前后温度

## 建模提示

- 需要分布效应时，优先使用离散管道。
- 闭环改造前，先在开环状态完成本次所需的静态检查或运行阶段；只有请求包含仿真时，才用一次有效仿真作为该阶段证据。
