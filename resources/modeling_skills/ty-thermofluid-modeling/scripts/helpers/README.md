# 热流体离线辅助脚本

`verify-key-results.py <results.json>` 仅在当前任务要求结果核验且已有结果证据时按需使用，不连接或启动 Sysplorer，不增加验收变量。输入格式见脚本开头示例。

| 退出码 | 状态 | 含义 |
|---|---|---|
| 0 | `PASSED` | 非空列表中的全部检查项通过 |
| 1 | `FAILED` | 阈值失败、字段类型错误、非对象条目或文件/JSON 错误 |
| 2 | `NOT_VALIDATED` | 缺少或没有验证项，尚未进行有效核验 |

`passed` 只接受 JSON 布尔值 `true` / `false`，提供时优先于数值阈值。数值与已提供的上下界必须为有限数，布尔值、字符串、`null`、NaN 和无穷值不作为有效数值；下界不能大于上界。无验证项不等于验证通过，也不自动表示父任务 `not_required`。父级任务已经明确不要求结果时，无需调用本脚本。

`extract-required-params.py` 为场景模板的输入提取辅助工具；其输出须结合当前任务范围复核，不能直接作为新增验收要求。
