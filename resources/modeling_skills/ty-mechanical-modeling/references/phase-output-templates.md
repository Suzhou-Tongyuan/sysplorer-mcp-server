# Phase Output Templates

仅使用当前请求适用字段；普通任务提供简洁交付证据，正式报告按请求生成。检查、翻译、仿真、结果和图面各自记录 `passed` / `failed` / `blocked` / `not_required`，模板不预设动作已执行。

职责说明：

- 本文件是各阶段字段定义的权威来源
- `templates/task-output-template.md` 是将这些阶段模板拼装成一次完整任务输出的总模板
