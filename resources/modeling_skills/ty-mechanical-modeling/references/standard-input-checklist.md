# Standard Input Checklist

建模开始前，优先按本清单收集输入。缺失信息允许进入最小闭环建模，但必须在需求识别结果中显式标记“当前信息缺口”。

---

## 1. 需求输入

- 建模对象
  例如：液压系统、热管理系统、电路系统、机械系统、多物理场系统
- 建模目标
  例如：功能验证、控制逻辑验证、性能分析、参数敏感性分析、故障分析
- 预期动作 / 工况
  例如：升起、下降、保压、同步控制、温度调节、速度控制
- 系统边界
  哪些部分详细建模，哪些部分简化
- 输入信号
  例如：阶跃、脉冲、正弦、控制指令、工况曲线
- 输出指标
  例如：压力、流量、位移、温度、速度、电压、电流、功率
- 仿真时长与步长要求
- 所用库约束
  例如：必须使用 Sysplorer 内置库、业务私有库、指定商业库
- 交付要求
  例如：模型文件、结构说明、参数表、仿真结果、问题清单

---

## 2. 补充输入

- 系统原理图
- P&ID 图
- 电路图
- 机械结构图
- 用户手册
- 对标案例
- 参考模型
- 历史报错日志

---

## 3. 最低通过标准

在进入组件映射前，至少应能回答：

1. 要建什么系统
2. 为什么建
3. 用什么库建
4. 验收是否要求结果；要求时看哪些结果，否则 `not_required`
5. 怎样算建模成功
