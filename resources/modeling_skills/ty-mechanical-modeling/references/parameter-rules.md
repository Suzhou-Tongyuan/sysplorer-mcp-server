# 参数规则 / Parameter Rules

用于统一 TY 机械模型的参数获取方式、设置顺序和默认来源。

## 参数获取强制规则

- 候选组件确定后，必须先通过 Sysplorer 参数查询接口获取真实参数名，再进行参数赋值、参数修改和 `redeclare`。
- 未查询到真实参数名时，不得凭经验猜测参数名直接赋值。
- 若同一组件存在多个候选参数版本，优先以当前实际加载库中的查询结果为准。
- 参数查询应与端口/接口查询配套完成：至少确认关键连接器名称、连接器物理域、信号输入输出方向和 inner/outer 依赖。
- 跨库组件连接前，先确认两个端口在同一物理域或存在明确转换组件；不能只因名称相似就连接。

## 参数设置顺序

1. 世界、重力、参考系和边界环境参数。
2. 主体部件的质量、惯量、几何和安装关系参数。
3. 关节、约束、接触、弹簧阻尼、摩擦等相互作用参数。
4. 动力源、执行器、外载和工况激励参数。
5. 传感器、结果观测和测试用例辅助参数。
6. 初始化、求解相关或样例验证专用参数。

## 参数类别清单

| 参数类别 | 适用对象 | 是否必设 | 默认来源 | 备注 |
|---|---|---|---|---|
| 世界与重力参数 | 2D/3D/多体模型 | 是 | 用户输入或场景模板 | 必须先设，避免参考系漂移 |
| 质量与转动惯量 | 刚体、转轴、传动件 | 是 | 用户输入、已有模型或模板 | 必须与目标工况数量级一致 |
| 几何尺寸与安装位置 | 刚体、梁、接触对象 | 是 | 用户输入或已有模型 | 决定连接关系与接触行为 |
| 刚度、阻尼、摩擦参数 | 弹簧阻尼、接触、副约束 | 视场景必设 | 模板、已有模型或经验基线 | 首轮宜采用稳定保守值，再细化 |
| 执行器与激励参数 | 动力源、力源、力矩源、外载 | 是 | 用户输入或测试工况 | 必须与输入边界一致 |
| 初始位置与速度 | 多体、接触、动力学模型 | 推荐 | 用户输入、已有模型或物理平衡假设 | 翻译与仿真失败时优先复查 |
| 观测与输出参数 | 传感器、测量模块 | 推荐 | 结果验证计划 | 与关键变量一一对应 |

## 参数来源优先级

1. 用户明确输入。
2. 已验证通过的现有模型参数。
3. 官方样例中可解释的参数习惯。
4. TY 库默认值或模板占位值。

## 参数设置纪律

- 首轮建模优先保证参数闭环可检查，不要在未完成最小闭环前展开大规模调参。
- 修复任务优先只调整与当前失败阶段直接相关的参数。
- 样例验证任务可以参考样例参数习惯，但必须明确哪些参数来自样例，哪些参数来自当前用户场景。
- 任意假设参数都必须在最终交付中说明来源和风险。
- 同一失败点不要通过大范围随机改参数试错；先判断是否为结构、接口、自由度或方程平衡问题。
- 生成可复用模型库时，仅在用户请求的文档内容包含参数说明时，按父级 Documentation 路径记录所需参数、单位、默认值来源和适用范围；默认写入 Documentation.info，独立 Markdown 仅在明确要求时创建。未请求文档时为 `not_required`，仅保留必要的参数单位、代码级简短描述和本次交付所需假设。
