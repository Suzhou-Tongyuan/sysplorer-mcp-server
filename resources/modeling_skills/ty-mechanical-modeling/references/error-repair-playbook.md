# Error Repair Playbook

已有故障由父级调试路线主导，本文件仅补充机械根因与最小修复；新建失败则留在原流程并复验受影响阶段。会话、错误解析和重试继承父级 shared-standards；只读诊断不得无条件调用可能自动写回的 check。

---

## 1. 标准修复流程

```text
识别错误现象
-> 提取报错信息
-> 判断错误类别
-> 定位具体问题
-> 若同一失败点多轮盲修仍未通过，先做文档核对、组件级最小验证或分层隔离
-> 执行修复
-> 重跑失败步骤
-> 验证修复是否生效
```

---

## 2. 错误分类与修复策略

### A. 连接类错误

典型现象：

- 端口未连接
- 端口连接错误
- 域不匹配
- 信号端与物理端误连

修复策略：

- 补齐缺失连接
- 替换错误连接对象
- 增加转换模块
- 删除无效连接

### B. 参数类错误

典型现象：

- 参数缺失
- 参数越界
- 单位错误
- 数量级异常

修复策略：

- 补充默认参数
- 调整参数范围
- 统一单位
- 修正初值

### C. 结构类错误

典型现象：

- 缺求解器配置
- 缺参考节点
- 存在孤立子系统
- 回路不闭合

修复策略：

- 增加基础配置块
- 重构连接关系
- 删除无效孤立部分
- 重新组织主回路

### D. 翻译类错误

典型现象：

- 方程不平衡
- 初始化失败
- 介质模型不兼容
- 模型结构不可翻译

修复策略：

- 检查变量与方程关系
- 放松初始化约束
- 更换兼容组件
- 减少过度约束

### E. 仿真类错误

典型现象：

- 发散
- 步长过小
- 状态爆炸
- 结果 NaN

修复策略：

- 调整求解器
- 缩小激励幅值
- 修改初始条件
- 增加阻尼/泄漏/缓冲
- 检查硬开关与不连续问题

### F. 结果类错误

先区分结果查询/后处理错误与模型行为错误。仅修正变量名、结果路径、查询时间或后处理逻辑时，确认既有结果来自成功仿真且与目标模型、参数和工况对应，再复用该结果重做受影响查询/核验；不触发重新仿真。若结果缺失、失效或来源无法确认，记录阻塞，不能因查询失败自动启动软件或仿真，也不能用残留旧结果掩盖新仿真失败。

典型现象：

- 能跑但结果不对
- 动作方向反了
- 曲线趋势明显异常
- 稳态值不合理

修复策略：

- 检查控制逻辑方向
- 检查执行机构连接极性
- 检查参数量级
- 检查边界条件与负载设置

## 3. 回退规则

- `check` 失败：修复后重跑 `check`
- `layout` / 图面验收失败：按父级 Gate 6 修复；纯视觉缺陷不阻止 check、翻译或仿真。写回后按实际影响重新检查，完整图形交付仍须闭环。
- `translate` 失败：按父级闭环回到翻译前的必要阶段
- `simulate` 失败：按父级闭环回到仿真前的必要阶段
- `result verify` 不通过：先按 F 类区分根因；仅查询/后处理修正时复用有效既有结果，只重做受影响查询和核验。只有改变模型行为、参数、工况、仿真配置或导致既有结果失效的修复，才按父级受影响阶段和用户授权范围重新仿真；未获运行授权时交付修复内容与待验证项。纯图形修改按实际影响完成适用 Gate 6，不自动重仿真。
