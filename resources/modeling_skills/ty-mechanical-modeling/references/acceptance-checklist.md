# 验收清单 / Acceptance Checklist

用于交付前确认 TY 机械建模任务是否达到“可复核、可交付、未夸大完成度”的标准。

## 必须满足的验收项

| 验收项 | 必须满足 |
|---|---|
| 任务对象清晰 | 已说明任务类型、目标系统、运动维度和目标工况 |
| 库边界合规 | 已说明机械子系统 TY/标准库组件及职责，保留项目其他已选领域；商业组合固定 `Modelica 4.0.0.TY.1` |
| 查询范围可控 | 已说明组件/文档查询范围；未对无关子库做重复深读 |
| 接口已确认 | 已确认关键组件端口域、跨库连接兼容性和 inner/outer world 需求 |
| 静态预检完成 | 已完成世界/参考、自由度或方程直觉、参数量级预检；仅在要求结果核验时预检结果变量 |
| 参数来源清楚 | 已说明哪些参数来自用户输入、已有模型、样例或默认值 |
| 参数已核对 | 已通过 Sysplorer 参数查询接口核对关键组件的真实参数名 |
| 闭环机构处理正确 | 曲柄滑块、曲柄连杆等平面带环或闭环多体机构已说明切割铰位置和被替换的转动副 |
| 执行动作真实 | 已明确标注父级闭环的实际完成情况 |
| 多体动画检查 | 仅在用户明确要求动画时打开并记录观察结论；否则为 `not_required` |
| 验证结论明确 | 用户要求结果时列出关键变量、判断标准、验证结论和异常解释；否则结果验证为 `not_required` |
| 工具重试受控 | 未在同一失败点无差别重复调用；超时或失败时已隔离根因或透明说明 |
| 文档可复用 | 仅在用户明确请求文档时，按父级 Documentation 路径及请求范围验收用途、参数、单位、限制或运行方式；默认写入 Documentation.info，独立 Markdown 仅在明确要求时验收。未请求文档时为 `not_required`，必要的代码级简短描述与单位仍保留 |
| 未闭环项透明 | 已说明当前风险、未闭环问题和下一步建议 |

## 不得宣称完成的情况

- 验收要求 check 时未执行 check，却声称检查通过；仅按用户约定完成范围评价，不为离线、文档或代码任务追加运行验证。
- 验收要求的 translate 或 simulate 失败，却以猜测性建议替代实际成功证据。
- 用户要求结果曲线，但输出后未说明关键变量和判断标准。
- 用户要求多体动画，但未在后处理中打开并检查动画。
- 曲柄滑块、曲柄连杆等闭环机构仍用普通转动副完整闭环，未使用切割铰或未说明切割位置。
- 使用官方样例直接包装成交付结果。
- 未核对真实参数名，却默认参数已经生效。
- 跨库连接未确认接口类型，却直接把 `flange`、`frame` 或信号端相连。
- 方程不平衡或自由度明显被锁死，仍宣称模型开发完成。
- 关键工具调用已超时/失败，但未说明验证链路停在哪一步。

## 推荐交付结构

1. `建模目标 / Modeling target`
2. `使用库边界 / Allowed libraries`
3. `选用组件 / Selected components`
4. `执行动作 / Actions performed`
5. `校验结果 / Validation result`
6. `下一步检查项 / Next checks`

若验收仅要求 `check + translate + simulate`，三项成功且父流程必需门禁完成后立即结束，不追加结果、曲线或动画检查。
