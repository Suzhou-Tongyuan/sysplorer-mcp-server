# 响应优化使用说明

本文面向通过 Python API 使用 `mworks.sysplorer.DesignOptMro` 的场景。

## 基本导入

```python
import mworks.sysplorer as pyapi
import mworks.sysplorer.DesignOptMro as mro
```

DesignOptMro 是独立工具箱模块，不能假设函数存在于主 `mworks.sysplorer` 命名空间中。

## 推荐执行顺序

1. 加载库并打开模型。
2. `mro.InitialApp(modelName)` 初始化响应优化。
3. 查询可用调节参数和变量：

```python
print(mro.GetTunerParam())
print(mro.GetVariable())
```

4. 选择并配置调节参数：

```python
mro.SelectTunerParam(("length",))
mro.ConfigTunerParam("length", minVal=0.001, maxVal=199.99, initialVal=10.0)
```

5. 新建并配置需求：

```python
mro.NewVariablePropertyRequirement("Req_1")
mro.ConfigVariablePropertyRequirement("Req_1", "Final Value", "Maximization")
```

6. 新建变量集并绑定需求：

```python
mro.NewVariableSet("Set_1", ("area",))
mro.SetRequirementVariableSet("Req_1", ("Set_1",))
```

7. 可选配置仿真和优化选项：

```python
mro.SetSimulationOption(startTime=0, endTime=1, stepNumber=500)
mro.SetOptimizeOption(continueOptimize=True, parallelNum=4)
```

8. 可选选择算法：

```python
mro.SelectAlgorithm("PSO")
mro.ConfigPSOAlgorithm(maxIterStep=100, populationSize=20)
```

9. 先评估，再优化：

```python
mro.StartEvaluate()
mro.StartOptimize()
```

10. 获取结果：

```python
data = mro.GetOptimizeData()
print(data["params"])
print(data["reqs"])
```

11. 关闭响应优化：

```python
mro.CloseApp()
```

## 需求类型选择

- 只关心终值、最大值、最小值、平均值等标量属性时，用变量属性需求。
- 关心阶跃响应形态时，用阶跃响应需求。
- 要限制变量曲线不越过某条线性边界时，用变量线性边界需求。
- 要让变量跟踪给定时间序列时，用变量追踪需求。

## 常见注意事项

- 调节参数和固定参数互斥。
- 需求必须关联变量集。
- `SelectRequirement` 可选；不调用时，已创建需求默认参与优化。
- 源码中的线性边界函数名是 `NewVariableLinearBoundRequirement` 和 `ConfigVariableLinearBoundRequirement`。
- 源码中的 `SetSimulationOption` 参数名是 `stepNumber`。
- 源码中的 `SetOptimizeOption` 参数名是 `parallelNum`。
- 在 MCP 工作流中不要调用 `ClearAll` 或 `ChangeDirectory`。
