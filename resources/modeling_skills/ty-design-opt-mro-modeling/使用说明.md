# ty-design-opt-mro-modeling 使用说明

本技能用于 Sysplorer 响应优化工具箱 `DesignOptMro` 的 Python API 辅助。

## 适用任务

- 编写响应优化脚本。
- 查询 DesignOptMro API 签名、参数和返回值。
- 组织调节参数、固定参数、需求和变量集。
- 配置 PSO/GA 等优化算法。
- 执行评估、优化并读取结果。
- 将 2024b 文档示例改写为符合 MCP 安全约定的脚本。

## 主要资料

- `SKILL.md`：面向 Codex/MCP 的技能入口。
- `SKILL_ZH.md`：中文概览。
- `references/DesignOptMro.md`：API 参考。
- `references/响应优化使用说明.md`：工作流说明。
- `references/响应优化demo说明.md`：矩形面积优化示例。

## 安全约定

不要在 MCP 脚本中调用 `ClearAll` 或 `ChangeDirectory`。响应优化结束后使用：

```python
mro.CloseApp()
```

如果脚本自己启动并拥有 Sysplorer 进程，可再调用：

```python
pyapi.Exit()
```
