本文档总结在 Sysplorer 中使用 `DesignOptMpe` 进行参数估计/参数标定的实操方法，重点覆盖：

- 标准工作流
- 常用 API
- 参数、变量、测量数据的配置方法
- 残差函数与算法选择
- 常见踩坑点
- 可直接复用的脚本模板

适用场景：

- 需要基于 `DesignOptMpe.py` 跑参数估计
- 需要把模型输出和测量数据做拟合
- 需要快速确认应如何设置调节参数、固定参数、变量映射、残差函数和优化算法

## 1. 基本认识

`DesignOptMpe` 是 Sysplorer 的参数估计工具箱。典型目标是：

- 选择若干模型参数作为待调参数
- 绑定测量数据文件
- 指定模型输出变量和测量列之间的映射关系
- 指定仿真时间与估计时间窗
- 选择残差函数和优化算法
- 启动估计，得到最优参数与残差

典型导入方式：

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptMpe as mpe
```

## 2. 标准工作流

推荐按下面顺序执行：

1. `OpenModelFile(...)` 加载模型文件
2. `InitialApp(modelName)` 初始化参数估计环境
3. `GetTunerParam()` 查看可调参数
4. `SelectTunerParam(...)` 选择待估计参数
5. `ConfigTunerParam(...)` 设置每个待估计参数的上下限和初值
6. `NewExpAttachPath(...)` 绑定测量数据文件
7. `SetEstimateExp(...)` 指定当前估计实验
8. 如果需要固定参数，执行 `SelectFixParam(...)` 和 `ConfigFixParam(...)`
9. `SetSimulateVariable(...)` 建立“模型变量 -> 测量列”映射
10. `SetSimulateOption(...)` 设置仿真时间和估计时间窗
11. `SetEstimateOption(...)` 设置残差函数和并行数
12. `SelectAlgorithm(...)` 选择优化算法
13. `ConfigPSOAlgorithm(...)` 或 `ConfigGAAlgorithm(...)` 配置算法参数
14. `StartEvaluate()` 先评估初值
15. `StartEstimate()` 启动正式估计
16. `GetEstimateResult()` / `GetEstimateParamData(...)` / `GetEstimateReport()` 读取结果
17. `CloseApp()` 收尾

说明：

- `StartEstimate()` 是阻塞接口，必须等待它结束后再读取结果。
- 如果中途提前取结果，容易误判“优化不彻底”。

## 3. 常用 API 一览

### 3.1 初始化与收尾

- `InitialApp(modelName, instPath="")`
- `CloseApp()`

### 3.2 调节参数

- `GetTunerParam()`
- `SelectTunerParam(tuple_of_names)`
- `ConfigTunerParam(paramName, minVal, maxVal, initialVal)`

### 3.3 实验与测量数据

- `NewExpAttachPath(expName, csvPath)`
- `SetEstimateExp(expName)`

### 3.4 固定参数

- `GetFixParam()`
- `SelectFixParam(expName, tuple_of_names)`
- `ConfigFixParam(expName, paramName, initialVal)`

### 3.5 变量映射

- `GetVariable()`
- `GetMeasureVariable(expName)`
- `SetSimulateVariable(expName, simulateVariable, measureVariable)`

### 3.6 仿真与估计设置

- `SetSimulateOption(SimStartTime, SimEndTime, estimateStartTime, estimateEndTime, stepNumber=500)`
- `GetResidualFunc()`
- `SetEstimateOption(residualFunc="Mean Absolute Percentage Error", parallelNum=..., continueEstimate=True)`

### 3.7 算法

- `GetAlgorithm()`
- `SelectAlgorithm(name)`
- `GetCurrentAlgorithm()`
- `ConfigPSOAlgorithm(...)`
- `ConfigGAAlgorithm(...)`

### 3.8 结果读取

- `StartEvaluate()`
- `GetEvaluateResultData()`
- `StartEstimate()`
- `GetEstimateResult()`
- `GetEstimateParamData(resultName)`
- `GetEstimateReport()`
- `GetEstimateResultData()`

## 4. 残差函数支持项

当前支持这 5 种残差函数：

- `Mean Error`
- `Mean Absolute Error`
- `Mean Percentage Error`
- `Mean Absolute Percentage Error`
- `Mean Squared Error`

经验建议：

- 想直接压低曲线点对点差值，优先试 `Mean Absolute Error`
- 想强调相对误差，使用 `Mean Absolute Percentage Error`
- 想放大大误差点影响，使用 `Mean Squared Error`

## 5. 优化算法支持项

当前可用算法：

- `Bobyqa`
- `Cobyla`
- `GA`
- `PSO`
- `Praxis`

经验建议：

- 全局搜索先用 `PSO`
- 已有较好初值后做局部精修，可再尝试 `Bobyqa` 或 `Cobyla`
- 参数较多、模型非线性明显时，`PSO` 通常更稳

## 6. 关键踩坑点

### 6.1 名称必须以工具实际枚举结果为准

不要只看模型源码里写的名字，要以工具枚举结果为准：

- 待调参数看 `GetTunerParam()`
- 固定参数看 `GetFixParam()`
- 变量映射看 `GetVariable()`

例如在 `NewSimplerCar.SimpleCar` 里：

- 不是 `engineTorque.tau_0`
- 而是 `engineTorque1.tau_0`

又例如：

- 不是 `carbody.a`
- 也不是 `carBody.a`
- 而是 `CarBody.a`

`DesignOptMpe` 对大小写和实例名都敏感。

### 6.2 固定参数必须先选再配

固定参数的正确顺序：

```python
mpe.SelectFixParam("exp", ("gearBox.ratio",))
mpe.ConfigFixParam("exp", "gearBox.ratio", 2.34)
```

如果只配不选，通常不会生效。

### 6.3 变量映射左边是模型变量，右边是 CSV 列名

```python
mpe.SetSimulateVariable("exp", "CarBody.a", "acc")
```

含义：

- 左边 `CarBody.a` 是模型仿真结果变量
- 右边 `acc` 是测量文件中的列名

### 6.4 `StartEstimate()` 是阻塞调用

它会一直跑到估计结束。正确做法：

```python
ok = mpe.StartEstimate()
result = mpe.GetEstimateResult()
```

不要在估计未结束时提前根据中间值下结论。

### 6.5 上下限不要乱设

上下限过宽会导致：

- 收敛慢
- 结果漂移
- 局部最优和无效搜索增多

建议原则：

- 初值附近先给合理范围
- 如果一轮结果靠近边界，再考虑扩边
- 如果参数出现物理上不合理的值，要及时缩小范围

## 7. `NewSimplerCar` 实战经验

模型：

- `NewSimplerCar.SimpleCar`

典型映射：

- 模型变量：`CarBody.a`
- 测量列：`acc`

实际可调参数名称：

- `engineTorque1.tau_0`
- `gearBox.lossTable[1,2]`

固定参数示例：

- `gearBox.ratio = 2.34`

示例时间窗：

- `SimStartTime = 3.8`
- `SimEndTime = 6`
- `estimateStartTime = 3.8`
- `estimateEndTime = 6`

示例配置：

```python
mpe.SelectTunerParam(("engineTorque1.tau_0", "gearBox.lossTable[1,2]"))
mpe.ConfigTunerParam("engineTorque1.tau_0", 100, 400, 320)
mpe.ConfigTunerParam("gearBox.lossTable[1,2]", 0, 1, 1)

mpe.NewExpAttachPath("exp", r"C:\\path\\Acceleration_measurements.csv")
mpe.SetEstimateExp("exp")

mpe.SelectFixParam("exp", ("gearBox.ratio",))
mpe.ConfigFixParam("exp", "gearBox.ratio", 2.34)

mpe.SetSimulateVariable("exp", "CarBody.a", "acc")
mpe.SetSimulateOption(3.8, 6, 3.8, 6)
mpe.SetEstimateOption("Mean Absolute Percentage Error")
mpe.SelectAlgorithm("PSO")
mpe.ConfigPSOAlgorithm()
```

## 8. `Muscle` 实战经验

模型：

- `Muscle`

变量映射：

- 模型变量：`y`
- 测量列：`muscle`

建议调节参数：

- `B`
- `J`
- `K`
- `alpha`
- `beta`
- `tau`

一组常用范围：

- `B`: `0 ~ 10`，初值 `3`
- `J`: `0 ~ 3`，初值 `1`
- `K`: `0 ~ 150`，初值 `75`
- `alpha`: `0 ~ 2`，初值 `0.2`
- `beta`: `0 ~ 2`，初值 `0.1`
- `tau`: `0 ~ 1`，初值 `0.005`

示例配置：

```python
params = [
    ("B", 0, 10, 3),
    ("J", 0, 3, 1),
    ("K", 0, 150, 75),
    ("alpha", 0, 2, 0.2),
    ("beta", 0, 2, 0.1),
    ("tau", 0, 1, 0.005),
]

mpe.SelectTunerParam(tuple(p[0] for p in params))
for name, mn, mx, init in params:
    mpe.ConfigTunerParam(name, mn, mx, init)

mpe.NewExpAttachPath("muscle_exp", r"C:\\path\\muscle.csv")
mpe.SetEstimateExp("muscle_exp")
mpe.SetSimulateVariable("muscle_exp", "y", "muscle")
mpe.SetSimulateOption(0, 5, 0, 5)
mpe.SetEstimateOption("Mean Absolute Error")
mpe.SelectAlgorithm("PSO")
mpe.ConfigPSOAlgorithm()
```

## 9. 推荐优化策略

### 9.1 粗搜

先用 `PSO` 默认参数做一轮：

- 看残差能否明显下降
- 看最优参数是否逼近上下限
- 看不同参数是否有明显漂移

### 9.2 缩范围

如果一轮结果已经比较稳定：

- 以当前最优值为中心缩小参数范围
- 再跑第二轮

这通常比一开始给超大范围更有效。

### 9.3 深化搜索

如果觉得 `PSO` 跑得不够彻底，可以提高：

- `maxIterStep`
- `populationSize`
- `convergenceTime`

例如：

```python
mpe.ConfigPSOAlgorithm(
    relativeTolerance=1e-5,
    convergenceTime=10,
    maxIterStep=300,
    populationSize=60,
    parameterAdaptive=True,
    w=0.6,
    c1=1.5,
    c2=2,
)
```

### 9.4 局部精修

在 `PSO` 得到较好初值后，再试：

- `Bobyqa`
- `Cobyla`

这类局部算法常用于最后进一步压低残差。

## 10. 结果读取建议

最常用的结果读取方式：

```python
result_names = mpe.GetEstimateResult()
best_param = mpe.GetEstimateParamData(result_names[0])
report = mpe.GetEstimateReport()
result_data = mpe.GetEstimateResultData()
```

建议同时看三类信息：

- 最优参数值
- 最终残差
- 迭代报告

其中迭代报告最有价值，因为能判断：

- 是否还在持续下降
- 是否过早停住
- 是否值得再扩大迭代次数

## 11. 最小可运行模板

```python
import mworks.sysplorer as sysplorer
import mworks.sysplorer.DesignOptMpe as mpe

sysplorer.OpenModelFile(r"your_model.mo")

assert mpe.InitialApp("YourModel")

mpe.SelectTunerParam(("param1", "param2"))
mpe.ConfigTunerParam("param1", 0, 10, 1)
mpe.ConfigTunerParam("param2", 0, 5, 0.5)

mpe.NewExpAttachPath("exp", r"measure.csv")
mpe.SetEstimateExp("exp")

mpe.SetSimulateVariable("exp", "simVar", "measureVar")
mpe.SetSimulateOption(0, 10, 0, 10)

mpe.SetEstimateOption("Mean Absolute Error")
mpe.SelectAlgorithm("PSO")
mpe.ConfigPSOAlgorithm()

mpe.StartEvaluate()
print(mpe.GetEvaluateResultData())

mpe.StartEstimate()

result_names = mpe.GetEstimateResult()
print(result_names)
print(mpe.GetEstimateParamData(result_names[0]))
print(mpe.GetEstimateReport())

mpe.CloseApp()
```

## 12. 快速检查清单

正式跑估计前，建议逐条确认：

- 模型类名是否正确
- 待调参数名是否来自 `GetTunerParam()`
- 固定参数名是否来自 `GetFixParam()`
- 仿真变量名是否来自 `GetVariable()`
- CSV 列名是否与测量文件完全一致
- 时间窗是否覆盖有效测量区间
- 残差函数是否符合目标
- 参数上下限是否合理
- 是否先执行过 `StartEvaluate()`

如果估计效果不好，优先检查：

- 名称大小写
- 参数范围
- 变量映射
- 时间窗
- 残差函数是否合适
