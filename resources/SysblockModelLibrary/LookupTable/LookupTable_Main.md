# LookupTable
---
&nbsp;

查找表模块报告。


查找表组件将图窗或表格插入到报告中。该表包含输入和输出数值。一个图窗绘制了这些值。

## 模块

| 模块名                | 说明         |
| --------------------- | ------------ |
| **[LookupTable1D](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/LookupTable/LookupTable1D.html)** | 一维线性查表模块 |
| **[LookupTable2D](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/LookupTable/LookupTable2D.html)** | 二维线性查表模块 |
| **[LookupTableND](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/LookupTable/LookupTableND.html)** | 逼近 N 维函数 |
| **[LookupTableDynamic](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/LookupTable/LookupTableDynamic.html)** | 使用所选的查找方法动态逼近一维函数 |
