# SubSystems
---
&nbsp;

与子系统有关的模块，例如 Subsystem 和 ActionPort。

使用 Subsystems 库中的模块来创建条件执行子系统、迭代子系统和可变子系统。

## 模块

| 模块名                                                       | 说明                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| **[SubSystem](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/SubSystem.html)** | 对各模块进行分组以创建模型层次结构                           |
| **[Trigger](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/Trigger.html)** | 向子系统或模型添加触发器或函数端口                           |
| **[Enable](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/Enable.html)** | 将使能端口添加到子系统或模型                                 |
| **[FunctionCallGenerator](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/FunctionCallGenerator.html)** | 提供函数调用事件来控制子系统或模型的执行                     |
| **[ForEach](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/ForEach.html)** | For Each 子系统的控制模块                                    |
| **[If](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/If.html)** | 使用类似于 if-else 语句的逻辑选择子系统执行                  |
| **[SwitchCase](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/SwitchCase.html)** | 使用类似于 switch 语句的逻辑选择子系统执行                   |
| **[ActionPort](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/ActionPort.html)** | If Action Subsystem 或 Switch Case Action Subsystem 模块的动作信号的控制端口 |
| **[SampleAndHold](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/SampleAndHold.html)** | 采样并保持输入信号                                           |
| **[WhileIterator](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/WhileIterator.html)** | 当逻辑表达式为 true 时，在仿真时间步中重复执行子系统         |
| **[ForIterator](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/SubSystems/ForIterator.html)** | 子系统中的模块将一直运行，直到迭代次数达到 For 迭代器的限制  |
