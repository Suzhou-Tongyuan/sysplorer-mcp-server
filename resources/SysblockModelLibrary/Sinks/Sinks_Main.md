# Sinks
---
&nbsp;

使用 Sinks 库中的模块为输入信号进行可视化分析。

## 模块

| 模块名                                                       | 说明                                               |
| ------------------------------------------------------------ | -------------------------------------------------- |
| **[PowerSpectralDensity](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Sinks/PowerSpectralDensity.html)** | 绘制输入信号的功率谱密度（PSD）                                 |
| **[AveragingPowerSpectralDensity](/Doc/Sysblock/SysblockBasic/SysblockModelLibrary/Sinks/AveragingPowerSpectralDensity.html)** | 绘制输入信号的平均功率谱密度（PSD）                                         |
